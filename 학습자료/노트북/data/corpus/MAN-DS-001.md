# 다이싱 소 운용 매뉴얼

## 1. 개요

다이싱 소 D-01~D-04의 운용 방법, 블레이드 관리, 알람 조치를 설명한다. 다이싱 소는 고속으로 회전하는 다이아몬드 블레이드로 웨이퍼를 자른다. 절단 중에는 냉각수를 뿌려 열과 실리콘 가루를 씻어 낸다.

## 2. 블레이드 장착과 드레싱

1. 스핀들을 정지하고 블레이드 커버를 연다.
2. 플랜지 너트를 전용 렌치로 풀고 블레이드를 교체한다.
3. 새 블레이드는 드레스 보드를 20회 잘라 날을 세운다(드레싱). 드레싱을 하지 않으면 처음 몇 줄에서 칩핑이 커진다.
4. 블레이드 높이를 자동 측정(셋업)한 뒤 절단을 시작한다.

## 3. 블레이드 교체 기준

다음 중 하나에 해당하면 블레이드를 교체한다.

- 누적 절단 거리가 10km에 이르렀을 때
- 블레이드 노출량이 0.6mm 미만일 때
- 뒷면 칩핑이 40μm를 넘을 때(SOP-DC-001)

## 4. 알람과 조치

| 코드 | 내용 | 조치 |
| --- | --- | --- |
| E-101 | 스핀들 과부하 | 절단 속도를 확인하고 블레이드 마모를 점검한다 |
| E-104 | 냉각수 유량 부족(1.5L/min 미만) | 냉각수 필터와 노즐 막힘을 확인한다 |
| E-110 | 블레이드 파손 감지 | 즉시 정지하고 블레이드를 교체한다. 파편이 튄 웨이퍼는 홀드한다 |
| E-120 | 테이블 진공 저하 | 테이프 마운트 상태와 진공 패드를 확인한다 |

## 5. 일상 점검

교대마다 냉각수 유량, 스핀들 소리, 블레이드 사용 거리를 확인하고 설비 일지에 적는다. 스핀들 소리가 평소와 다르면 설비보전팀에 점검을 요청한다.
