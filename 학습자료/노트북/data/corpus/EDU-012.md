# 외관 불량 유형 안내

외관 검사에서 판정하는 불량 유형의 모양과 흔한 원인을 설명한다. 판정 기준값은 외관 검사 기준(SOP-VI-001)에 있다.

| 불량 유형 | 모양 | 흔한 원인 공정 |
| --- | --- | --- |
| 패키지 크랙 | 패키지 몸체에 금이 감 | 트림 폼, 싱귤레이션, 습기 흡수 후 가열 |
| 칩아웃 | 패키지 모서리가 떨어져 나감 | 트림 폼, 취급 중 충격 |
| 리드 코플래너리티 불량 | 리드 하나가 다른 리드보다 높이 뜸 | 트림 폼의 폼 펀치 마모 |
| 리드 휨 | 리드가 옆으로 굽음 | 트림 폼, 취급 중 충격 |
| 마킹 불량 | 글자가 흐리거나 빠짐 | 마킹기 출력 저하, 렌즈 오염 |
| 이물 | 패키지 표면에 가루나 섬유가 붙음 | 몰딩 전 청소 불량 |
| 기포 자국 | 패키지 표면에 작은 구멍 | 몰딩 진공 불량, 컴파운드 수분 |
| 볼 누락 | BGA의 솔더 볼이 빠짐 | 볼 어태치 노즐 막힘 |

## 판정할 때 주의할 것

- 같은 유닛에 여러 불량이 있으면 표의 위쪽 유형으로 기록한다.
- 기포 자국은 표면에 보이는 것만 외관 불량으로 본다. 패키지 안의 기포는 X선 검사에서 판정한다.
- 판정이 애매하면 한계 견본과 비교한다.
