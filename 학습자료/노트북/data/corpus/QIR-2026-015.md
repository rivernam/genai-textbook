# QX48 패키지 테스트 수율 하락

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-05-18 |
| 제품 | QX48 |
| 로트 | 5월 2주차 전체 |
| 발견 공정 | 패키지 테스트 |
| 관련 설비 | 테스트 핸들러 H-07 |
| 담당 | 테스트기술팀 정우진 책임 |
| 진행 상태 | 종결(2026-05-25) |

## 현상

QX48의 주간 테스트 수율이 지난주 98.1%에서 95.2%로 떨어졌다. 수율이 떨어진 로트는 모두 H-07에서 테스트했다. H-07의 빈 4(접촉 불량 의심) 비율은 2.8%였다.

## 원인

H-07 소켓 핀 끝에 솔더 찌꺼기가 쌓여 접촉 저항이 커졌다. 당시 클리닝 주기는 1만 회 삽입이었다.

## 조치

소켓을 클리닝하고 빈 4 유닛을 재테스트했다. 재테스트에서 빈 4 유닛의 96%가 빈 1로 바뀌었다.

## 재발 방지

소켓 클리닝 주기를 5,000회로 줄이고(SOP-PT-002), 빈 4 비율이 1%를 넘으면 소켓을 점검하도록 했다(SOP-PT-001).
