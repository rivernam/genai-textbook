# 외관 검사 기준

## 1. 목적

패키지 외관 검사의 불량 판정 기준을 정한다. 불량 유형의 그림과 설명은 교육 자료 EDU-012에 있다.

## 2. 적용 범위

외관 검사 장비 V-01~V-03의 자동 검사와, 작업자의 육안 재검사에 모두 적용한다.

## 3. 판정 기준

| 불량 유형 | 판정 기준 | 적용 제품 |
| --- | --- | --- |
| 패키지 크랙 | 길이와 관계없이 불량 | 전 제품 |
| 칩아웃(모서리 깨짐) | 0.3mm 초과면 불량 | 전 제품 |
| 리드 코플래너리티 | 0.08mm 초과면 불량 | QX48, SP8 |
| 리드 휨(좌우) | 리드 폭의 50% 초과면 불량 | QX48, SP8 |
| 마킹 불량 | 글자 하나라도 읽기 어려우면 불량 | 전 제품 |
| 이물 | 0.2mm 초과면 불량 | 전 제품 |
| 볼 누락 | 하나라도 없으면 불량 | BG256 |

리드 코플래너리티는 패키지를 평면에 놓았을 때 가장 높이 뜬 리드와 평면 사이의 거리다.

## 4. 재검사

자동 검사에서 불량으로 판정된 유닛은 작업자가 확대경으로 한 번 더 본다. 작업자 판정이 자동 검사와 다르면 품질보증팀 담당자가 최종 판정한다.
