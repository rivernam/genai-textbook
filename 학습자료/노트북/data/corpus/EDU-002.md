# 사내 약어와 용어 모음

현장과 사내 문서에서 쓰는 약어와 용어를 모았다. 업계에서 널리 쓰는 말과 우리 회사에서만 쓰는 말을 구분해 적었다.

## 1. 우리 회사에서만 쓰는 말

| 약어나 용어 | 풀이 | 설명 |
| --- | --- | --- |
| SSC | Shift Start Check | 교대 시작 후 30분 안에 하는 점검. 알람 이력, 소모품 잔량, 손목띠 측정을 확인한다(SOP-CH-001) |
| QIR | Quality Issue Report | 품질 이슈 보고서. 품질보증팀이 발행하고 번호는 QIR-연도-일련번호로 붙인다 |
| 로트 카드 | | 로트마다 따라다니는 이력 카드. 예전에는 LT 카드, 트래블러라고도 불렀다 |
| 홀드 랙 | | 홀드한 로트를 모아 두는 노란색 선반 |
| 한계 견본 | | 양품과 불량의 경계에 있는 견본. 육안 판정이 애매할 때 비교한다 |
| P1, P2 | | 2동의 두 생산 라인. P1은 리드 프레임 제품, P2는 주로 BG256을 만든다 |
| CMP-A, CMP-B | | 몰딩 컴파운드의 사내 자재 코드. 공급사 이름 대신 쓴다 |
| F-PR-012 | | 교대 인수인계 전자 양식의 번호 |
| 빈 4 비율 | | 테스트에서 빈 4(접촉 불량 의심)로 분류된 유닛의 비율. 소켓 상태를 판단하는 지표로 쓴다 |

## 2. 업계에서 쓰는 말

| 약어나 용어 | 풀이 | 설명 |
| --- | --- | --- |
| PM | Preventive Maintenance | 예방 정비. 고장 전에 정해진 주기로 하는 정비 |
| MRB | Material Review Board | 홀드한 자재나 로트의 처리를 정하는 회의 |
| MSL | Moisture Sensitivity Level | 습도 민감 등급. 포장을 연 뒤 대기에 노출되어도 되는 시간을 정한다 |
| PMC | Post Mold Cure | 몰딩 후 오븐에서 하는 후경화 |
| EMC | Epoxy Molding Compound | 에폭시 몰딩 컴파운드 |
| NSOP | Non-Stick On Pad | 와이어 볼이 칩 패드에 붙지 않는 본딩 불량 |
| NSOL | Non-Stick On Lead | 스티치가 리드에 붙지 않는 본딩 불량 |
| EFO | Electronic Flame-Off | 방전으로 와이어 끝을 녹여 볼을 만드는 장치 |
| ESD | Electrostatic Discharge | 정전기 방전 |
| LOTO | Lockout Tagout | 정비 중 설비의 에너지원을 잠그고 표지를 거는 절차 |
| MES | Manufacturing Execution System | 로트 이력과 설비 상태를 관리하는 생산 관리 시스템 |
| HIC | Humidity Indicator Card | 방습 포장 안의 습도를 색으로 보여 주는 카드 |
| 8D | Eight Disciplines | 고객 불량에 대해 원인과 대책을 8단계로 정리하는 보고서 형식 |
