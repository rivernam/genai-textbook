# QX48 정전기 손상 의심

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-03-30 |
| 제품 | QX48 |
| 로트 | L260326-01 |
| 발견 공정 | 패키지 테스트 |
| 관련 설비 | 테스트 핸들러 H-04 구역 |
| 담당 | 품질보증팀 강서연 책임 |
| 진행 상태 | 종결(2026-04-13) |

## 현상

한 로트에서 빈 3(기능 불량)이 1.9% 나왔다. 평소에는 0.3% 아래다. 불량 유닛을 분석한 결과 입력 핀 보호 회로가 손상되어 있었다.

## 원인

테스트 구역의 손목띠 측정기가 3월 24일부터 이틀 동안 고장 나 있었다. 그동안 작업자들이 손목띠를 측정하지 않았고, 한 작업자의 손목띠 접지선이 끊어져 있었다.

## 조치

손목띠를 교체하고, 고장 난 측정기를 수리했다. 해당 로트는 재테스트 후 빈 3 유닛을 폐기했다.

## 재발 방지

정전기 관리 기준(SOP-ESD-001)에 측정기 고장 시 조치를 추가했다. 구역 안에 쓸 수 있는 측정기가 없으면 칩을 맨손으로 다루는 작업을 멈춘다.
