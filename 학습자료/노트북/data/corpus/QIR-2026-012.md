# QX48 마킹 흐림

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-04-20 |
| 제품 | QX48 |
| 로트 | L260416-01 |
| 발견 공정 | 출하 전 검사 |
| 관련 설비 | 레이저 마킹기 L-02 |
| 담당 | 몰딩기술팀 최민서 책임 |
| 진행 상태 | 종결(2026-04-30) |

## 현상

출하 대기 물량에서 마킹 글자가 흐리게 찍힌 제품이 섞여 있었다. 날짜 코드의 마지막 글자가 특히 읽기 어려웠다.

## 원인

L-02의 보호 렌즈를 3주 동안 닦지 않아 레이저 출력이 설정값의 82%로 떨어졌다. 매일 하는 출력 점검이 4월 둘째 주에 기록 없이 빠졌다.

## 조치

렌즈를 닦아 출력을 회복했다. 출하 대기 물량 4릴을 전수 검사해 흐린 마킹 37개를 다시 마킹했다.

## 재발 방지

출력 점검을 하지 않으면 마킹기가 작업을 시작하지 않도록 점검 입력 화면을 추가했다.
