# SP8 백 그라인딩 두께 미달

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-10-12 |
| 제품 | SP8 |
| 로트 | L261008-03 |
| 발견 공정 | 다이싱 전 두께 측정 |
| 관련 설비 | 백 그라인더 G-02 |
| 담당 | 웨이퍼가공팀 오세훈 책임 |
| 진행 상태 | 진행 중 |

## 현상

SP8 웨이퍼의 두께가 228μm로 측정되었다. 목표 두께는 250μm이고 공차는 ±15μm다.

## 원인

야간 교대에서 G-02의 인라인 두께 측정기를 보정하지 않고 작업을 시작했다. 측정기가 실제보다 두껍게 읽어, 설비가 더 깎았다. 보정을 건너뛴 이유는 조사 중이다.

## 조치

해당 로트 웨이퍼 25장을 홀드했다. 두께가 235μm 미만인 웨이퍼는 폐기하기로 MRB에서 판정했다.
