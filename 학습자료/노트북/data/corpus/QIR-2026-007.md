# QX48 몰딩 미충전

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-02-09 |
| 제품 | QX48 |
| 로트 | L260205-02, L260205-04 |
| 발견 공정 | 몰딩 후 육안 검사 |
| 관련 설비 | 몰딩 프레스 M-01 |
| 담당 | 몰딩기술팀 최민서 책임 |
| 진행 상태 | 종결(2026-02-16) |

## 현상

몰딩 후 패키지 모서리가 덜 채워진 미충전 불량이 두 로트에서 1.8% 나왔다. 패키지 표면에 작은 기포 자국도 함께 보였다.

## 원인

컴파운드는 당시 기준대로 4시간 해동했다. 그러나 2월에는 자재 대기실의 온도가 낮아, 4시간이 지나도 정제 중심부가 상온에 이르지 못했다. 덜 녹은 정제 표면에 수분이 맺혀 흐름이 나빠졌다.

## 조치

해당 로트를 선별하고 불량 유닛은 폐기했다. 남은 컴파운드는 해동 시간을 늘려 사용했다.

## 재발 방지

몰딩 컴파운드 보관과 해동 기준(SOP-MD-002)을 개정해 최소 해동 시간을 6시간으로 늘렸다. 이 결정은 2026-02-09 몰딩 미충전 대책 회의에서 내렸다.
