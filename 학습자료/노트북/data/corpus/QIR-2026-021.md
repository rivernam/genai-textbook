# BG256 솔더 볼 지름 불균일

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-10-26 |
| 제품 | BG256 |
| 로트 | L261021-02 |
| 발견 공정 | 볼 어태치 후 비전 검사 |
| 관련 설비 | 볼 어태치 A-01 |
| 담당 | 조립기술팀 이도윤 선임 |
| 진행 상태 | 진행 중 |

## 현상

볼 어태치 후 비전 검사에서 볼 지름 편차가 ±0.05mm까지 측정되었다. 기준은 ±0.03mm 이하다.

## 원인

10월에 입고된 솔더 볼 공급 로트에서 지름 산포가 크다고 의심한다. 공급 업체에 성적서와 샘플 측정을 요청했다. 리플로 조건은 기록상 정상이었다.

## 조치

의심 볼 로트의 사용을 멈추고 이전 볼 로트로 바꿨다.
