# W-07 NSOP 증가

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-05-04 |
| 제품 | QX48 |
| 로트 | L260430-01~L260430-03 |
| 발견 공정 | 와이어 본딩 |
| 관련 설비 | 와이어 본더 W-07 |
| 담당 | 조립기술팀 박지현 책임 |
| 진행 상태 | 종결(2026-05-18) |

## 현상

W-07에서 NSOP 알람(E-2041)이 한 교대에 11회 나왔고, 본더가 여러 번 멈췄다. 재시작해도 같은 알람이 이어졌다.

## 원인

리드 프레임을 플라즈마 세정한 뒤 9시간이 지나 본딩했다. 당시에는 세정한 매거진을 언제까지 써야 하는지 정한 기준이 없어, 작업자가 세정 여부를 판단했다. 시간이 지나면서 패드 표면에 유기물이 다시 쌓였다.

## 조치

남은 매거진을 다시 세정한 뒤 본딩했다. 그 뒤 NSOP 알람은 한 교대에 1회 아래로 줄었다.

## 재발 방지

플라즈마 세정 작업 표준(SOP-PL-001)을 제정해 세정 후 4시간 안에 본딩하도록 했다. 와이어 본더 운용 매뉴얼(MAN-WB-001)의 NSOP 조치에도 이 확인을 넣었다.
