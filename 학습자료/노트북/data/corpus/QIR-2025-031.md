# QX48 와이어 스윕 증가

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2025-06-23 |
| 제품 | QX48 |
| 로트 | L250619-02, L250620-01 |
| 발견 공정 | 몰딩 후 X선 검사 |
| 관련 설비 | 몰딩 프레스 M-02 |
| 담당 | 몰딩기술팀 최민서 책임 |
| 진행 상태 | 종결(2025-07-14) |

## 현상

몰딩 후 X선 검사에서 와이어 스윕 비율이 5%를 넘는 유닛이 두 로트에서 4.2% 나왔다. 평소에는 0.5% 아래다. 휜 와이어는 대부분 패키지의 게이트 반대쪽 모서리에 있었다.

## 원인

M-02의 트랜스퍼 시간이 10초로, 같은 조건을 쓰는 다른 프레스보다 컴파운드가 빠르게 흘렀다. 6월에 바뀐 QX48 리드 프레임은 와이어가 0.4mm 길어져, 같은 흐름 속도에서도 더 쉽게 밀렸다.

## 조치

QX48의 트랜스퍼 시간을 12초로 늘렸다. 두 로트는 MRB 판정으로 X선 전수 선별 후 출하했다.

## 재발 방지

몰딩 작업 표준(SOP-MD-001)을 3차 개정해 QX48 트랜스퍼 시간을 12초로 바꿨다.
