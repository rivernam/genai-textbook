# 안전 보호구 착용 기준

## 1. 목적

작업 구역별로 착용해야 하는 보호구를 정한다.

## 2. 구역별 보호구

| 구역 | 필수 보호구 | 추가 보호구 |
| --- | --- | --- |
| 클린룸 공통 | 방진복, 방진화, 마스크, 장갑 | |
| 몰딩실 | 클린룸 공통 보호구 | 금형을 다룰 때 내열 장갑 |
| 리플로 구역 | 클린룸 공통 보호구 | 출구에서 기판을 꺼낼 때 내열 장갑 |
| 화학물질 보관실 | 보안경, 내화학 장갑 | 약품을 옮겨 담을 때 앞치마 |
| 레이저 마킹 구역 | 클린룸 공통 보호구 | 덮개를 열고 정비할 때 레이저 보안경 |
| 옥외 가스 탱크 구역 | 안전모, 안전화 | 충전 작업 입회 때 보안경 |

## 3. 지급과 교체

- 보호구는 각 팀의 안전 담당자가 지급한다.
- 내열 장갑은 손바닥이 닳거나 구멍이 나면 바로 바꾼다.
- 레이저 보안경은 해당 레이저의 파장용인지 확인하고 쓴다.
