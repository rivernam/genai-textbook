# BG256 몰딩 기포(보이드) 증가

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-08-24 |
| 제품 | BG256 |
| 로트 | L260819-01 외 3로트 |
| 발견 공정 | 몰딩 후 X선 검사 |
| 관련 설비 | 몰딩 프레스 M-03 |
| 담당 | 몰딩기술팀 최민서 책임 |
| 진행 상태 | 진행 중 |

## 현상

M-03에서 몰딩한 BG256의 패키지 내부 기포가 늘었다. X선 검사에서 지름 0.1mm 넘는 기포가 있는 유닛이 2.4% 나왔다.

## 원인

M-03의 금형 진공도가 -88kPa로, 정상 기준(-95kPa 이하)에 미치지 못했다. 진공 펌프의 성능이 떨어진 것으로 보고 있으며, 펌프 분해 점검 결과를 기다리고 있다.

## 조치

M-03에서 BG256 생산을 멈추고 M-04로 옮겼다. 진공 펌프 교체 부품은 9월 말 입고 예정이다.
