# BG256 솔더 볼 누락 고객 반품

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-06-08 |
| 제품 | BG256 |
| 로트 | L260521-04 |
| 발견 공정 | 고객사 A 입고 검사 |
| 관련 설비 | 볼 어태치 A-01 |
| 담당 | 조립기술팀 이도윤 선임 |
| 진행 상태 | 종결(2026-06-22) |

## 현상

고객사 A가 반품한 제품 3개에서 솔더 볼 누락이 확인되었다. 3개 모두 같은 위치(C7)의 볼이 없었다.

## 원인

A-01 볼 툴의 C7 노즐이 플럭스 찌꺼기로 막혀 있었다. 노즐 청소를 하루 1회 했고, 막힌 뒤 다음 청소까지 볼이 빠진 채로 생산되었다. 당시 볼 누락 비전 검사는 로트마다 1스트립만 했다.

## 조치

노즐을 초음파 세척했다. 같은 기간에 생산한 7로트를 전수 검사해 볼 누락 유닛 41개를 리워크했다.

## 재발 방지

노즐 청소를 매 교대로 바꿨고(MAN-BA-001), 볼 누락 비전 검사를 스트립마다 하도록 바꿨다(SOP-BA-001).
