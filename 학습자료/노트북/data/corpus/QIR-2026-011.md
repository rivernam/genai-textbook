# QX48 다이 기울기 불량

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-04-13 |
| 제품 | QX48 |
| 로트 | L260409-02 |
| 발견 공정 | 다이 어태치 후 검사 |
| 관련 설비 | 다이 본더 B-02 |
| 담당 | 조립기술팀 이도윤 선임 |
| 진행 상태 | 종결(2026-04-27) |

## 현상

B-02에서 붙인 다이가 비스듬히 붙어 다이 기울기가 최대 28μm로 측정되었다. 기준은 15μm 이하다.

## 원인

B-02 콜릿의 사용 횟수가 27만 회였다. 당시 교체 기준(30만 회)에 이르지 않았지만 바닥면 한쪽이 닳아 다이를 고르게 누르지 못했다.

## 조치

콜릿을 교체했다. 와이어 본딩 전 단계에서 로트를 전수 선별했다.

## 재발 방지

다이 본더 운용 매뉴얼(MAN-DB-001)의 콜릿 교체 주기를 20만 회로 줄였다.
