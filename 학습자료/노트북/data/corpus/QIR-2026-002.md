# QX48 리드 코플래너리티 불량

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-01-26 |
| 제품 | QX48 |
| 로트 | L260122-01 |
| 발견 공정 | 외관 검사 |
| 관련 설비 | 트림 폼 T-02 |
| 담당 | 몰딩기술팀 최민서 책임 |
| 진행 상태 | 종결(2026-03-09) |

## 현상

외관 검사에서 리드 코플래너리티 불량이 오전에만 12건 나왔다. 불량 유닛은 모두 T-02를 거쳤다.

## 원인

T-02 폼 펀치의 타수가 72만 타였다. 당시 교체 기준은 80만 타였으나, 펀치 끝이 닳아 리드를 고르게 구부리지 못했다.

## 조치

펀치와 다이를 교체했다. 로트는 외관 전수 재검사 후 불량 12건을 폐기했다.

## 재발 방지

펀치 교체 주기를 50만 타로 줄였다(SOP-TF-001 2차 개정, MAN-TF-001 2차 개정).
