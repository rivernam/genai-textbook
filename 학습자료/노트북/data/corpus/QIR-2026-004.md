# SP8 와이어 스윕과 루프 높이 이탈

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-02-02 |
| 제품 | SP8 |
| 로트 | L260129-03 |
| 발견 공정 | 와이어 본딩 후 검사 |
| 관련 설비 | 와이어 본더 W-05 |
| 담당 | 조립기술팀 박지현 책임 |
| 진행 상태 | 종결(2026-02-20) |

## 현상

W-05에서 본딩한 SP8 로트에서 루프 높이가 210μm 안팎으로 측정되었다. 기준은 150±25μm다. 몰딩 후에는 와이어 스윕이 3.1% 나왔다.

## 원인

작업자가 SP8 대신 QX48 레시피를 불러왔다. 두 제품의 레시피 이름이 화면 목록에서 바로 붙어 있었고, 레시피를 확인하는 단계가 없었다.

## 조치

레시피를 바로잡고 로트는 몰딩 전에 루프 높이 전수 검사로 선별했다.

## 재발 방지

본딩 시작 전에 로트 카드의 바코드와 레시피 이름을 대조하는 기능을 W-01~W-12에 넣었다. 레시피가 다르면 본더가 시작되지 않는다.
