# 품질 이슈 보고서 작성 안내

## 1. 언제 쓰는가

다음 중 하나에 해당하면 품질보증팀이 품질 이슈 보고서(QIR)를 발행한다.

- 같은 불량이 한 로트에서 1%를 넘을 때
- 고객이 불량을 통보하거나 제품을 반품했을 때
- 작업 표준의 기준을 벗어난 로트를 MRB에서 다룰 때

## 2. 기한

- 이슈를 접수하고 24시간 안에 현상과 임시 조치를 적어 1차 발행한다.
- 원인과 재발 방지 대책은 2주 안에 채운다. 2주 안에 원인을 찾지 못하면 진행 상태를 "진행 중"으로 두고 주간 품질 회의에서 경과를 보고한다.

## 3. 항목

| 항목 | 쓰는 내용 |
| --- | --- |
| 개요 | 제품, 로트, 발견 공정, 관련 설비, 담당, 진행 상태 |
| 현상 | 관찰한 사실과 수치. 추측을 섞지 않는다 |
| 원인 | 확인한 원인. 확인 중이면 그렇게 적는다 |
| 조치 | 해당 로트와 설비에 한 일 |
| 재발 방지 | 바꾼 작업 표준이나 설비 기준. 문서 번호를 적는다 |

## 4. 종결

재발 방지 대책을 작업 표준에 반영하고, 그 뒤 2주 동안 같은 불량이 다시 나지 않으면 종결한다. 종결일은 개요의 진행 상태에 적는다.
