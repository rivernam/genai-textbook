# QX48 와이어 스윕 재발

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-09-14 |
| 제품 | QX48 |
| 로트 | L260908-01~L260910-02 |
| 발견 공정 | 몰딩 후 X선 검사 |
| 관련 설비 | 몰딩 프레스 M-01, M-02 |
| 담당 | 몰딩기술팀 최민서 책임 |
| 진행 상태 | 진행 중 |

## 현상

9월 둘째 주부터 QX48 와이어 스윕 비율이 5%를 넘는 유닛이 1.5% 안팎으로 나왔다. 특정 프레스에 몰리지 않고 M-01과 M-02 모두에서 나왔다.

## 원인

9월 1일부터 컴파운드 공급사가 바뀌었다(NOTI-2026-017). 새 컴파운드 CMP-B는 175℃에서 점도가 이전 컴파운드보다 높아, 같은 트랜스퍼 조건에서 와이어를 더 세게 민다. 원인은 확인 중이며, 공급사에 점도 데이터를 요청했다.

## 조치

트랜스퍼 시간을 12초에서 14초로 늘리는 평가를 진행하고 있다. 평가 결과가 나올 때까지 QX48은 로트마다 X선 검사를 3스트립으로 늘렸다.
