# 재료

교재의 예제와 실습에 쓰는 재료입니다. 모두 직접 작성했고, LLM으로 생성하지 않았습니다. 가상의 반도체 후공정 회사를 배경으로 하며, 설비 번호(W-07 등)와 사례는 가상입니다. 공정에 관한 일반적인 설명은 널리 알려진 내용입니다.

## 후공정_문장.txt

후공정의 일반 사실을 적은 문장 30개. 2장 예제 2-1(작은 모델을 처음부터 학습하기)에 씁니다.

## 문의.csv

후공정 라인의 현장 문의 60건. 4~6장의 예제와 실습에 씁니다.

| 열 | 뜻 |
| --- | --- |
| 번호 | Q01~Q60 |
| 문의 | 문의 글 |
| 라벨 | 정답 라벨: 설비 이상, 품질, 안전, 문서와 데이터 요청 |
| 긴급 | 예, 아니오 |
| 비고 | 헷갈리는 문의의 판정 근거, 정보가 빠진 문의의 빠진 항목 |

구성: Q01~Q40은 라벨이 분명한 문의(라벨마다 10건), Q41~Q55는 두 라벨에 걸쳐 헷갈리는 문의, Q56~Q60은 설비 번호나 담당자 같은 정보가 빠진 문의입니다.

정답 라벨은 아래 판정 기준을 위에서부터 차례로 적용해 정했습니다.

1. 사람이 다치거나 다칠 위험이 있으면 **안전**
2. 문의자가 원하는 것이 문서나 기록의 전달이면 **문서와 데이터 요청**
3. 원인 설비가 특정되고 조치 대상이 설비이면 **설비 이상**
4. 제품 결과에 이상이 있고 원인 설비가 특정되지 않으면 **품질**

## 14장/

14장(코딩 에이전트와 멀티 에이전트)의 예제에 쓰는 가상의 설비팀 작업 폴더입니다. 설비 번호, 알람 코드, 점검 기준, 규정은 모두 가상입니다.

| 파일 | 내용 |
| --- | --- |
| 규칙파일.md | 작업 폴더의 규칙 파일. 예제 14-1이 임시 폴더에 CLAUDE.md라는 이름으로 복사합니다. 이 폴더에 CLAUDE.md라는 이름으로 두지 않는 것은, 교재 폴더에서 코딩 에이전트를 쓸 때 이 규칙이 섞이지 않게 하려는 것입니다 |
| skills/ | Skill 세 개(writing-alarm-report, checking-safety-notice, summarizing-shift-handover). 예제 14-1이 임시 폴더의 .claude/skills/로 복사합니다 |
| 기록/알람로그.csv | 2026-11-16~22 설비 5대의 알람 400건. 열: 일시, 설비, 알람코드, 내용, 조치. 조치가 "부품 교체"인 행은 3건(W-07 캐필러리, B-04 흡착 노즐, M-03 히터 카트리지)입니다. 가장 많은 알람은 W-07의 E-214(108건)입니다 |
| 기록/점검기준.md | 설비별 PM 주기, 소모 부품 교체 기준, 주간 알람 기준 |
| 기록/점검기록.csv | 2026-11의 PM과 부품 교체 기록 8건 |
