# 재료

교재의 예제와 실습에 쓰는 재료입니다. 모두 직접 작성했고, LLM으로 생성하지 않았습니다. 가상의 반도체 후공정 회사를 배경으로 하며, 설비 번호(W-07 등)와 사례는 가상입니다. 공정에 관한 일반적인 설명은 널리 알려진 내용입니다.

## 후공정_문장.txt

후공정의 일반 사실을 적은 문장 30개. 2장 예제 2-1(작은 모델을 처음부터 학습하기)에 씁니다.

## 문의.csv

후공정 라인의 현장 문의 60건. 4~6장의 예제와 실습에 씁니다.

| 열 | 뜻 |
| --- | --- |
| 번호 | Q01~Q60 |
| 문의 | 문의 글 |
| 라벨 | 정답 라벨: 설비 이상, 품질, 안전, 문서와 데이터 요청 |
| 긴급 | 예, 아니오 |
| 비고 | 헷갈리는 문의의 판정 근거, 정보가 빠진 문의의 빠진 항목 |

구성: Q01~Q40은 라벨이 분명한 문의(라벨마다 10건), Q41~Q55는 두 라벨에 걸쳐 헷갈리는 문의, Q56~Q60은 설비 번호나 담당자 같은 정보가 빠진 문의입니다.

정답 라벨은 아래 판정 기준을 위에서부터 차례로 적용해 정했습니다.

1. 사람이 다치거나 다칠 위험이 있으면 **안전**
2. 문의자가 원하는 것이 문서나 기록의 전달이면 **문서와 데이터 요청**
3. 원인 설비가 특정되고 조치 대상이 설비이면 **설비 이상**
4. 제품 결과에 이상이 있고 원인 설비가 특정되지 않으면 **품질**

## 알람.csv

설비 알람 96건과 사내 표준 기록 형식. 11장과 12장의 예제와 실습(파인튜닝, 양자화한 모델, 비용 계산)에 씁니다.

| 열 | 뜻 |
| --- | --- |
| 번호 | A01~A96 |
| 알람 | 현장에서 남긴 알람 글 |
| 표준 | 정답. 사내 표준 형식 "설비코드 \| 분류 \| 담당" |
| 용도 | 학습(64건) 또는 평가(32건). 세 건마다 한 건을 평가로 떼었습니다 |

표준 형식은 다음 규칙으로 정했습니다. 설비코드와 담당 부서는 가상입니다.

1. 설비코드: 설비 종류의 약어(다이싱 소 DS, 다이 본더 DB, 와이어 본더 WB, 몰딩기 MD, 마킹기 MK, 테스트 핸들러 TH) 뒤에 호기를 두 자리로 붙입니다. 예: 3호기 와이어 본더 → WB-03
2. 분류: 위에서부터 차례로 적용합니다. 사람이 다치거나 다칠 위험이 있으면 **안전**, 제품의 측정값이나 외관이 기준을 벗어났으면 **품질**, 그 밖의 설비 동작 이상이면 **설비**
3. 담당: 설비는 보전팀, 품질은 품질팀, 안전은 안전팀
