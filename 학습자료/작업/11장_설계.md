## 확인할 사실

1. LoRA의 원리, 학습 파라미터와 메모리 감소, 추론 지연 없음: Hu 외(2021) 초록 확인(GPT-3 175B에서 학습 파라미터 1만분의 1, GPU 메모리 3분의 1).
2. LoRA가 덜 학습하고 덜 잊음: Biderman 외(2024) 확인.
3. 새 지식 파인튜닝과 환각: Gekhman 외(2024) 초록 확인.
4. Qwen2.5-0.5B-Instruct의 구조(24층, q_proj 896×896, v_proj 128×896): 로컬 실행으로 확인.

## 사용자에게 확인할 것

1. 사내 GPU 환경에서 노트북을 여는 방법(실습 11-3의 안내 문장을 비워 둠, 설계서 8절).
2. 강의 파트 3(성능 평가)의 학습 곡선, 라벨 노이즈, 선택 트리는 넣지 않았다. 평가셋으로 전후를 비교하는 원리는 9장과 11장에 있고, 학습 곡선은 실습 11-3을 GPU에서 건수를 바꿔 실행하면 같은 것을 볼 수 있다고 판단했다. 넣을지 확인.
3. 예제 11-3은 CPU에서 약 5분 걸린다. 더 짧게 하려면 학습 데이터나 에포크를 줄여야 하는데, 그러면 학습 후 답이 형식을 지키지 못한다(1에포크 실험에서 평가셋 0%).
