# 와이어 본더 운용 매뉴얼

## 1. 개요

와이어 본더 W-01~W-12의 구조, 일상 점검, 알람 조치를 설명한다. 이 본더는 열과 초음파를 함께 써서 금선이나 구리선을 붙이는 열초음파(thermosonic) 방식이다.

## 2. 본딩 순서

1. EFO(electronic flame-off) 방전으로 와이어 끝을 녹여 둥근 볼을 만든다.
2. 캐필러리가 볼을 칩의 패드에 눌러 붙인다(볼 본드, 1차 본드).
3. 캐필러리가 와이어를 풀며 루프를 그리고 리드로 이동한다.
4. 와이어를 리드에 눌러 붙이고 끊는다(스티치 본드, 2차 본드).

## 3. 주요 부품

- 트랜스듀서: 초음파 진동을 캐필러리에 전달한다. 분기마다 진동 출력을 보정한다.
- 히터 블록: 리드 프레임을 200℃로 가열한다. 허용 범위는 ±10℃다.
- 클램프: 본딩 중 리드 프레임을 눌러 고정한다. 클램프가 들뜨면 NSOL이 늘어난다.

## 4. 일상 점검

교대를 시작할 때 다음을 확인하고 설비 일지에 적는다.

- 히터 블록 온도
- 캐필러리 사용 횟수(교체 기준은 SOP-WB-002)
- 와이어 잔량
- 최근 8시간의 알람 이력

## 5. 알람 코드와 조치

| 코드 | 알람 | 뜻 | 조치 |
| --- | --- | --- | --- |
| E-2041 | NSOP | 볼이 패드에 붙지 않음 | 패드 오염을 확인하고, 플라즈마 세정 후 4시간이 지났으면 다시 세정한다 |
| E-2042 | NSOL | 스티치가 리드에 붙지 않음 | 클램프 들뜸과 캐필러리 마모를 확인한다 |
| E-2107 | WIRE BREAK | 와이어 끊김 | 와이어 경로를 확인하고 와이어를 다시 끼운다 |
| E-2210 | EFO OPEN | 볼 형성 방전 실패 | EFO 전극과 와이어 끝의 간격을 확인한다 |
| E-2305 | LOOP HEIGHT | 루프 높이 이탈 | 레시피의 루프 설정을 확인한다 |
| E-2400 | HEATER | 히터 블록 온도 이탈 | 열전대 연결을 확인하고 설비보전팀에 알린다 |

같은 알람이 한 교대에 3회 넘게 나면 조립기술팀 엔지니어에게 알린다.

## 6. 정기 PM

와이어 본더의 정기 PM은 설비 PM 주기표(MAN-PM-001)를 따른다. PM 때 트랜스듀서 출력, 클램프 평탄도, 히터 블록 온도 분포를 점검한다.
