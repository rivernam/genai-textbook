# SP8 칩 가장자리 크랙

## 개요

| 항목 | 내용 |
| --- | --- |
| 발행일 | 2026-04-27 |
| 제품 | SP8 |
| 로트 | L260423-01 |
| 발견 공정 | 외관 검사 |
| 관련 설비 | 다이 본더 B-05 |
| 담당 | 조립기술팀 이도윤 선임 |
| 진행 상태 | 종결(2026-05-08) |

## 현상

외관 검사에서 칩 가장자리가 미세하게 깨진 제품이 발견되었다. 패키지를 열어 보니 다이 뒷면 모서리에서 시작된 크랙이 있었다.

## 원인

4월에 SP8 웨이퍼 두께를 280μm에서 250μm로 바꿨으나, B-05의 니들 높이 레시피를 갱신하지 않았다. 니들이 얇아진 다이를 너무 높이 밀어 올려 뒷면 모서리에 힘이 몰렸다.

## 조치

B-05의 니들 높이를 250μm 다이에 맞춰 낮췄다. 해당 로트는 외관 전수 검사 후 크랙 유닛을 폐기했다.

## 재발 방지

웨이퍼 두께를 바꾸는 변경 요청서에 다이 본더 니들 높이 확인 항목을 추가했다.
