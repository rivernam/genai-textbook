# 비상 연락 체계

## 1. 연락 순서

사고를 발견한 사람은 종합 상황실(내선 4119)에 먼저 알린다. 종합 상황실은 아래 순서로 연락한다.

1. 환경안전팀 당직자
2. 사고가 난 구역의 팀장
3. 공장장

## 2. 주요 연락처

| 연락처 | 내선 |
| --- | --- |
| 종합 상황실 | 4119 |
| 환경안전팀 사무실 | 4110 |
| 설비보전팀 당직자 | 4471 |
| 생산관리팀 당직자 | 4402 |
| 사내 의무실 | 4150 |

## 3. 야간과 휴일

야간과 휴일에는 종합 상황실이 환경안전팀 당직자에게 휴대 전화로 연락한다. 당직 일정은 종합 상황실에 있다.

이 문서는 결재본을 스캔한 것이다. 원본은 환경안전팀이 보관한다.
