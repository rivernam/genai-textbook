강의에 없지만 넣는 것: 사전 학습의 목표를 손실(loss)로 설명, 베이스 모델과 instruct 모델의 차이를 직접 실행해 보기, 틀린 문장도 손실이 낮을 수 있다는 것(환각의 원인), RLHF와 DPO의 차이, 지식 기준일이 생기는 이유, thinking 모델의 학습(검증할 수 있는 보상으로 하는 강화 학습)과 토큰 비용.

## 학습 목표

1. 사전 학습이 대량의 글에서 다음 토큰 맞히기를 학습한다는 것을 손실로 설명하고, 사전 학습만 한 모델(베이스 모델)이 질문에 답하지 않고 글을 이어 쓰는 이유를 설명할 수 있습니다.
2. SFT(instruction tuning)와 RLHF, DPO가 각각 어떤 데이터로 모델의 무엇을 바꾸는지 설명할 수 있습니다.
3. 모델에 지식 기준일이 생기는 이유와, 학습 목표가 "사실"이 아니라 "그럴듯한 다음 토큰"이어서 환각이 생기는 이유를 설명할 수 있습니다.
4. thinking 모델이 답하기 전에 토큰을 더 생성하는 이유와, 그 토큰이 시간과 요금에 어떻게 나타나는지 설명할 수 있습니다.

| 2-1 베이스 모델과 instruct 모델 | 같은 질문 "반도체 후공정에서 다이싱이란 무엇입니까?"에 베이스 모델은 질문을 되풀이하며 웹 문서처럼 글을 이어 쓰고, instruct 모델은 답하는 형식으로 응답 | 공개 모델 Qwen2.5-0.5B(베이스)와 Qwen2.5-0.5B-Instruct를 PC에서 실행. 두 모델에 채팅 형식의 같은 입력을 넣음 | 없음. 베이스 모델 약 1GB 추가 내려받기 |

시험 실행(2026-11-27, API 없음)에서 확인한 것:
- Qwen2.5-0.5B 베이스 모델은 질문을 넣으면 "- 전기전자뉴스 / 반도체 후공정에서 다이싱이란 무엇입니까? / …"처럼 질문을 되풀이했다.
- instruct 모델도 채팅 형식 없이 그냥 질문만 넣으면 웹 문서처럼 이어 썼다. 채팅 형식으로 넣었을 때만 답하는 형식이 나왔다. SFT가 "채팅 형식이 오면 답한다"를 학습시킨다는 근거로 쓴다.
- 베이스 모델에 "질문: … 답: …" 예를 하나 주면 답 형식을 따라 한 뒤 다음 "질문:"을 이어 썼다(실습 2-1).
- 틀린 문장의 손실이 맞는 문장과 같거나 낮았다(와이어 본딩: 맞는 문장 4.18, 틀린 문장 3.97).

## 개념 확인 실습

- **실습 2-1 베이스 모델에게 답하게 하기**: 베이스 모델에 "질문: … / 답: …" 예를 한두 개 앞에 붙이면 무엇을 생성할지 먼저 적고 실행한다. 답 형식을 따라 하는지, 답 뒤에 무엇을 이어 쓰는지 확인하고 이유를 사전 학습으로 설명한다. 빈칸: 예를 붙인 프롬프트를 만드는 함수.
- **실습 2-2 그럴듯함과 사실 구분해 보기**: 맞는 문장과 낱말 하나만 바꾼 틀린 문장을 직접 세 쌍 만들고, 어느 쪽의 손실이 낮을지 먼저 적은 뒤 `sentence_loss()`로 확인한다. 예측이 틀린 쌍이 있으면 "모델이 배운 것"으로 설명한다. 빈칸: `sentence_loss(text)`.

관통 프로젝트 단계는 없다(5장부터).

## 확인할 사실

1. SFT, RLHF: Ouyang 외, "Training language models to follow instructions with human feedback"(InstructGPT), 2022. 데이터 규모(SFT 약 1.3만 건 등)를 쓸지 확인.
2. DPO: Rafailov 외, "Direct Preference Optimization", 2023.
3. 환각의 원인: Kalai 외(OpenAI), "Why Language Models Hallucinate", 2025. "평가가 추측에 점수를 준다"는 주장을 원문으로 확인.
4. thinking 모델의 학습: DeepSeek-R1(DeepSeek-AI, 2025)의 검증 가능한 보상을 쓰는 강화 학습. OpenAI o1 발표(2024).
5. Claude의 thinking 토큰이 출력 토큰으로 계산되고, 기본 설정에서 내용이 응답에 보이지 않는다는 것(Anthropic 문서). Claude Haiku 5.5의 thinking 기본값(adaptive, effort medium).
6. 지식 기준일: Anthropic 모델 문서의 "reliable knowledge cutoff"와 "training data cutoff" 구분. 현행 모델의 값.
7. Qwen2.5의 사전 학습 규모(18조 토큰)와 베이스 모델, instruct 모델의 학습 단계: Qwen2.5 Technical Report(2024).

## 사용자에게 확인할 것

1. 베이스 모델(Qwen2.5-0.5B, 약 1GB)을 1장의 모델과 별도로 내려받는다.
2. 계산 한계(1일차 p.63~67)는 2장에서 빼고 13장 "AI 에이전트"의 도구 호출에서 다룬다. 2장에는 "숫자는 토큰으로 다뤄진다"는 1장의 설명을 가리키는 한 문장만 둔다.
3. API 호출은 예제 2-3의 2회와 준비 셀의 연결 확인 1회.
