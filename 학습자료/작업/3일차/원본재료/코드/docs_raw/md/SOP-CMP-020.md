# SOP-CMP-020 CMP 장비 가스라인 퍼지 표준작업지침

- 적용 장비: CMP 계열 전 호기 (예: CMP-02)
- 개정일: 2025-09-13 · 작성: 설비기술팀 임도현 · 승인: 파트장
- 등급: 사내 일반

## 목적
CMP 장비의 가스라인 퍼지 작업을 표준화하여 작업자 간 편차와 설비 사고를 방지한다.

## 절차
1. MFC 전량 폐쇄.
2. N2 치환 3회.
3. 잔압 확인.

## 주의 사항
- 작업 전 해당 호기의 인터락 상태를 반드시 확인해 주세요. 인터락이 걸린 상태에서
  임의 해제 후 작업하는 것은 금지되어 있습니다.
- 절차 중 이상 발견 시 즉시 작업을 중단하고 파트장에게 보고해 주세요.
- 본 지침과 장비 매뉴얼이 상충하는 경우 최신 개정본을 우선합니다.
