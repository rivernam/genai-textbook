GenAI Intensive 3일차 실습 미션 3 재료
새 문서 12건으로 RAG 만들고 버전 충돌 고치기

이 파일과 corpus_m3/ · corpus_m3_manifest.csv · corpus_m3_ext/ 는
3일차 실습 자료를 푼 폴더 안에 있어야 합니다. 실습 노트북
day03-lab.ipynb 의 「미션 3 준비」 셀 네 개와 도우미 셀을 실행한 뒤,
미션 셀 (a) (b) (c) 를 차례로 실행합니다. 셀의 코드는 모두 채워져
있습니다. 먼저 그대로 실행해 기본 결과를 보고, 바꿀 값을 아래 [3]
대로 고쳐 다시 실행한 뒤, 달라진 점을 노트북의 Q1 · Q2 답 셀에
적습니다. 확산 · 이온주입 라인의 가상 문서이고, 예제 corpus 253건과
겹치는 문서는 없습니다.

학습 목표
  1. 조립 셀의 문서 묶음을 바꿔 검색 → 프롬프트 → 답변을 새 문서로
     다시 이을 수 있다 (예제 3-1 (a))
  2. 프롬프트의 근거 없음 규칙을 넣고 뺐을 때 답과 진단 표가 어떻게
     달라지는지 설명할 수 있다 (예제 3-2 · 3-4)
  3. 같은 문서의 구판이 섞였을 때 진단 표로 알아보고, 구판 청크를
     색인에서 빼서 고칠 수 있다 (예제 3-3 (f) · 3-4 (c))

[3] 바꿔 보기와 질문
==========================================================================
바꿀 값은 둘입니다.
  (a) USE_RULE = True    근거 없음 규칙을 프롬프트에 넣을지
  (c) ADD_OLD = False    구판 SOP-DIFF-002 v1.0 을 색인에 함께 넣을지
(b) 는 질문 다섯 개라 Claude API 를 5번, (c) 는 2번(ADD_OLD = True
면 4번) 호출합니다. 답 문장은 실행마다 조금씩 다릅니다.

바꿔 보기 1  USE_RULE = False 로 고쳐 (a) (b) 를 실행합니다. 5번 질문의
             답과 진단 표의 「출처 표기」 · 「근거 없음」 칸을 처음
             결과와 비교합니다.
             본 뒤에는 바꿔 보기 2 첫 줄대로 USE_RULE 을 되돌리고
             (a) 를 다시 실행합니다.
바꿔 보기 2  USE_RULE = True 로 되돌려 (a) 를 실행하고, ADD_OLD = True
             로 고쳐 (c) 를 실행합니다. 발췌 네 칸의 판, 답의 허용 편차
             값과 출처, 진단 줄의 「같은 문서 여러 판」을 봅니다.
             (c) 는 구판을 넣은 결과를 보인 뒤 구판 청크를 빼고 한 번
             더 묻습니다.
되돌리기    USE_RULE = True · ADD_OLD = False 로 두고 (a) (b) (c) 를
             다시 실행합니다.

Q1. 근거 없음 규칙을 뺐을 때 5번 질문 「DIFF-07 호기 PM 요일은
    언제인가요?」의 답은 무엇이었고, 진단 표의 「출처 표기」 ·
    「근거 없음」 칸은 어떻게 바뀌었습니까? 규칙 문장이 없을 때 답이
    없는 질문을 진단 표로 골라낼 수 있는지, 운영에서 무엇이
    곤란해지는지 적어 주세요.
Q2. 구판을 함께 넣었을 때 「확산로 온도 프로파일 허용 편차는?」의 발췌
    네 칸에 v1.0 과 v2.0 이 각각 몇 칸 들어왔고, 답의 허용 편차 값과
    출처는 어떻게 바뀌었습니까? 답이 맞게 나왔더라도 구판을 색인에
    남겨 두면 안 되는 까닭을 발췌 칸 수를 근거로 적어 주세요.

확장 미션(선택): Claude Code 로 RAG 함수 만들기
==========================================================================
준비 (1) 조립 셀과 (a) 의 프롬프트가 하는 일, 곧 「검색 → 프롬프트
네 칸 → 답」을 함수 하나로 만들어 봅니다.
 1. 이 파일이 있는 폴더를 Claude Code 로 열고 아래 프롬프트를
    그대로 붙여 넣습니다. m3_rag.py 가 만들어집니다.
 2. 그 내용을 노트북의 확장 미션 3 빈 셀에 붙여 넣고 실행합니다.
 3. 「확장 3 비교」 셀이 기본 미션 (b) 의 질문 다섯 개를 내 함수로
    묻고(API 5번), 출처 · 근거 없음을 (b) 표와 나란히 찍습니다.
 4. 다른 곳이 있으면 함수의 어느 단계(자르기 · 검색 · 프롬프트)
    차이 때문인지 적습니다.
 함수를 처음 부를 때 색인을 만들므로 비교 셀에서 오류가 날 수 있습니다.
 오류 문장을 Claude Code 에 그대로 붙여 넣고 고쳐 달라고 한 뒤, 고친
 코드를 다시 붙여 넣어 두 셀을 다시 실행합니다. 이 확장에서는
 AttributeError: 'ThinkingBlock' object has no attribute 'text' 가
 자주 납니다. 응답의 첫 조각만 읽는 코드에서 나는 오류이니, 이
 문장을 그대로 붙여 고치면 됩니다.
 확장 코드를 붙인 뒤 기본 미션 3 을 다시 돌릴 때는 「미션 3 준비」
 셀부터 실행합니다.
