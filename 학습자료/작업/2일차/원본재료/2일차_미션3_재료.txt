GenAI Intensive 2일차 실습 미션 3 재료 · 현장 질문

실습 노트북(2일차_실습.ipynb)의 「미션 3 준비」 셀이 예제 3-2 · 3-3 의
docs · names · model · E · search() 를 다시 만듭니다.
아래 현장 질문 6개 가운데 1 · 4 · 5번 세 개가 「실습 미션 3 (1)」 셀에
1 · 2 · 3번으로 들어 있습니다. 질문마다 검색 1위 문서를 직접 열어 읽고,
그 질문에 답하는 문서인지 판정합니다.

================================================================
[1] 현장 질문 6개 · 노트북에서 쓰는 것은 1 · 4 · 5번
================================================================
0. 챔버 인터락이 걸리는 ESC 온도가 몇 도부터예요?
1. 칠러 유량이 얼마 이상이어야 정상인가요?              → 노트북 1번
2. 에치 장비 더미 웨이퍼 몇 장 돌리고 양산 넣어요?
3. RCP-ETCH-693 관리 한계
4. PHOTO-02 파티클이 올라서 필터를 바꾸기로 했다는데, 포토 시즈닝
   런은 원래 어떻게 하나요?                              → 노트북 2번
5. CMP-02 RCP-CMP-330 이탈 로트가 있었다는데, CMP 알람 뜨면 1차로
   뭘 봐야 하나요?                                       → 노트북 3번

노트북 2 · 3번은 질문 앞부분에 사례 이야기가 붙어 있습니다. 실제로
묻는 것은 뒷부분(시즈닝 런 절차 / 알람 1차 대응)입니다.
나머지 질문(0 · 2 · 3번)은 더 해 보고 싶을 때 같은 방법으로 써 봅니다.

================================================================
[2] 판정하는 법 · 기본 실행
================================================================
· 「실습 미션 3 (1)」 셀을 실행해 질문마다 1~3위 문서를 봅니다.
· 「실습 미션 3 (2)」 셀의 NAME 에 문서 이름을 넣어 문서 전체를 엽니다.
  제목만 보고 정하지 않고, 질문에 대한 답(수치 · 절차)이 본문에
  있는지 읽습니다.
· 판정이 어려우면 「실습 미션 3 (2-1)」 판정 도우미(선택)에 질문 번호와
  문서 이름을 넣습니다. 모델이 답할 수 있는지와 근거 문장을 돌려주니,
  그 문장이 문서에 정말 있는지 직접 확인하고 판정합니다.
· 답이 있으면 O, 없으면 X 로 정해 「실습 미션 3 (3)」 셀의 JUDGE 에
  질문 1~3 을 모두 적습니다.
· X 인 질문은 2 · 3위 문서도 열어 정답 문서가 몇 위에 있는지 RANK 에
  적습니다. 3위 안에 없으면 None 을 적습니다.

================================================================
[3] 바꿔 보기 · 처음에는 그대로 실행, 그다음 문장을 바꿔 다시 실행
================================================================
· 바꿔 보기 A: 2 · 3번 질문 앞의 사례 이야기를 지우고 다시 검색합니다.
  1위 문서가 무엇에서 무엇으로 바뀌었는지, 원래 1위 문서의 어느 낱말이
  질문과 겹쳤는지, 1위 말고 무엇을 더 확인할지 Q1 에 적습니다.
· 바꿔 보기 B: 1 · 3번 질문을 문서 말투로 바꿔 씁니다(예: 「CMP 장비
  알람 1차 대응」). 정답 문서의 순위가 몇 위에서 몇 위가 되었는지와
  1 · 2위 점수 차를 Q2 에 적습니다.

================================================================
[4] 지켜야 할 것
================================================================
· 기본 실행((1)~(3))에서는 질문 문장을 고쳐 쓰지 않습니다. 문장을 고쳐
  쓰는 것은 바꿔 보기 A · B 에서만 합니다.
· 점수가 높다고 O 로 적지 않습니다. 본문을 읽고 정합니다.

================================================================
[5] 제출
================================================================
미션 1 · 2 · 3 을 마친 노트북 하나를 [파일] → [다운로드] →
[.ipynb 다운로드] 로 받아, 이름을 아이디_2일차_실습미션.ipynb 로
바꾸고 zip 으로 묶어 휴넷 랩스에 올립니다.
노트북에는 판정 표 3줄((3) 셀 출력)과 Q1 · Q2 답이 남아 있어야 합니다.

================================================================
확장 미션 3(심화) · 기본 미션을 마친 분만 · 제출 의무 없음
================================================================
사내 문서 질의응답 도구를 PC 의 Claude Code 로 직접 만들어 봅니다.
목적: 현장 질문을 넣으면 사내 문서를 근거로 답하고, 어느 문서에서 나온
답인지 함께 보여 주는 도구입니다.
재료: corpus 폴더(문서 253건)와 corpus_manifest.csv 를 코랩 왼쪽 파일
패널에서 내려받습니다. 본인 업무 문서로 바꿔도 됩니다.
1. 어떤 단계로 만들지 먼저 짧게 메모합니다.
2. PC 작업 폴더에 재료를 넣고 Claude Code 에서 새 세션을 시작합니다.
3. 목적과 내 계획을 보내고, 결과를 보며 고쳐 달라고 요청합니다.
4. 다 만들면 노트북 「확장 미션 3」 아래 회고 답 셀에 적습니다.
