# 실습 환경 준비

2일차부터는 채팅 화면이 아니라 코드로 모델을 호출합니다. 이 장에서는 예제와 실습 노트북을 실행하는 데 필요한 것을 준비합니다.

## 준비물 {원본 p.11-14}

| 준비물 | 설명 |
| --- | --- |
| Python 3.10 이상과 Jupyter | 사내 PC의 Jupyter나 VS Code의 노트북에서 실행합니다 |
| `노트북` 폴더 | 학습 노트북과 실습 노트북, 공통 호출 함수 `llm.py`, 임베딩 모델(글을 벡터로 바꾸는 모델. 파트 3에서 설명합니다)을 불러오는 `embed.py`, 실습 테스트와 mock(파트 1에서 설명합니다)을 담은 `checks.py`, `checks2.py`, `checks3.py`, 재료 폴더 `data`가 들어 있습니다 |
| API 접근 정보 | Anthropic API 키, 또는 사내 LLM API의 주소, 키, 모델 이름 |

필요한 패키지는 다음 명령으로 설치합니다.

```bash
python -m pip install anthropic openai pandas pydantic openpyxl jupyter
```

## 교재와 학습 노트북 {추가}

같은 내용을 두 가지 형태로 제공합니다.

- **교재**(`교재/2일차.html`)는 브라우저로 읽습니다. 찾기와 용어 설명이 있고, 실행 환경이 없어도 볼 수 있습니다.
- **학습 노트북**은 파트마다 하나입니다(`노트북/2일차_01_LLM_API_기초.ipynb`, `노트북/2일차_02_구조화_출력과_시스템_연동.ipynb`, `노트북/2일차_03_RAG의_원리와_임베딩_검색.ipynb`). 교재와 같은 설명, 그림, 예제 코드가 순서대로 들어 있어, 읽으면서 바로 아래 셀을 실행합니다.

실행하며 학습하려면 학습 노트북 하나만 열면 됩니다. 교재와 노트북을 오갈 필요가 없습니다. 이 장의 API 키, 환경 변수, 연결 확인 내용도 학습 노트북과 실습 노트북의 "준비" 절에 들어 있습니다. 학습 노트북에는 미리 실행한 결과가 들어 있어, 실행하지 않고 읽기만 해도 됩니다. 준비 셀에는 결과가 들어 있지 않으므로 연결은 직접 실행해 확인합니다. 실습 노트북과 풀이 노트북도 파트마다 따로 있습니다.

## API 키 다루기 {원본 p.12}

[[API 키]]는 API를 호출한 사람을 식별하는 문자열입니다. 사용 기록과 요금은 키별로 집계됩니다. 키를 가진 사람은 누구나 그 키로 호출할 수 있고, 요금은 키의 주인에게 청구됩니다.

그래서 키는 코드에 적지 않습니다. 코드에 적은 키는 파일을 공유하거나 저장소에 올리는 순간 함께 퍼집니다. 키는 [[환경 변수]]에 두고 코드에서는 환경 변수를 읽습니다.

:::주의
키를 메신저, 화면 공유, 캡처 이미지에 노출하지 않습니다. 노출됐다면 바로 폐기하고 새로 발급받습니다.
:::

## 환경 변수 설정 {추가}

교재의 노트북은 `llm.py`를 통해 모델을 호출합니다. `llm.py`는 아래 환경 변수를 읽어 어느 API로 보낼지 고릅니다.

:::탭 Anthropic
| 환경 변수 | 값 |
| --- | --- |
| `ANTHROPIC_API_KEY` | 발급받은 키 |

모델 이름은 설정하지 않아도 됩니다. 소형, 기본, 대형 [[모델 등급]]에 현행 Claude 모델이 기본값으로 들어 있습니다(2026-11 기준 `claude-haiku-5-5`, `claude-sonnet-5-5`, `claude-opus-5-5`).
:::
:::탭 OpenAI 호환
| 환경 변수 | 값 |
| --- | --- |
| `LLM_PROVIDER` | `openai` |
| `OPENAI_BASE_URL` | 사내 API 주소. 보통 `/v1`로 끝납니다 |
| `OPENAI_API_KEY` | 사내 API 키 |
| `LLM_MODEL_SMALL` | 소형 모델 이름 |
| `LLM_MODEL_DEFAULT` | 기본 모델 이름 |
| `LLM_MODEL_LARGE` | 대형 모델 이름 |
| `LLM_STRUCTURED` | 구조화 출력을 요청하는 방식. 설정하지 않으면 `json_schema`입니다. 서버가 이 방식을 지원하지 않을 때만 바꿉니다(파트 2의 "구조화 출력" 절) |

사내에서 쓸 수 있는 모델이 하나뿐이면 세 변수에 같은 이름을 넣습니다. 그러면 모델 등급을 비교하는 예제에서는 차이가 나지 않습니다.
:::

환경 변수는 Jupyter를 시작하기 전에 설정합니다. `setx`로 설정한 값은 그 뒤에 새로 연 창에만 적용됩니다. Windows PowerShell에서 다음과 같이 설정한 뒤 터미널을 새로 열고, 그 터미널에서 Jupyter를 시작합니다. VS Code로 노트북을 연다면 VS Code 창을 모두 닫았다가 다시 엽니다.

Anthropic API를 쓸 때:

```powershell
setx ANTHROPIC_API_KEY "발급받은_키"
```

사내 API를 쓸 때(위 표의 나머지 변수도 같은 방법으로 설정합니다):

```powershell
setx LLM_PROVIDER openai
setx OPENAI_BASE_URL "사내_API_주소"
setx OPENAI_API_KEY "사내_API_키"
```

`setx`로 설정해 두면 모든 일자의 노트북에서 그대로 씁니다.

환경 변수를 미리 설정하지 못했다면 노트북의 "준비 (1)" 셀이 키, 주소, 모델 이름을 물어봅니다. 입력한 값은 화면에 보이지 않고 노트북 파일에도 저장되지 않습니다. 이 값은 커널이 살아 있는 동안만 쓰이므로, 노트북을 새로 열거나 커널을 다시 시작하면 다시 입력합니다. 단, 사내 API를 쓰려면 `LLM_PROVIDER=openai`만은 Jupyter를 시작하기 전에 설정해야 합니다. "준비 (1)" 셀이 이 값을 보고 어떤 값을 물을지 정하기 때문입니다. 이 값이 없으면 `llm.py`는 Anthropic API로 요청을 보냅니다.

## 연결 확인 {원본 p.21-24}

노트북을 `노트북` 폴더에서 열고 "준비 (1)", "준비 (2)" 셀을 차례로 실행합니다. 두 셀이 오류 없이 끝나고 마지막 줄에 모델의 응답(보통 `준비 완료`)이 나오면 연결된 것입니다. 응답 문구는 모델에 따라 조금 다를 수 있습니다.

:::결과
```
소형 모델: claude-haiku-5-5
기본 모델: claude-sonnet-5-5
대형 모델: claude-opus-5-5
준비 완료
```
:::

오류가 나면 아래 표에서 원인을 찾습니다.

| 나온 문구 | 원인과 조치 |
| --- | --- |
| `환경 변수 ...의 값이 비어 있습니다` | 환경 변수를 설정하지 않았습니다. 변수 이름의 철자를 확인하고 "준비 (1)" 셀을 다시 실행합니다 |
| `환경 변수 LLM_MODEL_...에 '소형' 모델 이름을 넣어 주세요` | 사내 API를 쓰는데 모델 이름을 비워 두었습니다. 커널을 다시 시작하고 "준비 (1)" 셀에서 모델 이름을 입력합니다 |
| `401 auth` | 키가 틀렸습니다. "준비 (1)" 셀은 값이 비어 있을 때만 묻습니다. 셀에서 입력했다면 커널을 다시 시작한 뒤 "준비 (1)" 셀에서 앞뒤 공백이나 따옴표 없이 다시 입력합니다. `setx`로 설정했다면 값을 다시 설정하고 Jupyter를 다시 시작합니다 |
| `403 permission` | 키에 그 모델이나 기능을 쓸 권한이 없습니다. 키를 발급한 곳에 권한을 확인합니다 |
| `404 not_found` | 모델 이름이나 API 주소가 틀렸습니다. 고치는 방법은 `401 auth`와 같습니다 |
| `connection` | 서버에 연결하지 못했습니다. 주소와 사내망 연결을 확인합니다 |
| `timeout` | 정해진 시간 안에 응답이 오지 않았습니다. 잠시 뒤 다시 실행합니다 |
| `NameError` | 앞 셀을 건너뛰었거나 커널을 다시 시작했습니다. 위에서부터 차례로 다시 실행합니다 |

## 임베딩 모델 준비 {추가}

파트 3은 임베딩 모델을 PC에서 실행합니다. 패키지 두 개를 더 설치합니다.

```bash
python -m pip install sentence-transformers scikit-learn
```

임베딩 모델(`intfloat/multilingual-e5-small`, 약 470MB)은 처음 실행할 때 한 번 내려받고, 그 뒤에는 PC에 저장된 파일을 씁니다. 사내에서는 Hugging Face에 직접 연결하지 않고 사내 Hugging Face 프록시에서 내려받습니다. 프록시 주소는 사내 안내에서 확인해 아래 환경 변수에 넣습니다. 이 교재에는 주소를 적지 않습니다.

| 환경 변수 | 값 |
| --- | --- |
| `HF_ENDPOINT` | 사내 Hugging Face 프록시 주소. `https://`로 시작하는 주소 전체를 넣습니다. 설정하지 않으면 `huggingface.co`에서 받습니다 |
| `EMBED_MODEL` | 설정하지 않아도 됩니다. 다른 임베딩 모델을 쓰거나 모델 파일이 든 폴더를 따로 받았을 때, 모델 이름이나 폴더 경로를 넣습니다 |

환경 변수는 Jupyter를 시작하기 전에 설정합니다. 앞의 API 키와 같이, 설정한 뒤 터미널을 새로 열고 그 터미널에서 Jupyter를 시작합니다.

```powershell
setx HF_ENDPOINT "사내_프록시_주소"
```

모델이 PC에 없고 `HF_ENDPOINT`도 설정하지 않았으면, 모델을 처음 불러오는 셀(`embed.load()`)이 주소를 물어봅니다. 입력한 주소는 화면에 보이지 않고 노트북 파일에도 저장되지 않습니다. 이 값은 커널이 살아 있는 동안만 쓰입니다. 모델이 이미 PC에 있으면 묻지 않습니다.

모델을 불러오는 셀에서 오류가 나면 아래에서 원인을 찾습니다.

| 나온 문구 | 원인과 조치 |
| --- | --- |
| `임베딩 모델 ...을 내려받지 못했습니다` | 프록시 주소가 틀렸거나 사내망에 연결되지 않았습니다. `HF_ENDPOINT`의 값을 확인하고 Jupyter를 다시 시작합니다 |
| `HF_ENDPOINT는 Jupyter를 시작하기 전에 설정해야 합니다` | 같은 커널에서 Hugging Face 라이브러리를 이미 불러온 뒤에 주소를 입력했습니다(예: 다른 모델을 먼저 불러온 경우). 라이브러리는 처음 불러올 때 읽은 주소만 씁니다. 환경 변수 `HF_ENDPOINT`를 설정하고 Jupyter를 다시 시작합니다 |
| `sentence-transformers 패키지가 없습니다` | 패키지를 설치하지 않았습니다. 위의 설치 명령을 실행한 뒤 커널을 다시 시작합니다 |

## 준비 셀이 만들어 두는 이름 {추가}

"준비 (1)", "준비 (2)" 셀은 연결을 확인하면서 예제가 공통으로 쓰는 이름도 정의합니다. 교재의 예제 코드에 아래 이름이 정의 없이 나오면 준비 셀에서 정의한 것입니다.

| 이름 | 내용 |
| --- | --- |
| `llm` | 공통 호출 함수가 든 모듈(`llm.py`)입니다 |
| `os`, `json`, `time`, `pd`, `ThreadPoolExecutor` | 파이썬 표준 라이브러리와 pandas입니다 |
| `DATA` | 재료 폴더의 경로(`data/2일차`)입니다 |
| `SYSTEM` | 문의를 다섯 가지로 분류하는 규칙 파일(`분류_규칙.txt`)의 내용입니다. 파트 1의 "시스템 프롬프트" 절부터 시스템 프롬프트로 씁니다 |
| `PRICE`, `cost_usd()` | 모델 등급별 단가와, 토큰 수로 요금(달러)을 계산하는 함수입니다 |
