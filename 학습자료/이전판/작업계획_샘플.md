# 복습 교재 샘플(2일차 파트 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 2일차 파트 1 "LLM API 기초"(원본 p.11–175)를 대상으로 작성규칙·용어집·원고·HTML 교재·예제/실습 노트북·재료를 한 벌 만들어, 사용자가 방향을 검토하고 확정할 수 있게 한다.

**Architecture:** 원본 PDF를 쪽 단위 텍스트와 이미지로 뽑아 분석하고, 학습 목표를 먼저 정한 뒤 그 목표에 맞춰 개념 설명(Markdown 원고)과 예제·실습(노트북)을 새로 쓴다. `build.py`가 원고와 용어집을 읽어 외부 의존 없는 HTML 한 파일을 만든다. 모델 호출은 Anthropic과 OpenAI 호환 두 경로를 지원한다.

**Tech Stack:** Python 3.11, `markdown`, `pygments`, `nbformat`, `pypdfium2`, `anthropic`, `openai`, `sentence-transformers`(파트 1에서는 미사용), `pytest`.

**Spec:** `학습자료/설계서.md`

## Global Constraints

- 원본 폴더(`GenAI_N일차_배포용/`)는 읽기만 한다.
- 모든 결과물은 `학습자료/` 아래에 둔다. 이 폴더는 git 저장소가 아니므로 커밋 단계는 없다.
- 최우선 기준: 생성형 AI 개념이 잘 설명되어야 한다. 원본에 없어도 필요한 내용은 추가하고, 틀린 내용은 고치고, 필요 없는 내용은 삭제한다.
- 추가·정정한 사실은 확신할 수 없으면 공식 문서로 확인한다. 확인하지 못하면 싣지 않는다. 모델 이름·요금·API 파라미터는 확인 날짜를 적는다.
- 실행 결과는 실제로 실행해 얻은 값만 싣는다. 실행하지 못하면 "미실행"으로 표시한다.
- 새 재료는 지어낸 가상 데이터만 쓴다.
- 문체는 합니다체. 용어는 `용어집.md`의 채택 표기만 쓴다.
- API 키·사내 주소·사내 모델명은 어떤 파일에도 적지 않는다. 환경 변수로만 읽는다.
- 교재 HTML은 외부 CDN·폰트·이미지를 참조하지 않는다.
- Anthropic API를 부르는 코드를 쓰기 전에 `claude-api` 스킬을 읽어 현재 모델 ID·파라미터·요금을 확인한다.
- API 실행 비용을 줄인다: 가능한 한 소형 모델과 적은 건수로 실행하고, 샘플 전체의 실제 사용 토큰과 요금을 마지막 보고에 적는다.

### Task 4: 공통 호출 함수 `llm.py`

**Files:**
- Create: `학습자료/노트북/llm.py`, `학습자료/tests/test_llm.py`

**Interfaces:**
- Produces:

```python
@dataclass
class Reply:
    text: str
    input_tokens: int | None
    output_tokens: int | None
    stop_reason: str          # 'end' | 'max_tokens' | 'other'
    model: str
    seconds: float

def model_name(alias: str) -> str            # alias: '소형' | '기본' | '대형'
def ask(prompt: str, *, system: str | None = None,
        history: list[dict] | None = None,   # [{'role': 'user'|'assistant', 'content': str}]
        model: str = '기본', max_tokens: int = 1024,
        timeout: float = 60.0) -> Reply
```

- 환경 변수: `LLM_PROVIDER`(`anthropic` 기본 / `openai`), `ANTHROPIC_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `LLM_MODEL_SMALL`, `LLM_MODEL_DEFAULT`, `LLM_MODEL_LARGE`. Anthropic 경로의 모델 기본값은 `claude-api` 스킬에서 확인한 현재 ID를 쓴다. OpenAI 경로는 기본값이 없다.

- [ ] **Step 1:** 테스트 작성(네트워크 없이, SDK 클라이언트를 가짜로 바꿔서):
  - Anthropic 경로: `system`·`history`·`prompt`가 `messages.create` 인자로 올바르게 들어가고, `Reply`의 여섯 필드가 채워진다.
  - OpenAI 경로: `system`이 첫 메시지(`role='system'`)로 들어가고, `finish_reason='length'`가 `stop_reason='max_tokens'`로 바뀐다.
  - OpenAI 응답에 `usage`가 없으면 토큰 두 값이 `None`이다.
  - `LLM_PROVIDER=openai`인데 `OPENAI_BASE_URL`이 없으면 `RuntimeError`가 나고 메시지에 `OPENAI_BASE_URL`이 들어 있다. `ANTHROPIC_API_KEY`가 없을 때도 같다.
  - `LLM_PROVIDER`가 다른 값이면 `ValueError`.
  - `model_name('없는별칭')`은 `ValueError`.
- [ ] **Step 2:** 실패 확인: `python -m pytest 학습자료/tests/test_llm.py -v`
- [ ] **Step 3:** `llm.py` 구현.
- [ ] **Step 4:** 통과 확인.
- [ ] **Step 5:** OpenAI 경로 형식 확인: 표준 라이브러리 `http.server`로 `/v1/chat/completions`에 고정 응답을 주는 로컬 가짜 서버를 테스트 안에서 띄우고, 실제 `openai` 클라이언트로 `ask()`가 끝까지 도는지 확인하는 테스트를 추가해 통과시킨다.
- [ ] **Step 6:** `ANTHROPIC_API_KEY`가 설정되어 있으면 `ask('한 문장으로 인사해 주세요', model='소형', max_tokens=50)`을 한 번 실제로 실행해 `Reply`를 출력한다. 없으면 사용자에게 설정을 요청하고 Task 6의 실행 단계를 보류한다.

### Task 7: `build.py`와 교재 화면

**Files:**
- Create: `학습자료/build.py`, `학습자료/교재_템플릿/page.html`, `학습자료/교재_템플릿/style.css`, `학습자료/교재_템플릿/app.js`, `학습자료/tests/test_build.py`

**Interfaces:**
- Consumes: `원고/N일차/NN_*.md`(`NN_분석.md` 제외), `용어집.md`.
- Produces: `python 학습자료/build.py` → `학습자료/교재/index.html`, `학습자료/교재/N일차.html`. 실패하면 0이 아닌 종료 코드와 `파일:줄` 위치를 출력한다.
- 원고 문법(Markdown에 더해):
  - `[[용어]]` → 용어집 정의가 뜨는 링크
  - `:::예제 1-1-2` … `:::` → 예제 상자(실행 위치 표시 포함)
  - `:::결과` … `:::` → 실행 결과 상자
  - `:::정답` … `:::` → 접히는 정답
  - `:::탭 Anthropic` / `:::탭 OpenAI 호환` → 나란히 전환되는 코드 탭
  - `:::주의`, `:::보충` → 강조 상자
  - 절 제목 뒤 `{원본 p.60-62}` 또는 `{추가}` → 출처 표시

- [ ] **Step 1:** 테스트 작성(임시 폴더의 작은 원고로):
  - 위 일곱 가지 문법이 각각 정해진 class의 HTML 요소로 바뀐다.
  - 용어집에 없는 `[[용어]]`가 있으면 빌드가 실패하고 출력에 파일 이름과 줄 번호가 있다.
  - 없는 절을 가리키는 내부 링크가 있으면 빌드가 실패한다.
