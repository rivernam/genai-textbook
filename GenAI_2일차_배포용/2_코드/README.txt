GenAI Intensive 2일차 실습 재료 · 2_코드 폴더 안내

예제는 2일차_예제.ipynb, 실습 미션 1 · 2 · 3 은 2일차_실습.ipynb 에서 합니다. 두 노트북은 아래 코랩 링크로 열고, 첫 「환경 준비」 셀이 학습 사이트에서 day02-data.zip 을 받아 풉니다. 미션마다 기본 실행 → 바꿔 보기 A · B(✏️ 칸을 처음에는 그대로 실행하고, 그다음 값을 바꿔 다시 실행) → Q1 · Q2(Q 문항 아래 답 셀에 적음) 순서로 진행합니다. 확장 미션(심화)은 기본 미션을 마친 분이 목적만 받고 PC 의 Claude Code 로 직접 만들어 본 뒤, 노트북의 회고 답 셀에 적습니다.

| 파일 | 내용 | 미션 |
| --- | --- | --- |
| 2일차_예제.ipynb | 강의안 예제 1-1 ~ 3-3 의 셀 | 예제 |
| 2일차_실습.ipynb | 실습 미션 1 · 2 · 3 · 바꿔 보기 · Q1 · Q2 · 확장 미션 회고(답 셀은 비어 있음) | 1 · 2 · 3 |
| day02-data.zip | 2일차_미션1_재료.csv(문의 60건) · 2일차_미션2_재료.csv(접수 본문 80건) · 2일차_미션3_재료.txt(현장 질문 6개 중 노트북에서 쓰는 3개 · 판정법 · 제출) · inquiries_120.csv · corpus(문서 253건) · corpus_manifest.csv · day02-cc 폴더 | 예제 · 1 · 2 · 3 |

확장 미션은 정해진 프롬프트 없이 노트북의 목적 · 재료 · 생각해 볼 것을 보고 직접 만듭니다.
코랩에 day02-cc 폴더가 없으면 배포용 zip 의 day02-cc 를 코랩 왼쪽 파일 패널에 올립니다.
