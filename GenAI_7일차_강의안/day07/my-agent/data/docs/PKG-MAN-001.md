# PKG-MAN-001 장비 매뉴얼 발췌 — 와이어 본더 캐필러리 점검

- 원본: 제조사 유지보수 매뉴얼 발췌 · 적용 설비: WB-01 ~ WB-05 · 등급: 사내 일반

## 정기 점검 항목
- 캐필러리 끝단 마모와 이물 부착을 교대마다 현미경으로 확인합니다.
- 캐필러리는 본딩 120만 회마다 교체합니다. 본딩 횟수는 설비 화면의 카운터로 확인합니다.
- 교체 후에는 테스트 본딩 20회를 하고 볼 지름과 접합 강도를 확인합니다.

## 이상 징후
- 볼 모양이 찌그러지거나 테일 길이가 들쭉날쭉하면 교체 주기 전이라도 교체를 검토합니다.
