# PKG-SOP-002 백그라인더 휠 교체 절차

- 적용 설비: BG-01 ~ BG-03
- 개정일: 2025-08-18 (v1.0) · 작성: 후공정 설비기술팀

## 절차
1. PKG-EHS-001 에 따라 LOTO 를 적용합니다.
2. 휠 커버를 열고 휠 고정 볼트를 대각선 순서로 풉니다.
3. 새 휠을 장착하고 볼트를 대각선 순서로 조입니다.
4. 커버를 닫고 LOTO 를 해제합니다.

## 교체 뒤 확인
- 휠 교체 후 하이트 체크를 하고 값을 설비 이력에 남깁니다.
- 더미 웨이퍼 1장을 연삭해 두께 편차를 확인합니다.
