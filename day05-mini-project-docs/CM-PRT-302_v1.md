# CM-PRT-302 CP-3 CMP 장비 핵심 부품 수명 관리 기준표
- 문서번호: CM-PRT-302
- 판: v1
- 시행일: 2025-06-07
- 종류: 부품 교체 기준표

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위

이 기준표는 한결반도체 2팹 설비지원센터가 운영하는 화학 기계 연마(CMP, Chemical Mechanical Planarization) 장비 CP-3(모델 PL-300)의 핵심 소모 부품 여섯 종에 적용한다. 문서번호는 CM-PRT-302이며, 2025-06-07부터 CMP 파트 엔지니어와 협력 정비 인원이 같은 기준으로 부품을 교체하도록 하는 것을 목적으로 한다. 이 장비에서 발생하는 헤드 압력 이상 알람 P3-0417은 조기 교체를 판단하는 근거이므로 3절에서 함께 다룬다. 일반 소모품(와이퍼, 장갑 등)과 장비 개조를 수반하는 부품 변경은 대상이 아니다. 개조는 변경 관리 시스템 CMS를 통해 별도로 처리한다.

## 2. 부품별 교체 주기

이 장비의 핵심 부품은 아래 표의 주기에 따라 교체한다. 한 부품에 기준이 둘이면 먼저 도달하는 쪽을 따른다.

| 부품 | 정기 교체 기준 | 사전 알림 시점 |
|---|---|---|
| 연마 패드 | 누적 연마 1,150장 또는 사용 96시간 | 920장 |
| 컨디셔너 디스크 | 누적 컨디셔닝 310시간 | 250시간 |
| 리테이너 링 | 가동 520시간 또는 잔여 두께 1.85 mm 이하 | 420시간 |
| 캐리어 멤브레인 | 가동 780시간 | 620시간 |
| 슬러리 라인 필터 | 14일 또는 전후 차압 0.18 MPa 초과 | 11일 |
| 슬러리 펌프 튜브 | 45일 | 36일 |

누적값은 설비 이력 시스템 EQ-LOG에 쌓인 가동 기록을 기준으로 계산하며, 담당 엔지니어가 수기로 따로 세지 않는다. 사전 알림은 기준값의 약 80%에 도달하면 CMP 파트 담당자에게 자동으로 발송된다. 알림을 받은 담당자는 교체 일정을 잡고 재고를 확인한다. 정기 교체 기준은 원칙적으로 연장하지 않는다. 다만 생산 일정 때문에 불가피하면 파트장이 승인하여 기준값의 5% 이내에서 1회에 한해 연장할 수 있다.

## 3. 조기 교체 조건

아래 중 하나에 해당하면 정기 주기와 관계없이 해당 부품을 조기 교체 대상으로 본다.

1. 이 알람이 24시간 안에 3회 이상 발생한 경우. 헤드 압력 계통의 리테이너 링과 캐리어 멤브레인을 우선 점검한다.
2. 웨이퍼 한 장당 스크래치가 12개를 넘는 결과가 연속 2롯(lot, 생산 묶음 단위) 나온 경우. 연마 패드와 컨디셔너 디스크를 우선 점검한다.
3. 재측정 후에도 연마 제거율이 기준 대비 ±8%를 벗어나는 경우.
4. 부품에 균열, 변형, 슬러리 고착 등 외관 이상이 육안으로 확인된 경우.

조기 교체 여부는 CMP 파트장이 판단한다. 판단 즉시 품질팀(내선 7600)에 해당 롯의 격리 여부를 문의하고, 설비지원센터장에게 승인을 요청한다. 센터장은 요청을 받은 때로부터 4시간 이내에 승인 또는 반려를 회신한다. 회신이 늦어져도 외관 파손처럼 안전과 직결된 경우에는 파트장이 장비를 먼저 정지시킬 수 있으며, 이때 사후 승인을 받는다.

## 4. 교체 절차 요약

교체는 다음 순서로 진행한다.

1. 담당 엔지니어가 EQ-LOG에서 교체 작업 건을 열고, 장비를 유지보수 모드로 전환한다.
2. 슬러리 공급을 차단하고 라인을 탈이온수로 10분간 헹군다. 슬러리 접촉 부품은 방호복과 보안경을 착용한 뒤 만진다.
3. 기존 부품을 분리하고 장착면의 잔여물을 제거한다. 신품은 로트 번호와 유효기한을 확인한 뒤 장착한다.
4. 연마 패드와 컨디셔너 디스크를 교체했으면 패드 길들이기(브레이크인)를 30분 수행한다.
5. 시험 연마 웨이퍼 3장을 처리하고 제거율, 균일도, 스크래치 수를 측정한다. 세 장 모두 규격 안에 들면 파트장이 장비를 생산에 복귀시킨다.
6. 사용한 슬러리와 세정액은 안전환경팀 기준에 따라 분리 배출한다. 누출이나 피부 접촉 사고가 나면 안전환경팀 비상 내선 7119로 즉시 알린다.

시험 연마에서 한 장이라도 규격을 벗어나면 같은 조건으로 추가 2장을 처리한다. 그래도 벗어나면 설비지원센터 당직(내선 7700)에 보고하고 장착 상태를 재점검한다.

## 5. 재고와 발주 기준

이 장비의 부품은 자재 창고(내선 7720)에서 보관하며, 아래 안전재고 이하로 내려가면 발주한다.

| 부품 | 안전재고 |
|---|---|
| 연마 패드 | 4장 |
| 컨디셔너 디스크 | 2개 |
| 리테이너 링 | 2개 |
| 캐리어 멤브레인 | 2개 |
| 슬러리 라인 필터 | 6개 |
| 슬러리 펌프 튜브 | 3개 |

재고가 안전재고 이하가 되면 담당 엔지니어는 영업일 2일 이내에 자재 시스템 MAT-ON으로 발주를 요청한다. 연마 패드와 리테이너 링은 납품까지 평균 21일이 걸리므로, 사전 알림을 받는 즉시 재고 수량을 확인하고 부족하면 바로 요청한다. 조기 교체로 재고가 한꺼번에 줄어든 경우에는 자재팀에 긴급 발주를 요청하고, 자재 창고에 수령 예정일을 문의한다. 신품은 입고 시 유효기한이 6개월 이상 남은 것만 받으며, 이보다 짧으면 반품한다.

## 6. 교체 기록

교체를 마친 담당 엔지니어는 작업 종료 후 24시간 이내에 EQ-LOG에 아래 항목을 입력한다.

- 교체 부품명과 신품 로트 번호
- 교체 사유(정기 또는 조기)와, 조기 교체라면 3절의 해당 조건 번호
- 교체 직전 누적 사용량(장수 또는 시간)
- 시험 연마 3장의 측정 결과
- 작업자, 확인한 파트장, 센터장 승인 시각(조기 교체인 경우)

입력한 기록은 파트장이 다음 영업일 안에 확인하고 서명한다. 기록은 3년간 보관하며, 품질팀 감사나 고객 요청이 있으면 열람할 수 있게 둔다. 교체한 부품은 마모 상태 분석이 필요할 수 있으므로 지정 선반에 7일간 보관한 뒤 폐기한다. 조기 교체 부품은 원인 분석이 끝날 때까지 폐기하지 않는다. 기록 누락이나 입력 오류는 설비 상황실(내선 7701)에 알려 정정한다.
