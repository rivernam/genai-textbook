# CM-ALM-105 CP-3 CMP 장비 패드 온도 상승 알람(코드 C833) 조치 가이드
- 문서번호: CM-ALM-105
- 판: v1
- 시행일: 2024-08-14
- 종류: 알람 조치 가이드

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위와 알람 조건

이 문서는 화학적 기계적 연마(CMP, Chemical Mechanical Polishing) 장비 CP-3(모델 PL-300)에서 발생하는 패드 온도 상승 알람(코드 C833)의 조치 방법을 정한다. CMP 파트 엔지니어와 설비지원센터 당직자가 대상이며, 연마 패드와 냉각 계통에서 발생한 온도 이상에만 적용한다.

이 알람은 연마 레시피를 실행하는 동안 패드 표면 온도가 58.0℃ 이상으로 20초 연속 유지되면 발생한다. 52.0℃ 이상이면 알람 전 단계로 화면에 노란색 경고가 표시되며, 이때는 장비가 멈추지 않는다. 대기 상태에서는 온도를 판정하지 않는다.

## 2. 증상

이 알람이 발생하면 다음 현상이 나타난다.

- 조작 화면에 적색 알람 문구가 표시되고, 인터락(연동 정지 장치)이 작동하여 플래튼 회전이 멈춘다.
- 웨이퍼 헤드가 자동으로 상승하고, 진행 중이던 로트는 일시 정지 상태가 된다.
- 알람 직전 연마 속도가 평소보다 빠르거나 불안정하다.
- 패드 표면이 번들거리거나 슬러리에 거품이나 변색이 보인다.

## 3. 추정 원인

원인은 발생 빈도가 높은 순서로 아래와 같이 본다.

| 순번 | 추정 원인 | 확인 부위 |
|---|---|---|
| 1 | 냉각수 유량 부족 또는 공급 온도 상승 | 플래튼 냉각 라인, 필터 |
| 2 | 슬러리 공급 유량 저하 | 공급 펌프, 노즐 막힘 |
| 3 | 패드 노후 또는 컨디셔닝 불량 | 패드 누적 사용 시간, 컨디셔너 디스크 |
| 4 | 온도 센서 렌즈 오염 또는 측정 오차 | 적외선 센서 |
| 5 | 하향 압력이나 회전수를 높인 레시피 변경 | 변경 관리 시스템(CMS) 이력 |

## 4. 조치 절차

1. 알람 발생 시각과 진행 중이던 로트 번호를 설비 이력 시스템(EQ-LOG)에 기록하고, 후속 로트 투입을 중지한다.
2. 웨이퍼 헤드에 웨이퍼가 남아 있는지 확인하고, 헤드가 상승한 상태에서 로더로 회수한다. 웨이퍼가 깨졌으면 파편을 수거하기 전에 당직(내선 7700)에 알린다.
3. 패드 온도가 45.0℃ 이하로 내려갈 때까지 최소 10분 동안 자연 냉각한다.
4. 냉각수 공급 온도가 18~22℃, 유량이 4.5 L/min 이상인지 확인한다. 기준에 못 미치면 라인 필터를 점검하고 막혔으면 교체한다.
5. 슬러리 유량이 180±10 mL/min인지 확인하고, 벗어나면 노즐을 세척한 뒤 다시 측정한다.
6. 온도 센서 렌즈를 전용 와이퍼로 닦고 기준 온도계와 비교한다. 오차가 ±1.0℃를 넘으면 교정을 의뢰한다.
7. 패드 누적 사용 시간이 700시간을 넘었으면 패드와 컨디셔너 디스크 교체를 요청한다. 소모품 교체와 불출은 CM-PRT-301 문서를 따르며, 재고는 자재 창고(내선 7720)에 문의한다.
8. 조치를 마치면 알람을 해제하고, 더미 웨이퍼로 연마 시험을 한다.

## 5. 복구 확인 기준

아래 조건을 모두 만족해야 복구로 인정한다.

| 항목 | 기준 |
|---|---|
| 더미 웨이퍼 연속 연마 | 3매 연속 알람 없음 |
| 연마 중 패드 최고 온도 | 50.0℃ 미만 |
| 연마 제거율 편차 | 기준 대비 ±3% 이내 |
| 재발 관찰 | 복구 후 24시간 동안 알람 재발 없음 |

복구 후 첫 제품 로트는 품질팀(내선 7600)이 두께 측정 결과를 확인한 뒤 다음 공정으로 보낸다.

## 6. 안전 주의

- 알람 직후 패드와 플래튼 표면은 뜨거울 수 있다. 45.0℃ 이하임을 확인하기 전에는 맨손으로 만지지 않고 내열 장갑을 낀다.
- 슬러리는 피부와 눈을 자극한다. 보안경, 내화학 장갑, 방호복을 착용한다. 눈이나 피부에 닿으면 즉시 흐르는 물로 15분 이상 씻고 안전환경팀 비상 번호(내선 7119)로 연락한다.
- 냉각 라인을 열거나 필터를 교체할 때는 잠금·표지(LOTO, Lock-Out Tag-Out) 절차를 먼저 하고, 배관 안의 잔압을 빼낸다.
- 바닥에 냉각수나 슬러리가 샜으면 전기 장치에서 먼저 떨어지고, 미끄럼 주의 표지를 세운 뒤 닦는다.
- 작업은 2인 1조로 한다.

## 7. 보고와 에스컬레이션

알람이 발생하면 먼저 설비지원센터 당직(내선 7700)에 알리고, 15분 안에 CMP 파트장에게 보고한다. 알람이 1시간 안에 3회 이상 반복되면 이 장비를 가동 중지하고 파트장에게 알린다. 이어서 설비지원센터장에게 2단계로 보고한다. 파트장의 1차 승인과 센터장의 2차 승인을 모두 받기 전에는 재가동하지 않는다.

알람 시점에 진행 중이던 로트가 2개 로트 이상이면 품질팀(내선 7600)에 알려 보류(hold) 여부를 판정받는다. 상황 전파가 필요하면 설비 상황실(내선 7701)로 연락한다. 웨이퍼 파손이나 화학물질 누출이 함께 일어났으면 안전환경팀(내선 7119)에도 즉시 알린다.

조치를 마치면 담당 엔지니어가 아래 항목을 기록한다.

| 기록 항목 | 기록 위치 | 기한 |
|---|---|---|
| 알람 발생 시각, 로트 번호, 조치 내용 | EQ-LOG | 조치 종료 후 24시간 이내 |
| 측정값(냉각수 온도·유량, 슬러리 유량, 패드 온도) | EQ-LOG 점검 표 | 조치 당일 |
| 센서 교정이나 패드 교체 이력 | EQ-LOG, 자재 시스템 MAT-ON | 작업 후 24시간 이내 |
| 레시피나 설정값 변경 | CMS 변경 요청 | 변경 전 |

기록은 3년 동안 보존한다. 같은 원인이 한 달 안에 두 번 이상 반복되면 CMP 파트장이 근본 원인 분석 결과를 첨부하여 다음 달 첫 주 안에 설비지원센터장에게 제출한다.
