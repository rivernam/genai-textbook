# CL-PRT-302 WS-5 세정 장비 핵심 부품 수명 관리 기준표
- 문서번호: CL-PRT-302
- 판: v1
- 시행일: 2025-09-26
- 종류: 부품 교체 기준표

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위

이 기준표는 한결반도체 2팹 설비지원센터가 관리하는 세정 장비 WS-5(모델 CL-80)의 핵심 부품 다섯 종에 적용한다. 대상은 약액 순환 펌프 다이어프램, 약액 필터 카트리지, 석영 히터, 스프레이 노즐, 이송 로봇 벨트이다. 부품 수명은 달력 기간과 누적 사용량 중 먼저 도래하는 쪽을 기준으로 정한다. 약액 필터의 차압 상승 알람 W5-F214가 발생했을 때의 대응도 이 문서(CL-PRT-302)에서 정한다. 와이퍼나 일반 튜브 같은 소모품, 그리고 부품 사양을 바꾸는 개조는 이 문서의 대상이 아니다. 개조는 변경 관리 시스템(CMS, Change Management System)의 절차를 따른다.

## 2. 부품별 교체 주기

대상 부품의 교체 주기는 다음 표와 같다. 사용량과 기간 중 하나라도 먼저 도달하면 교체 대상이 된다.

| 부품 | 부품 코드 | 교체 주기 |
|---|---|---|
| 약액 순환 펌프 다이어프램 | RP-11 | 누적 가동 4,200시간 또는 12개월 |
| 약액 필터 카트리지(0.02 µm) | FL-07 | 90일 또는 차압 0.18 MPa |
| 석영 히터 | HT-31 | 누적 가열 9,000시간 또는 30개월 |
| 스프레이 노즐 | NZ-05 | 웨이퍼 85만 매 또는 24개월 |
| 이송 로봇 벨트 | BT-02 | 웨이퍼 120만 매 또는 18개월 |

설비 이력 시스템(EQ-LOG)은 교체 주기 도래 14일 전에 세정 파트에 예고 알림을 보낸다. 주기가 지난 부품은 최대 72시간까지만 더 사용할 수 있다. 이 유예에는 설비지원센터장의 사전 승인이 필요하며, 유예 기간 중에는 하루 두 번 상태를 점검한다.

## 3. 조기 교체 조건

다음 중 하나라도 확인되면 주기와 관계없이 해당 부품을 조기 교체한다.

1. 필터 차압이 0.18 MPa 이상이 되어 이 알람이 발생하면 8시간 이내에 필터 카트리지를 교체한다.
2. 펌프 토출 압력이 정상 범위에서 ±12% 넘게 벗어난 상태가 3회 연속 측정되면 다이어프램을 교체한다.
3. 히터의 절연 저항이 5 MΩ 미만이면 즉시 가열을 중지하고 히터를 교체한다.
4. 노즐 분사 균일도 편차가 7%를 넘는 측정이 2회 연속 나오면 노즐을 교체한다.
5. 벨트 장력이 기준값 38 N에서 ±15% 넘게 벗어나거나 웨이퍼 위치 편차가 0.3 mm를 넘으면 벨트를 교체한다.
6. 약액 누출 흔적이 있거나 부품 표면에 균열이 보이면 사용량과 관계없이 즉시 교체한다.

조기 교체를 결정하면 담당 파트는 4시간 이내에 품질팀(내선 7600)에 사유를 통보한다.

## 4. 교체 절차 요약

1. 세정 파트 담당자가 EQ-LOG에 부품 교체 작업 요청서를 등록한다.
2. 주기 도래에 따른 교체는 파트장이 승인한다. 조기 교체와 72시간 유예는 파트장 승인 후 설비지원센터장이 추가로 승인한다.
3. 작업 전에 약액 라인을 배출하고 잠금·표지(LOTO, Lockout/Tagout)를 건다. 약액 온도가 40℃ 이하임을 확인한 뒤 작업한다. 히터는 가열 중지 후 2시간 이상 냉각한 다음 분리한다. 약액이 피부나 눈에 닿으면 안전환경팀 비상 번호 7119로 연락한다.
4. 신품은 포장 상태와 로트 번호를 확인한 뒤 장착하고, 로트 번호를 작업 요청서에 적는다.
5. 장착 후 30분간 누설 시험을 하고, 시험 웨이퍼 3매를 처리해 입자 수가 기준 이내인지 확인한다. 품질팀 담당자가 결과에 서명하면 이 장비를 생산에 복귀시킨다.

## 5. 재고와 발주 기준

각 부품의 안전 재고는 다이어프램 2세트, 필터 카트리지 6개, 히터 1개, 노즐 4개, 벨트 1개이다. 재고가 안전 재고 이하로 내려가면 자재 시스템(MAT-ON)이 자동으로 발주 요청을 만든다. 자재팀은 요청을 받은 날부터 3영업일 이내에 발주를 확정한다. 일반 부품의 조달 기간은 21일, 석영 히터는 42일을 기준으로 하므로, 히터는 재고가 1개 남았을 때 바로 발주한다. 필터 카트리지는 입고 후 보관 기간이 12개월을 넘으면 사용하지 않고 반품하거나 폐기한다. 부품 불출과 재고 문의는 자재 창고(내선 7720)로 한다. 긴급 교체에 필요한 부품이 창고에 없으면 설비지원센터 당직(내선 7700)이 자재팀과 협의해 대체 조달 여부를 정한다.

## 6. 교체 기록

교체를 마친 담당자는 24시간 이내에 EQ-LOG에 다음 항목을 입력한다.

- 부품 코드와 신품 로트 번호
- 교체 사유(주기 도래, 조기 교체 조건 번호, 유예 여부)
- 작업자의 직무와 승인자의 직무
- 누설 시험과 입자 시험 결과
- 누적 사용량 초기화 여부

교체한 부품은 불량 분석이 필요할 수 있으므로 3일간 격리 보관한 뒤 폐기한다. 교체 기록은 5년간 보존한다. 설비지원센터장은 매월 첫째 주에 전월 기록을 점검해 누락이나 지연 입력이 있으면 해당 파트장에게 시정을 요구한다. 기록과 실제 부품 상태가 맞지 않는 사항은 설비 상황실(내선 7701)에 알리고 CMS에 시정 요청을 등록한다.
