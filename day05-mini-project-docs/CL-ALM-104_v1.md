# CL-ALM-104 WS-5 세정 장비 배스 온도 이탈 알람(코드 W847) 조치 가이드
- 문서번호: CL-ALM-104
- 판: v1
- 시행일: 2024-03-01
- 종류: 알람 조치 가이드

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위와 알람 조건

이 문서는 한결반도체 2팹의 세정 장비 WS-5(모델 CL-80)에서 배스 온도 이탈 알람(코드 W847)이 발생했을 때, 세정 파트 담당자와 설비지원센터 당직자가 따르는 조치 절차를 정한다. 다른 세정 장비나 다른 알람에는 적용하지 않는다. 알람 조건은 다음과 같다.

| 항목 | 기준 |
|---|---|
| 공정 설정 온도 | 65.0℃ |
| 경고 단계 | 설정값 대비 ±1.5℃ 초과 |
| 알람 발생 | 설정값 대비 ±2.5℃ 초과가 180초 이상 지속 |
| 히터 강제 차단 | 배스 온도 80℃ 도달 시 |

## 2. 증상

조작 화면에 배스 온도 이탈 문구가 붉은색으로 표시되고, 경광등이 점멸하며 부저가 울린다. 이 알람이 발생하면 장비는 새 로트의 투입을 막는다. 처리 중인 로트는 현재 단계까지만 진행한 뒤 대기한다. 온도 추이 화면에서는 측정값이 설정값에서 벗어나 있거나, 배스에 달린 두 온도 센서의 값이 1.0℃를 넘게 차이 나는 경우가 많다. 경고 단계에서 알람까지는 보통 10분 안팎이므로, 경고 표시를 놓치지 않고 이 시간 안에 확인해야 한다.

## 3. 추정 원인

원인은 발생 빈도가 높은 순서로 다음과 같이 본다.

1. 온도 센서의 열화나 접촉 불량: 두 센서의 편차가 1.0℃를 넘는다.
2. 순환 필터 막힘이나 순환 펌프 성능 저하: 순환 유량이 12 L/min 미만이다.
3. 히터 출력 저하: 히터 전류가 정격의 85% 미만이다.
4. 약액 보충 과다: 보충 직후 온도가 급히 떨어졌다가 회복되지 않는다.
5. 냉각수 밸브 오작동: 냉각수가 계속 흘러 승온이 되지 않는다.

## 4. 조치 절차

1. 알람을 확인한 뒤 5분 이내에 장비 안의 로트 상태를 확인하고, 처리 단계를 기록한다. 로트는 임의로 꺼내지 않는다.
2. 온도 추이 화면에서 두 센서의 값과 편차를 확인한다. 편차가 1.0℃를 넘으면 예비 센서로 전환한다. 전환은 세정 파트장의 1단계 구두 승인을 받은 뒤 한다.
3. 순환 유량을 확인한다. 12 L/min 미만이면 필터 전후 차압을 확인하고, 차압이 0.8 bar 이상이면 필터를 교체한다. 교체용 필터는 자재 창고(내선 7720)에서 자재 시스템 MAT-ON으로 출고받는다.
4. 히터 전류를 확인한다. 정격의 85% 미만이면 히터 교체가 필요하다. 이때는 세정 파트장과 설비지원센터장의 2단계 승인을 받고, 변경 관리 시스템 CMS에 부품 교체 건을 등록한 뒤 작업한다.
5. 냉각수 밸브가 닫혀 있는지 확인한다. 닫힌 상태에서도 냉각수 유량이 4.0 L/min을 넘으면 밸브 교체 대상으로 분류한다.
6. 조치 후 알람을 해제하고 재승온한다. 재승온 허용 시간은 최대 30분이다.
7. 조치를 시작한 지 20분이 지나도 원인을 찾지 못하면 7절에 따라 에스컬레이션한다.

## 5. 복구 확인 기준

아래 기준을 모두 만족해야 복구로 인정한다.

| 확인 항목 | 기준 |
|---|---|
| 배스 온도 | 설정값 ±0.5℃ 이내를 30분 연속 유지 |
| 센서 간 편차 | 0.5℃ 이하 |
| 순환 유량 | 14 L/min 이상 |
| 시험 처리 | 더미 웨이퍼 2매 처리 후 입자 검사 합격 |

입자 검사의 합격 여부는 품질팀이 판정한다. 판정 전에는 제품 로트를 투입하지 않는다.

## 6. 안전 주의

이 장비의 배스에는 65℃의 가열된 약액이 들어 있어 화상과 약액 접촉 위험이 있다. 배스 내부나 배관에 손을 대는 작업은 배스 온도가 40℃ 이하로 내려간 뒤에 한다. 작업자는 내화학 장갑, 안면 보호구, 내화학 앞치마를 착용한다. 히터나 펌프를 교체할 때는 전원을 차단하고 잠금·표지 절차(Lockout-Tagout)를 적용한다. 약액이 누출되거나 증기 냄새가 나면 즉시 작업을 멈추고 안전환경팀 비상 내선 7119로 연락한다.

## 7. 보고와 에스컬레이션

알람이 발생하면 10분 이내에 설비지원센터 당직(내선 7700)에 알린다. 에스컬레이션은 다음 기준에 따른다.

- 조치 시작 후 20분 안에 복구하지 못하면 세정 파트장에게 보고한다.
- 60분을 넘기거나 처리 중이던 로트에 온도 이탈이 의심되면 설비지원센터장과 품질팀(내선 7600)에 보고한다. 로트 영향 판정은 품질팀이 한다.
- 장비를 정지하거나 재가동할 때는 설비 상황실(내선 7701)에 통보한다.

## 8. 조치 기록

조치가 끝나면 24시간 이내에 설비 이력 시스템 EQ-LOG에 알람 이력을 입력한다. 입력 항목은 발생 시각, 경고 단계 진입 시각, 두 센서의 값, 순환 유량, 히터 전류, 추정 원인, 수행한 조치, 복구 확인 결과, 영향을 받은 로트 번호이다. 센서, 필터, 히터를 교체했다면 MAT-ON의 출고 내역과 CMS 등록 번호를 함께 연결한다. 기록은 3년간 보관하며, 세정 파트장이 월 1회 반복 발생 여부를 검토한다.
