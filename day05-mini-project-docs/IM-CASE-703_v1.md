# IM-CASE-703 IM-1 이온주입 빔 전류 불안정 장애 사례 보고서
- 문서번호: IM-CASE-703
- 판: v1
- 시행일: 2025-10-06
- 종류: 장애 사례 보고서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 개요

이 문서는 2025-09-24 새벽에 이온주입 장비 IM-1(모델 IX-200)에서 발생한 빔 전류 불안정 장애의 경과, 영향, 원인, 조치를 정리한 사례 보고서다. 이 장비는 설정 빔 전류 4.20 mA(밀리암페어)를 유지해야 한다. 그러나 이날 실측값이 설정값 대비 최대 ±6.8%까지 흔들려 알람 BC-4417이 발생했다. 정상 운전 허용 범위는 ±1.5%다. 조사 결과 이온 소스의 필라멘트 열화와 소스 가스 유량 제어 오차가 겹친 것이 원인으로 확인되었다. 이 보고서는 교육 실습용 가상 사례이며, 설비지원센터 이온주입 파트가 작성하고 품질팀이 검토했다.

## 2. 발생 경과

장애 경과는 아래 표와 같다.

| 일시 | 내용 |
|---|---|
| 09-24 02:10 | 빔 전류 변동 알람이 발생하고 장비가 자동으로 일시정지됨 |
| 09-24 02:25 | 야간 운전원이 설비지원센터 당직(내선 7700)에 호출함 |
| 09-24 02:50 | 이온주입 파트 엔지니어가 현장에 도착함 |
| 09-24 03:40 | 빔 재조정을 1차로 실시했으나 약 10분 뒤 변동이 재발함 |
| 09-24 05:30 | 소스 가스 유량과 필라멘트 이력을 점검하여 필라멘트 사용 412시간을 확인함 |
| 09-24 07:20 | 파트장이 설비 정지(hold) 결정을 내리고 설비 상황실(내선 7701)에 공유함 |
| 09-24 14:00 | 필라멘트 교체와 소스 챔버 세정을 시작함 |
| 09-25 06:30 | 시험 주입을 마치고 가동 재개를 승인함 |

초기 대응에서는 빔 재조정만 반복했기 때문에 원인 확인이 늦어졌다. 정지 결정까지 약 5시간 10분이 걸렸다.

## 3. 영향 범위

장애 시점에 이 장비에서 처리 중이던 물량은 7 lot, 168장이었다. 이 가운데 4 lot, 96장은 알람 발생 전에 주입이 끝나 영향이 없는 것으로 확인되었다. 나머지 3 lot, 72장은 도즈(주입량) 편차가 의심되어 품질팀(내선 7600)이 48시간 동안 격리했다. 시트 저항 전수 측정 결과, 이 중 1 lot, 24장이 도즈 편차 허용치 ±2.0%를 넘어 최대 +3.1%로 나타났다. 이 24장은 폐기로 판정했고, 나머지 48장은 출하를 허용했다. 장비 가동 중지 시간은 총 28시간 20분이다. 이 때문에 후속 확산 공정의 투입 계획을 하루 늦춰 조정했다.

## 4. 원인 분석

원인은 직접 원인, 기여 원인, 관리상 원인으로 나누어 분석했다.

1. 직접 원인: 이온 소스 필라멘트가 가늘어져 전자 방출이 불안정해졌다. 이 필라멘트의 사용 시간은 412시간으로, 교체 기준 400시간을 이미 넘은 상태였다.
2. 기여 원인: 소스 가스 질량유량 제어기의 보정 편차가 0.8 sccm(표준 cm³/분)으로 측정되었다. 허용 편차는 ±0.3 sccm이다. 이 편차가 방전 상태를 더 흔들어 변동 폭을 키웠다.
3. 관리상 원인: 필라멘트 교체 시점을 사용 시간이 아니라 4주 단위 달력 점검으로만 관리했다. 사용 시간이 기준에 가까워져도 알리는 장치가 없었다.
4. 인계 누락: 전날 주간 교대 인계 시 빔 전류 추세가 완만하게 나빠지고 있다는 내용이 인계 서식에 없었다.

## 5. 조치 내용

복구와 재가동을 위해 다음 조치를 실시했다.

1. 필라멘트를 신품으로 교체하고 소스 챔버를 세정했다.
2. 질량유량 제어기를 재보정하여 편차를 ±0.2 sccm 이내로 맞췄다.
3. 시험 웨이퍼 5장으로 30분간 연속 주입했고, 빔 전류 편차가 ±1.0% 이내인 것을 확인했다.
4. 가동 재개는 이온주입 파트장, 설비지원센터장, 품질팀 순서의 3단계 승인을 거쳐 결정했다.
5. 점검 내용과 교체 부품 이력은 설비 이력 시스템 EQ-LOG에 기록했다. 교체한 필라멘트는 자재 시스템 MAT-ON에서 출고 처리했다.
