# IM-PM-202 IM-1 이온주입 장비 월간 예방 점검(PM) 절차서
- 문서번호: IM-PM-202
- 판: v1
- 시행일: 2024-03-28
- 종류: 정기 점검 절차서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적과 주기

이 절차서(IM-PM-202)는 한결반도체 2팹 설비지원센터 이온주입 파트가 이온주입 장비 IM-1의 월간 예방 점검(Preventive Maintenance, PM)을 항상 같은 품질로 수행하도록 순서와 기준을 정한다. 점검 대상은 이온 소스, 빔라인, 웨이퍼 척이 있는 엔드스테이션, 냉각수 계통, 도판트 가스 라인이다. 점검은 매월 첫째 주 목요일에 한 번 실시하고, 작업 구분 코드는 PM-M1, 표준 작업 시간은 6시간으로 한다. 점검 일정은 3영업일 전까지 설비 상황실(내선 7701)에 알려 생산 계획에 반영하게 한다.

## 2. 준비물과 사전 조건

작업 전에 아래 준비물을 갖춘다.

- 헬륨 누설 검출기와 교정 기한이 남은 디지털 멀티미터, 유량계
- 절연 장갑, 무진 와이퍼, 이소프로필알코올
- 월간 소모품 키트(MAT-ON에서 출고 요청하며, 수령은 자재 창고 내선 7720)
- 측정 기록용 점검표와 모니터 웨이퍼 3매

사전 조건은 다음과 같다.

1. 이 장비 안에 진행 중인 로트가 없어야 한다.
2. 이온 소스는 전원을 끈 뒤 30분 이상 식힌 상태여야 한다.
3. 작업은 2인 1조로 하며, 한 명은 이온주입 파트 정비 담당이고 다른 한 명은 입회자다.
4. 작업 전날까지 설비 이력 시스템 EQ-LOG에서 최근 30일의 알람 이력을 검토한다.

고전압 잠금·표지(Lockout/Tagout, LOTO)와 도판트 가스 퍼지에 관한 안전 요건은 FC-SAF-501 문서를 따른다.

## 3. 점검 항목과 기준값

이 장비는 아래 표의 기준값을 모두 만족해야 정상으로 본다.

| 점검 항목 | 기준값 | 측정 방법 |
|---|---|---|
| 이온 소스 필라멘트 누적 사용 시간 | 300시간 미만 (280시간 이상이면 교체 예약) | 장비 화면 확인 |
| 빔 전류 안정도 | 30분간 ±2.5% 이내 | 장비 내장 측정기 |
| 빔라인 기저 압력 | 6.0×10⁻⁵ Pa 이하 | 진공 게이지 |
| 냉각수 유량 | 12 L/min 이상 | 유량계 |
| 냉각수 온도 | 21±1 ℃ | 온도 센서 |
| 후면 헬륨 누설량 | 0.8 sccm 이하 | 유량 표시값 |
| 가스 라인 헬륨 누설률 | 1.0×10⁻⁹ mbar·L/s 이하 | 누설 검출기 |
| 고전압 방전(아킹) 횟수 | 시간당 3회 이하 | 장비 로그 |
| 모니터 웨이퍼 면저항 균일도 | 49점 측정 기준 ±1.5% 이내 | 면저항 측정기 |

sccm은 표준 세제곱센티미터 매분(standard cubic centimeter per minute)이다.

## 4. 작업 절차

1. 설비 상황실(7701)에 점검 시작을 알리고, EQ-LOG에 작업 구분 코드 PM-M1로 작업 시작을 등록한다.
2. 장비를 정비 모드로 바꾸고 고전압 전원을 차단한 뒤 잠금·표지를 건다. 접지봉으로 잔류 전하가 방전됐는지 확인한다.
3. 이온 소스를 분리해 필라멘트 마모와 절연체 오염을 눈으로 확인한다. 교체가 필요하면 소스 부품 교체는 IM-PRT-301 문서를 따른다.
4. 빔라인의 어퍼처와 슬릿에 쌓인 증착물을 무진 와이퍼로 닦아낸다.
5. 냉각수 유량과 온도를 측정하고, 웨이퍼 척의 후면 헬륨 누설량을 확인한다.
6. 도판트 가스 라인을 퍼지한 뒤 누설 검출기로 접속부의 헬륨 누설률을 측정한다.
7. 장비를 닫고 진공 펌프다운을 시작한다. 기저 압력이 기준값에 도달하면 값을 기록한다.
8. 잠금을 풀고 고전압을 복귀시킨 뒤 빔을 인출한다. 30분 동안 빔 전류 안정도와 시간당 방전 횟수를 기록한다.
9. 모니터 웨이퍼 3매에 시험 주입을 하고, 품질팀 측정실에서 면저항 균일도를 측정한다.

## 5. 판정 기준

판정은 합격, 조건부 합격, 불합격으로 나눈다.

- **합격**: 3절의 모든 항목이 기준값 안에 들고, 모니터 웨이퍼 3매가 모두 균일도 기준을 만족한다.
- **조건부 합격**: 한 항목만 기준을 벗어났으나 재측정에서 만족한 경우다. 이온주입 파트장이 승인하고 7일 이내에 재점검한다.
- **불합격**: 두 항목 이상이 기준을 벗어나거나, 균일도가 기준을 넘거나, 가스 누설 기준을 넘은 경우다. 불합격이면 이 장비는 생산에 투입하지 않는다.

## 6. 이상 발견 시 조치

기준을 벗어난 항목은 원인을 확인한 뒤 한 번만 재측정한다. 재측정에서도 벗어나면 불합격으로 처리한다. 이후 조치는 다음과 같이 한다.

1. 장비 상태를 EQ-LOG에 「정지」로 바꾸고, 2시간 이내에 이온주입 파트장에게 보고한다. 파트장이 자리에 없으면 설비지원센터 당직(7700)에 알린다.
2. 가스 냄새나 누설 경보가 있으면 즉시 작업을 멈추고 대피한 뒤 안전환경팀 비상(7119)에 연락한다.
3. 교체 부품이 모자라면 자재 창고(7720)에 긴급 출고를 요청한다.
4. 설정값이나 하드웨어 구성을 바꿔야 하면 변경 관리 시스템 CMS에 변경 요청을 올린다. 파트장 검토와 설비지원센터장 승인을 받은 뒤 시행한다.
5. 점검 직전 처리한 로트에 영향이 우려되면 품질팀(7600)에 알려 격리 여부를 협의한다.

## 7. 기록과 보고

점검 담당자는 작업 종료 후 24시간 이내에 EQ-LOG에 측정값, 판정 결과, 교체 부품을 입력한다. 점검표 원본과 모니터 웨이퍼 측정 결과도 함께 첨부한다. 점검표에는 정비 담당과 입회자 두 사람이 서명한다. 이온주입 파트장은 1영업일 이내에 기록을 검토하고 승인한다. 조건부 합격이나 불합격이면 품질팀(7600)이 결과를 추가로 확인한다. 기록은 3년간 보존하고, 월간 점검 결과는 다음 달 첫 주에 설비지원센터장에게 요약 보고한다.
