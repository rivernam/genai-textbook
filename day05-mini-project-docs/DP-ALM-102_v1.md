# DP-ALM-102 DP-2 증착 장비 가스 유량 편차 알람(코드 D455) 조치 가이드
- 문서번호: DP-ALM-102
- 판: v1
- 시행일: 2025-01-15
- 종류: 알람 조치 가이드

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위와 알람 조건

이 문서는 증착 장비 DP-2(모델 CV-700)에서 가스 유량 편차 알람(코드 D455)이 발생했을 때 설비지원센터 증착 파트가 따르는 조치 절차를 정한다. 이 알람은 공정 중 질량유량 제어기(MFC, Mass Flow Controller)가 측정한 실제 유량이 설정 유량에서 벗어난 상태가 일정 시간 이어지면 발생한다. 주간과 야간 근무 모두에 적용하며, 알람 단계별 조건은 다음과 같다.

| 구분 | 발생 조건 | 장비 동작 |
|---|---|---|
| 경고 | 편차 ±3.0% 초과가 10초 지속 | 화면에 경고 표시, 공정은 계속 진행 |
| 알람 | 편차 ±5.0% 초과가 30초 지속 | 공정 중단, 공정 가스 밸브 자동 차단 |

## 2. 증상

이 알람이 발생하면 조작 화면에 유량 편차 알람 창이 뜨고 경광등이 황색에서 적색으로 바뀐다. 진행 중이던 증착 공정은 즉시 멈추며, 챔버 안에 있던 웨이퍼는 미완료 상태로 남는다. 알람 직전에는 대개 다음 징후가 먼저 나타난다.

- 유량 그래프에서 실측값이 설정값 주위로 흔들리거나 한쪽으로 서서히 치우친다.
- 챔버 압력이 설정 범위의 아래쪽 또는 위쪽으로 벗어난다.
- 같은 로트에서 증착 두께 측정값이 평소보다 한쪽으로 쏠린다.

## 3. 추정 원인

원인은 발생 빈도가 높은 순서로 아래와 같이 본다. 조치 절차는 이 순서를 따라 하나씩 배제하는 방식으로 진행한다.

1. 가스 공급 압력 저하: 공급 압력이 280 kPa(킬로파스칼) 미만으로 내려간 경우이다.
2. 가스 라인 필터 막힘: 필터 전후 차압이 40 kPa을 넘었거나 마지막 교체 후 6개월이 지난 경우이다.
3. MFC 영점 이동: 가스를 흘리지 않은 상태의 표시값이 ±0.5%를 넘게 벗어난 경우이다.
4. 배관 연결부 누설: 이음부나 밸브 접속부의 체결이 느슨해졌거나 실링이 열화된 경우이다.
5. 제어 신호 이상: MFC 신호 케이블이나 커넥터의 접촉이 불량한 경우이다.

## 4. 조치 절차

1. 알람 발생 5분 이내에 자동 이송을 정지하고, 챔버 안 웨이퍼의 위치와 상태를 확인하여 로트 번호를 적어 둔다.
2. 설비 이력 시스템 EQ-LOG에서 알람 직전 10분간의 유량 및 압력 추이를 조회하여 어느 가스 라인에서 편차가 났는지 특정한다.
3. 해당 라인의 공급 압력을 확인한다. 280 kPa 미만이면 설비 상황실(내선 7701)에 가스 공급 설비 점검을 요청하고, 압력이 회복될 때까지 다음 단계로 넘어가지 않는다.
4. 해당 라인에 질소를 5분간 흘려 잔류 가스를 퍼지(purge, 배관 내 가스 치환)한다.
5. 가스를 흘리지 않은 상태에서 MFC 영점을 확인한다. 표시값이 ±0.5% 이내이면 정상이며, 넘으면 영점 보정을 실시한다.
6. 라인을 가압한 뒤 10분간 압력 강하를 측정한다. 강하 속도가 분당 0.2 kPa 이하여야 하며, 넘으면 연결부를 다시 조이거나 실링을 교체한다.
7. 필터 차압이나 사용 기간이 기준을 넘었다면 필터를 교체한다. 필터는 자재 시스템 MAT-ON에서 자재 코드 GF-2210으로 불출 신청하고, 급한 경우 자재 창고(내선 7720)에 연락한다.
8. 위 조치로도 편차가 해소되지 않으면 MFC를 예비품으로 교체한다. 교체 전에 변경 관리 시스템 CMS에 변경 신청을 올리고 파트장의 승인을 받는다.
9. 알람 해제와 장비 재가동은 파트장의 승인을 받은 뒤에만 실시한다.

## 5. 복구 확인 기준

조치를 마친 뒤 다음 기준을 모두 만족해야 정상 복구로 인정한다.

- 시험 웨이퍼 3매를 연속으로 처리하여, 매 회 유량 편차가 ±1.5% 이내여야 한다.
- 시험 웨이퍼의 증착 두께가 규격 범위 안에 들어와야 하며, 품질팀이 측정 결과를 확인한다.
- 재가동 후 24시간 동안 경고 및 알람이 다시 발생하지 않아야 한다.

기준을 하나라도 만족하지 못하면 조치 절차의 해당 단계로 돌아가 원인을 다시 점검한다.

## 6. 안전 주의

이 장비의 공정 가스에는 독성이거나 가연성인 것이 포함되어 있다. 배관을 열기 전에는 반드시 질소 퍼지를 마치고, 휴대용 가스 감지기로 작업 위치의 농도가 경보 설정값 아래임을 확인한다. 배관과 밸브 작업 시에는 잠금·표지(LOTO, Lockout Tagout) 절차를 적용하고, 작업자는 보안경, 내화학 장갑, 방독 마스크를 착용한다. 배관 개방 작업은 반드시 2인 1조로 하며, 가스 냄새나 감지기 경보로 누출이 의심되면 즉시 작업을 중단하고 대피한 뒤 안전환경팀 비상 내선 7119로 연락한다.

## 7. 보고와 에스컬레이션

이 알람이 발생하면 담당자는 30분 이내에 설비지원센터 당직(내선 7700)에 발생 사실을 보고한다. 알람으로 중단된 로트가 있으면 2시간 이내에 품질팀(내선 7600)에 로트 번호와 진행 단계를 통보하여 처리 방향을 정한다. 같은 장비에서 24시간 이내에 이 알람이 2회 이상 재발하면 파트장에게 즉시 알리고, 파트장은 1시간 이내에 설비지원센터장에게 보고한다. MFC 교체나 배관 변경이 필요한 경우에는 CMS 변경 신청에 대해 파트장 승인과 설비지원센터장 승인을 차례로 받는다.

## 8. 조치 기록

담당자는 조치를 마친 뒤 24시간 이내에 EQ-LOG에 조치 내용을 입력한다. 기록에는 다음 항목을 반드시 포함하며, 기록은 3년간 보관한다.

| 항목 | 기재 내용 |

| 발생 정보 | 발생 일시, 해당 가스 라인, 영향 로트 번호 |
| 측정값 | 공급 압력, 필터 차압, MFC 영점, 압력 강하 속도 |
| 조치 내용 | 교체 부품과 자재 코드, CMS 변경 신청 번호 |
| 확인 결과 | 시험 웨이퍼 3매의 편차, 품질팀 확인 여부 |
