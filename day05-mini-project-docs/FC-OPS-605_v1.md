# FC-OPS-605 설비지원센터 협력사 엔지니어 출입 · 작업 규정
- 문서번호: FC-OPS-605
- 판: v1
- 시행일: 2024-11-24
- 종류: 운영 규정

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적
이 문서(FC-OPS-605)는 한결반도체 2팹 설비지원센터 관리 구역에 협력사 엔지니어가 출입해 설비 작업을 할 때 지켜야 할 기준과 절차를 정한다. 외부 인력의 작업으로 생기는 공정 오염, 설비 손상, 인명 사고를 막고, 모든 작업 내용이 빠짐없이 기록으로 남게 하는 것이 목적이다.

## 2. 적용 범위
이 규정은 설비 공급사, 정비 용역사, 부품 수리사 등 외부 회사 소속으로 설비지원센터 관리 구역에서 작업하는 모든 엔지니어에게 적용한다. 식각, 증착, 화학적 기계적 연마(CMP, Chemical Mechanical Polishing), 세정, 이온주입 파트의 장비 작업을 모두 포함한다. 단순 견학, 자재 납품, 건물 시설 공사는 이 규정의 대상이 아니며 각각 안전환경팀과 자재팀의 별도 기준을 따른다. 협력사 엔지니어를 입회하는 파트 담당자와 승인자도 이 규정을 지켜야 한다.

## 3. 기준
협력사 엔지니어의 출입과 작업은 아래 기준을 모두 충족해야 한다.

| 항목 | 기준 |
|---|---|
| 사전 신청 | 작업 3영업일 전 17시까지 신청 |
| 안전 교육 | 2시간 과정 이수, 유효기간 180일 |
| 출입증 | 최대 14일 유효, 작업 종료 당일 반납 |
| 작업 인원 | 2인 1조 필수, 한 조 최대 4명 |
| 1회 작업 시간 | 최대 8시간 |
| 클린룸 입실 | 에어샤워 30초 이상 통과 |
| 반입 공구 | 사전 등록 목록에 있는 공구만 반입, 반출 시 개수 대조 |
| 촬영·저장매체 | 촬영 금지, 노트북과 저장장치는 봉인 스티커를 붙여야 반입 |

안전 교육 유효기간이 작업 종료일보다 먼저 끝나는 엔지니어는 작업 시작 전에 재교육을 받아야 한다. 단독 작업은 어떤 경우에도 금지하며, 조원 중 한 명이 자리를 비우면 나머지 인원도 작업을 멈춘다.

## 4. 절차
1. 협력사 담당자는 변경 관리 시스템(CMS, Change Management System)에 출입·작업 신청서(양식 WP-17)를 등록한다. 신청서에는 작업자 명단, 교육 이수일, 반입 공구 목록, 작업 범위를 적는다.
2. 담당 파트장이 작업 범위와 공정 영향을 검토하고, 설비지원센터장이 최종 승인한다. 반려할 때는 사유를 CMS에 남긴다.
3. 작업 당일 협력사 엔지니어는 안내 데스크에서 신원과 교육 이수 여부를 확인받고 출입증을 받는다. 반입 공구는 등록 목록과 대조해 개수를 기록한다.
4. 작업 전 파트 담당자가 입회한 상태에서 잠금·표지(LOTO, Lockout/Tagout) 조치를 한다. 협력사 엔지니어는 황색 태그를 직접 부착하고, 태그에 소속과 작업 시작 시각을 적는다.
5. 작업 중 파트 담당자는 30분 간격으로 현장을 순회한다. 승인된 범위를 벗어난 작업이 보이면 즉시 중단시킨다.
6. 작업을 마치면 공구 개수를 다시 대조하고, 설비 상태를 파트 담당자와 함께 확인한 뒤 서명한다. 이어서 황색 태그를 제거하고 출입증을 반납한다.
7. 협력사 담당자는 24시간 이내에 작업 보고서를 설비 이력 시스템(EQ-LOG)에 등록한다. 부품을 교체했으면 자재 시스템(MAT-ON)에도 교체 내역을 입력한다.

## 5. 예외와 승인
설비 정지로 생산 손실이 커져 사전 신청 기한을 지킬 수 없으면 긴급 출입을 허용한다. 이때는 설비지원센터 당직 책임자가 설비 상황실을 통해 구두로 승인할 수 있다. 협력사는 구두 승인 후 2시간 이내에 신청서를 보완해야 하며, 작업이 끝날 때까지 파트 담당자 1명 이상이 동행한다.

야간과 휴일 작업은 전일 16시까지 신청하고 설비지원센터장이 승인한다. 가스 라인 개방이나 고전압 구간 작업 같은 고위험 작업은 담당 파트장, 설비지원센터장, 안전환경팀의 3단계 승인을 받아야 한다. 작업 시간 연장은 1회에 한해 2시간까지 허용하며 담당 파트장이 승인한다. 안전 교육 면제는 긴급 출입을 포함해 어떤 경우에도 인정하지 않는다.

## 6. 연락처와 기한
| 구분 | 내선 | 용도 |
|---|---|---|
| 설비지원센터 당직 | 7700 | 출입 승인 문의, 긴급 출입 요청 |
| 설비 상황실 | 7701 | 긴급 출입 구두 승인, 작업 중 이상 보고 |
| 안전환경팀 비상 | 7119 | 사고, 부상, 가스 누출 |
| 자재 창고 | 7720 | 교체 부품 불출·반납 |
| 품질팀 | 7600 | 공정 오염 의심 시 즉시 통보 |

기한은 다음과 같이 지킨다. 일반 신청은 작업 3영업일 전 17시, 야간·휴일 신청은 전일 16시, 긴급 출입 신청서 보완은 구두 승인 후 2시간, 작업 보고서 등록은 작업 종료 후 24시간, 출입증 반납은 작업 종료 당일이다. 사고가 나면 대피 후 집결지 B-2 구역에서 인원을 확인하고 안전환경팀 비상 내선으로 알린다.

## 7. 기록과 개정
신청서, 교육 이수 기록, 공구 대조표, 작업 보고서는 3년간 보존한다. 안전환경팀은 이 규정을 어긴 사례를 협력사 엔지니어별로 기록한다. 위반이 누적 3회가 되면 해당 엔지니어의 출입을 90일간 정지하고 소속 협력사에 서면으로 통보한다.

설비지원센터는 이 규정을 연 1회, 매년 12월에 검토한다. 개정이 필요하면 CMS에서 개정안을 승인받고, 시행 7일 전까지 협력사에 알린다. 이 문서는 v1이며 2024-11-24부터 시행한다.
