# CL-PM-203 WS-5 세정 장비 분기 오버홀 점검 절차서
- 문서번호: CL-PM-203
- 판: v1
- 시행일: 2024-09-15
- 종류: 정기 점검 절차서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적과 주기

이 절차서(CL-PM-203 v1)는 세정 장비 WS-5(모델 CL-80)의 분기 오버홀 점검을 누가 하더라도 같은 방법과 같은 기준으로 수행하도록 정한 문서다. 약액 순환 계통, 필터, 펌프, 배관, 배기 계통의 마모와 누설을 정기적으로 확인하여 파티클 불량과 약액 누출 사고를 예방하는 것이 목적이다. 점검 주기는 13주마다 1회이며, 정해진 날짜 기준 ±5일 이내에 시행한다. 1회 작업 시간은 8시간을 기준으로 한다. 오버홀 중 약액 누액 감지 알람 LK-412가 발생하면 6절에 따라 조치한다. 담당 부서는 세정 파트다.

## 2. 준비물과 사전 조건

오버홀은 세정 파트 작업자 2인 1조로 수행하며, 조원 중 1명은 파트장이 지정한 정비 책임자여야 한다. 작업 3일 전까지 MAT-ON에서 교체 부품을 예약하고, 자재 창고(내선 7720)에 수령 가능 여부를 확인한다.

준비물은 다음과 같다.

1. 약액 필터 카트리지 2개, 펌프 씰 키트 1세트, 오링 세트
2. 토크 렌치(5~25 N·m), 디지털 압력계, 진동계, 비저항계
3. 시험용 웨이퍼 3매와 파티클 계측 일정(품질팀 협의)
4. 약액 취급용 보호구 일체

사전 조건은 다음과 같다.

- 이 장비의 가동을 멈추고 약액 배출과 탈이온수(DI수, Deionized water) 린스를 마친다.
- 약액 탱크 온도가 40℃ 이하로 내려간 것을 확인한다.
- 설비 상황실(내선 7701)에 정지 시각과 예상 복귀 시각을 알린다.
- 잠금·표지(LOTO, Lock-Out Tag-Out) 적용과 약액 취급 안전 수칙은 FC-SAF-501 문서를 따른다.
- 교체 부품의 규격과 보관 상태 확인은 CL-PRT-301 문서를 따른다.

## 3. 점검 항목과 기준값

| 항목 | 기준값 | 비고 |
|---|---|---|
| 약액 탱크 온도 제어 | 65±2℃ | 안정화 후 30분 평균 |
| 필터 차압 | 0.15 MPa 미만 | 오버홀에서는 값과 무관하게 교체 |
| 순환 펌프 진동 | 4.5 mm/s 이하 | 구동부 3개 지점 중 최댓값 |
| 배관 누설 시험 | 0.30 MPa에서 10분간 압력 강하 0.01 MPa 이하 | DI수로 가압 |
| DI수 비저항 | 17.5 MΩ·cm 이상 | 린스 완료 후 측정 |
| 배기 압력 | -120 Pa ± 20 Pa | 덕트 측정 포트 기준 |
| 시험 웨이퍼 파티클 | 0.12 μm 이상 20개 이하(매당) | 3매 모두 충족 |

## 4. 작업 절차

1. 사전 조건을 모두 확인하고 작업 시작 시각을 기록한다.
2. 약액 계통 잔액을 완전히 배출한 뒤 필터 하우징을 열어 기존 카트리지를 제거한다. 제거 전 차압 값을 먼저 기록한다.
3. 새 카트리지와 오링을 장착하고, 하우징 체결은 토크 렌치로 규정 토크에 맞춘다.
4. 순환 펌프의 씰 키트를 교체한다. 교체 후 시운전 10분 동안 진동을 측정한다.
5. 배관을 DI수로 채워 0.30 MPa까지 가압하고 10분간 압력 강하를 측정한다.
6. 약액을 다시 채우고 탱크 온도를 올려 65℃에서 30분간 안정화한다. 이때 온도 편차를 기록한다.
7. 배기 압력과 DI수 비저항을 측정한다.
8. 시험 웨이퍼 3매를 세정하여 품질팀(내선 7600)에 파티클 계측을 의뢰한다.
9. 잠금·표지를 해제하고 설비 상황실에 복귀를 알린다.

## 5. 판정 기준

3절의 모든 항목이 기준값을 충족하면 합격으로 판정하고, 정비 책임자가 확인한 뒤 파트장이 복귀를 승인한다. 한 항목이라도 기준을 벗어나면 조건부로 판정하여 원인을 조치한 뒤 해당 항목만 1회 재측정한다. 재측정에서도 기준을 벗어나거나 파티클 항목이 2회 연속 초과하면 불합격으로 판정하고 가동 복귀를 보류한다. 불합격 건의 복귀는 파트장 검토와 설비지원센터장 승인을 모두 거쳐야 한다.

## 6. 이상 발견 시 조치

작업 중 누액 감지 알람이 울리면 즉시 약액 공급을 차단하고 작업자를 대피시킨 뒤 안전환경팀 비상(내선 7119)과 설비지원센터 당직(내선 7700)에 연락한다. 이 알람은 원인 확인과 누액 제거가 끝날 때까지 해제하지 않는다.

기준값 초과가 확인되면 아래와 같이 조치한다.

- 진동 초과: 펌프 정렬과 씰 장착 상태를 다시 점검하고, 재측정에서도 초과하면 펌프를 교체한다.
- 압력 강하 초과: 체결부와 오링을 점검하고 재시험한다.
- 파티클 초과: 약액 탱크를 재세정하고 재측정한다.

같은 항목의 재작업은 최대 2회까지 허용한다. 2회를 넘기면 파트장이 설비지원센터장에게 즉시 보고한다. 부품 규격이나 기준값의 변경이 필요하면 변경 관리 시스템 CMS에 변경 요청을 먼저 등록하고, 승인 전에는 기존 값을 유지한다.

## 7. 기록과 보고

정비 책임자는 작업 종료 후 24시간 이내에 설비 이력 시스템 EQ-LOG에 교체 부품, 측정값, 판정 결과를 입력한다. 점검 보고서는 2영업일 이내에 파트장에게 제출하고, 파트장은 검토 후 설비지원센터장에게 보고한다. 파티클 계측 결과는 품질팀이 회신하는 대로 보고서에 첨부한다. 불합격이나 재작업이 발생한 건은 원인과 조치 내용을 별도로 기재한다. 측정 원본 기록과 보고서는 3년간 보존한다.
