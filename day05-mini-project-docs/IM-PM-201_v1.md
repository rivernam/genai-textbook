# IM-PM-201 IM-1 이온주입 장비 주간 예방 점검(PM) 절차서
- 문서번호: IM-PM-201
- 판: v1
- 시행일: 2024-05-12
- 종류: 정기 점검 절차서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적과 주기

이 문서(IM-PM-201)는 한결반도체 2팹 설비지원센터 이온주입 파트가 IM-1 이온주입 장비에 대해 주 1회 수행하는 예방 점검(PM, Preventive Maintenance)의 절차와 기준을 정한다. 빔 이상과 진공 불량을 미리 찾아 계획 외 정지를 줄이는 것이 목적이다. 점검은 매주 월요일 08:00에 시작하고 소요 시간은 약 90분이다. 월요일이 공휴일이면 다음 근무일에 수행하며, 어떤 경우에도 2주 연속으로 건너뛰지 않는다. 점검은 이온주입 파트 엔지니어 2인 1조로 한다.

## 2. 준비물과 사전 조건

준비물은 다음과 같다.

- 디지털 멀티미터, 헬륨 누설 검출기, 냉각수 유량계
- 무진 와이퍼와 전용 세정액, 절연 장갑
- EQ-LOG 점검표 양식

사전 조건은 다음과 같다.

1. 이 장비에 진행 중인 로트가 없고 상태가 대기(Idle)여야 한다.
2. 마지막 빔 가동 종료 후 30분 이상 지나 고전압 단자의 잔류 전하와 소스부 열이 빠져 있어야 한다.
3. 소모품 재고를 전날까지 MAT-ON에서 확인한다. 부족하면 자재 창고(내선 7720)에 요청한다.

고전압과 유해 가스를 다루는 작업의 잠금·표지(LOTO) 방법과 보호구 기준은 FC-SAF-501 문서를 따른다.

## 3. 점검 항목과 기준값

| 항목 | 기준값 | 확인 방법 |
|---|---|---|
| 주 챔버 진공 압력 | 6.0×10⁻⁴ Pa 이하 | 장비 화면 진공 게이지 |
| 냉각수 유량 | 7.5 L/min 이상 | 유량계 직접 확인 |
| 냉각수 온도 | 18~22℃ | 온도 표시값 |
| 빔 전류 안정도 | 설정값 대비 ±2.5% 이내 | 10분간 시험 빔 |
| 고전압 아크 횟수 | 1시간당 3회 이하 | 이력 화면 |
| 소스 필라멘트 누적 사용 | 280시간 미만 | 누적 시간 표시 |
| 가스 라인 압력 상승률 | 0.4 Pa/min 이하 | 밸브 차단 후 5분 측정 |
| 웨이퍼 핸들러 위치 편차 | 0.3 mm 이하 | 시험 웨이퍼 정렬 확인 |

## 4. 작업 절차

1. 점검 시작 시각과 조원을 점검표에 적고, 이 장비의 현재 알람 이력을 먼저 확인한다.
2. 잠금·표지를 건 뒤 외관, 케이블 체결 상태, 냉각수 배관의 누수 흔적을 눈으로 확인한다.
3. 냉각수 유량과 온도를 읽어 기록한다.
4. 진공 압력을 읽고, 가스 라인 밸브를 닫은 뒤 5분간 압력 상승률을 잰다.
5. 소스 필라멘트 누적 사용 시간과 최근 1주일 아크 횟수를 이력 화면에서 확인한다.
6. 잠금을 풀고 시험 빔을 10분간 내보내 전류 안정도를 측정한다.
7. 시험 웨이퍼를 핸들러로 이송해 위치 편차를 확인한다.
8. 외부 덮개와 점검 구역을 무진 와이퍼로 닦고, 공구와 시험 웨이퍼를 회수한다.
9. 모든 측정값을 점검표에 적고 서명한다.

## 5. 판정 기준

모든 항목이 기준값 안이면 '적합'으로 판정하고 이 장비를 가동 상태로 돌려놓는다. 한 항목이 기준값을 10% 이내로 벗어나면 '조건부 적합'이다. 이 경우 24시간 안에 같은 항목을 다시 측정해 기준값 안으로 돌아왔는지 확인한다. 한 항목이라도 10%를 넘게 벗어나거나 두 항목 이상이 기준값을 벗어나면 '부적합'이다. 소스 필라멘트 누적 사용이 280시간에 이르면 다른 항목과 관계없이 교체 계획을 세운다. 판정은 점검 조원 2인이 함께 하고, 의견이 다르면 더 엄격한 쪽을 따른다.

## 6. 이상 발견 시 조치

부적합이면 즉시 가동을 중지하고 설비 상황실(내선 7701)에 알린다. 2시간 안에 파트장에게 보고하고, 처리가 어렵다면 설비지원센터 당직(내선 7700)에 지원을 요청한다. 가스 냄새나 누설 경보가 있으면 작업을 멈추고 구역에서 나온 뒤 안전환경팀 비상(내선 7119)에 연락한다. 이 알람이 반복되는 경우도 같은 방식으로 보고한다. 점검 직전 4시간 안에 처리된 로트가 있으면 품질팀(내선 7600)에 알려 영향 여부를 확인받는다. 소모 부품의 교체와 폐기는 IM-PRT-301 문서를 따른다. 설정값이나 구성을 바꿔야 하면 변경 관리 시스템 CMS에 변경 요청을 등록한다. 재가동은 파트장이 확인하고 설비지원센터장이 승인한 뒤에 한다.

## 7. 기록과 보고

점검표는 점검 당일 17:00까지 EQ-LOG에 입력한다. 부적합이나 조건부 적합이면 조치 내용과 재측정 결과를 함께 적는다. 파트장은 다음 근무일 12:00까지 입력 내용을 검토하고 확인 서명을 한다. 점검 기록은 3년간 보관한다. 파트장은 한 달 동안의 점검 결과를 모아 매월 첫째 주 금요일까지 설비지원센터장에게 보고한다. 이 절차를 수행하지 못한 주에는 사유와 보완 일정을 같은 기한 안에 기록한다.
