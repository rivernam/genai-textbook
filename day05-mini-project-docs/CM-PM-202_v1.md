# CM-PM-202 CP-3 CMP 장비 월간 예방 점검(PM) 절차서
- 문서번호: CM-PM-202
- 판: v1
- 시행일: 2025-02-09
- 종류: 정기 점검 절차서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적과 주기

이 절차서(CM-PM-202)는 CMP(Chemical Mechanical Planarization, 화학적 기계적 평탄화) 장비 CP-3(모델 PL-300)의 월간 예방 점검(PM, Preventive Maintenance) 방법을 정한다. 연마 균일도 저하와 예기치 않은 정지를 막는 것이 목적이다. 점검은 매월 1회, 매월 첫째 주 안에 시행한다. 1회 소요 시간은 약 4시간으로 잡고, 직전 점검일부터 다음 점검일까지 35일을 넘기지 않는다. 담당은 CMP 파트이다. 점검 중 알람 코드 CP-E417(헤드 압력 편차 초과)이 나타나면 6절에 따라 조치한다.

## 2. 준비물과 사전 조건

준비물은 다음과 같다.
- 토크 렌치(설정 범위 2~10 N·m)
- 패드 두께 측정 게이지
- 압력 검증기
- 교정 유효기간이 남은 슬러리 유량계
- 무진 와이퍼
- 내화학 장갑과 보안면

사전 조건은 다음과 같다.
1. 점검 시작 24시간 전까지 설비 상황실(내선 7701)에 정지 일정을 알린다.
2. 점검 전날까지 자재 시스템 MAT-ON에서 연마 패드 1세트와 컨디셔너 디스크 1개의 재고를 확인한다. 부족하면 자재 창고(내선 7720)에 요청한다.
3. 진행 중인 로트는 마무리하고, 장비 안에 웨이퍼가 남아 있지 않은 것을 확인한다.

작업 전 에너지 차단·표지 부착과 슬러리 등 화학물질 취급 안전은 FC-SAF-501 문서를 따른다.

## 3. 점검 항목과 기준값

이 장비의 점검 항목과 기준값은 아래 표와 같다.

| 항목 | 기준값 | 기준을 벗어난 경우 |
|---|---|---|
| 연마 패드 잔여 두께 | 0.80 mm 이상 | 교체 |
| 컨디셔너 디스크 누적 사용 시간 | 60시간 이하 | 교체 |
| 리테이닝 링 잔여 두께 | 2.5 mm 이상 | 교체 |
| 연마 헤드 압력 편차 | 설정값 대비 ±1.5 kPa 이내 | 재교정 |
| 플래튼 회전수 편차 | 설정값 대비 ±2 rpm 이내 | 구동부 점검 |
| 슬러리 유량 | 180±10 mL/min | 펌프 점검 |
| 슬러리 공급 라인 압력 | 120~160 kPa | 필터 점검 |
| 순수 린스 유량 | 1.2 L/min 이상 | 노즐 청소 |
| 배기 차압 | -40~-70 Pa | 덕트 점검 |

(rpm은 분당 회전수, Pa는 파스칼, kPa는 킬로파스칼이다.)

## 4. 작업 절차

1. 장비를 점검 모드로 전환하고 슬러리 공급을 차단한다. 공급 라인의 잔압이 빠질 때까지 5분간 기다린다.
2. 연마 패드의 잔여 두께를 중심과 가장자리 각 4곳, 모두 8곳에서 측정하고 가장 작은 값을 기록한다.
3. 컨디셔너 디스크의 누적 사용 시간을 장비 화면에서 확인하고, 표면 마모와 이물 부착을 눈으로 살핀다.
4. 리테이닝 링의 잔여 두께를 측정하고, 헤드 하부 멤브레인에 찢김이나 변형이 없는지 본다.
5. 압력 검증기를 헤드에 연결해 설정 압력별로 편차를 확인한다.
6. 플래튼을 정해진 회전수로 구동하고 실제 회전수와 진동 상태를 확인한다.
7. 슬러리와 순수의 유량, 공급 라인 압력, 배기 차압을 각각 측정한다.
8. 슬러리 라인 필터의 막힘과 배관 이음부의 누액을 확인하고, 연마 부스 내부를 무진 와이퍼로 닦는다.
9. 더미 웨이퍼 3매를 연마해 제거율을 측정한다.

소모품 교체가 필요하면 세부 방법은 CM-PRT-301 문서를 따른다.

## 5. 판정 기준

3절의 모든 항목이 기준값 안에 있고, 더미 웨이퍼 3매의 제거율 편차가 3% 이내이면 "적합"으로 판정한다. 기준값 안이지만 한계에 근접한 항목이 있으면 "조건부 적합"으로 판정하고, 7일 이내에 해당 항목을 재점검한다. 한계에 근접한 경우란 패드 잔여 두께가 0.90 mm 미만이거나 디스크 누적 사용 시간이 55시간을 넘은 경우를 말한다. 기준값을 하나라도 벗어나거나 제거율 편차가 3%를 넘으면 "부적합"으로 판정한다.

판정은 작업자가 작성하고, CMP 파트장이 확인한 뒤 품질팀이 재가동 전에 최종 승인한다. 이 3단계 승인이 끝나기 전에는 생산 로트를 투입하지 않는다.

## 6. 이상 발견 시 조치

부적합 항목이 나오면 장비에 "사용 금지" 표지를 붙이고 설비지원센터 당직(내선 7700)에 즉시 알린다. 슬러리나 약액이 누출됐으면 작업을 멈추고 안전환경팀 비상(내선 7119)에 먼저 연락한 뒤 FC-SAF-501 문서에 따라 대응한다.

소모품 교체나 재교정을 마치면 해당 항목과 더미 웨이퍼 연마를 다시 수행해 적합 여부를 확인한다. 같은 항목이 2회 연속 부적합이면 원인 분석을 CMP 파트장에게 요청한다. 복구에 2시간 넘게 더 걸릴 것으로 예상되면 설비지원센터장에게 보고하고 생산 일정 조정을 협의한다.

## 7. 기록과 보고

작업자는 점검 종료 후 24시간 이내에 측정값, 교체 부품, 판정 결과를 설비 이력 시스템 EQ-LOG에 입력한다. 서명한 점검표 원본은 CMP 파트에서 3년간 보관한다. 부품 사양이나 교정값을 바꾼 경우에는 3영업일 이내에 변경 관리 시스템 CMS에 변경 요청을 등록한다. 월간 점검 결과 요약은 매월 5영업일까지 설비지원센터장에게 보고한다. 기록 내용에 대한 문의는 품질팀(내선 7600)으로 한다.
