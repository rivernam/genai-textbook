# DP-PRT-301 DP-2 증착 장비 소모품 교체 기준표
- 문서번호: DP-PRT-301
- 판: v1
- 시행일: 2025-08-03
- 종류: 부품 교체 기준표

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위

이 문서는 한결반도체 2팹 설비지원센터가 운영하는 증착 장비 DP-2(모델 CV-700)의 소모품 교체 시기와 방법을 정한 기준표(DP-PRT-301)다. 대상 부품은 샤워헤드, 챔버 리드 O-링, 히터 세라믹 링, 배기 라인 필터, 건식 펌프 오일의 다섯 가지다. 교체 작업은 증착 파트가 수행하고, 품질팀이 교체 후 공정 상태를 검증하며, 자재팀이 재고를 관리한다. 소모품 수명 경고 알람 CW-5120이 표시될 때도 이 기준표를 따른다. 설비 개조나 부품 사양 변경은 이 문서의 대상이 아니며, 변경 관리 시스템(CMS, Change Management System)으로 별도 처리한다.

## 2. 부품별 교체 주기

이 장비의 소모품은 아래 표의 기준 중 먼저 도달하는 쪽에 맞춰 교체한다. 누적 막 두께와 가동 시간은 설비 이력 시스템(EQ-LOG)이 자동으로 집계한 값을 쓴다. 이 알람은 각 기준의 90%에 도달하면 표시되므로, 알람이 뜬 날부터 교체 일정을 잡는다.

| 부품 | 교체 주기 | 비고 |
|---|---|---|
| 샤워헤드 | 누적 막 두께 2,400 μm 또는 고주파 가동 1,100시간 | 먼저 도달하는 쪽 적용 |
| 챔버 리드 O-링 | 90일 또는 웨이퍼 18,000매 | 리드 개방 시 함께 교체 |
| 히터 세라믹 링 | 누적 막 두께 1,600 μm | 균열 육안 확인 병행 |
| 배기 라인 필터 | 45일 | 차압 점검 주 1회 |
| 건식 펌프 오일 | 가동 4,000시간 | 색상 점검 월 1회 |

챔버 리드를 여는 정비가 있으면 O-링은 주기가 남아 있어도 함께 교체한다. 한 번 떼어 낸 O-링은 다시 쓰지 않는다.

## 3. 조기 교체 조건

다음 조건 중 하나라도 확인되면 주기가 남아 있어도 해당 부품의 조기 교체를 검토한다.

1. 막 두께 균일도가 3.5%를 넘는 로트가 연속 2회 나오면 샤워헤드를 점검한다.
2. 크기 0.2 μm 이상 파티클이 웨이퍼 한 장당 30개를 넘으면 샤워헤드와 히터 세라믹 링을 함께 점검한다.
3. 챔버 누설률이 1.5 mTorr/min을 넘으면 O-링을 교체한다.
4. 배기 라인 차압이 12 kPa를 넘으면 배기 라인 필터를 교체한다.
5. 건식 펌프 오일이 검게 변하거나 펌프 구동 전류가 정상 값보다 15% 높아지면 오일을 교체한다.

조기 교체는 증착 파트장이 승인한다. 다만 정해진 주기의 50%에 도달하기 전에 교체하려면 설비지원센터장이 추가로 승인해야 하며, 이때 원인 분석 결과를 요청서에 첨부한다. 승인은 요청한 날 17시까지 처리하는 것을 원칙으로 한다.

## 4. 교체 절차 요약

이 절차는 아래 순서로 진행한다.

1. 증착 파트 담당자가 EQ-LOG에서 교체 요청서를 작성하고 파트장의 승인을 받는다.
2. 공정을 중단하고 챔버 온도를 60℃ 이하로 낮춘 뒤, 에너지 차단 잠금·표지(LOTO, Lockout/Tagout)를 건다.
3. 질소로 20분간 퍼지한다. 가스 라인을 열어야 하면 안전환경팀 비상 내선 7119에 작업 시작을 알린다.
4. 기존 부품을 분리하고, 신품의 일련번호와 포장 밀봉 상태를 확인한 뒤 장착한다.
5. 누설 시험에서 누설률 1.0 mTorr/min 이하임을 확인한다.
6. 시즈닝 웨이퍼 5매를 처리한다.
7. 품질팀(내선 7600)이 검증 웨이퍼 3매의 막 두께와 파티클을 측정하고, 합격하면 생산에 복귀시킨다.

샤워헤드 교체는 작업 시작부터 생산 복귀까지 6시간 이내를 목표로 한다. 목표를 넘길 것으로 예상되면 설비 상황실(내선 7701)에 알리고, 작업 중 이상이 생기면 설비지원센터 당직(내선 7700)에 연락한다.

## 5. 재고와 발주 기준

소모품마다 최소 재고와 예상 납기를 아래와 같이 정한다.

- 샤워헤드: 최소 재고 2개, 납기 35일
- 챔버 리드 O-링 키트: 최소 재고 6세트, 납기 14일
- 히터 세라믹 링: 최소 재고 1개, 납기 42일
- 배기 라인 필터: 최소 재고 4개, 납기 21일
- 건식 펌프 오일: 최소 재고 20 L, 납기 10일

재고가 최소 재고 이하로 내려가면 증착 파트가 자재 시스템(MAT-ON)에서 영업일 2일 이내에 발주를 요청한다. 납기가 긴 샤워헤드와 히터 세라믹 링은 수명 경고 알람이 표시되기 전이라도 재고가 최소 수준이면 먼저 발주한다. 신품이 입고되면 자재팀이 일련번호와 제조일을 확인하고, 재고 조회와 불출 문의는 자재 창고(내선 7720)가 받는다. O-링은 제조일로부터 24개월이 지나면 사용하지 않고 폐기한다.

## 6. 교체 기록

교체를 마치면 작업자는 24시간 이내에 EQ-LOG에 교체 기록을 입력한다. 기록에는 부품명, 기존 부품과 신품의 일련번호, 교체 사유(정기 또는 조기), 누설 시험값, 시즈닝 웨이퍼 매수, 품질팀 검증 결과, 작업자와 승인자를 반드시 적는다. 입력이 누락되었거나 값이 틀렸다면 발견한 날부터 3영업일 이내에 보완한다.

증착 파트장은 매월 첫째 영업일에 전월 교체 기록을 검토하고, 품질팀은 분기마다 1회 검증 결과를 대조한다. 교체 기록은 5년간 보존한다. 교체 주기나 기준값을 바꿔야 하면 기록을 근거로 CMS에 변경 요청을 올리며, 승인 전에는 이 기준표의 값을 그대로 적용한다.
