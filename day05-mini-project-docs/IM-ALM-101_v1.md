# IM-ALM-101 IM-1 이온주입 장비 빔 전류 불안정 알람(코드 I454) 조치 가이드
- 문서번호: IM-ALM-101
- 판: v1
- 시행일: 2024-02-20
- 종류: 알람 조치 가이드

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위와 알람 조건

이 문서는 한결반도체 2팹 설비지원센터가 운영하는 IM-1 이온주입 장비(모델 IX-200)에서 빔 전류 불안정 알람(코드 I454)이 발생했을 때 당직 엔지니어와 이온주입 파트 담당자가 따를 조치 방법을 정한다. 다른 장비의 알람과 이 장비의 다른 빔 관련 알람에는 적용하지 않는다. 이 알람은 아래 조건 중 하나라도 충족되면 발생한다.

| 구분 | 발생 조건 | 장비 동작 |
|---|---|---|
| 빔 전류 편차 | 설정값 대비 ±4.5% 초과 상태가 30초 이상 지속 | 주입 일시 정지 |
| 아크 전류 변동 | 1분 이동 평균 대비 ±12% 초과 변동이 3회 연속 | 경고 표시 후 주입 계속 |
| 추출 전압 방전 | 10분 안에 순간 강하 3회 이상 | 고전압 자동 차단 |

## 2. 증상

이 알람이 발생하면 조작 화면에 빔 전류 추이 그래프가 톱니 모양으로 표시되고 알람 배너가 노란색에서 붉은색으로 바뀐다. 주입 중이던 로트는 자동으로 보류(hold) 상태가 되며, 도즈 적산값이 목표보다 부족하게 집계된다. 소스 챔버 압력이 평소보다 크게 흔들리거나 추출부 근처에서 간헐적인 방전 소리가 들리기도 한다. 증상이 아크 전류 변동에만 해당하면 주입이 계속되므로, 담당자는 경고 표시를 놓치지 말고 즉시 확인해야 한다.

## 3. 추정 원인

아래 순서로 점검한다. 위쪽 항목일수록 발생 빈도가 높다.

1. 이온 소스 필라멘트 소모: 누적 사용 시간이 180시간을 넘으면 방출이 불균일해진다.
2. 소스 가스 공급 불안정: 가스 유량 조절 장치의 흔들림이나 배관 잔압 변동이 원인이다.
3. 추출 전극 오염: 증착물이 쌓여 미세 방전이 생긴다. 마지막 세정 후 누적 주입 시간이 400시간을 넘으면 의심한다.
4. 빔라인 진공 저하: 압력이 5.0×10⁻⁶ Pa을 넘으면 빔이 산란한다.

## 4. 조치 절차

1. 알람 발생 시각과 보류된 로트 번호를 설비 이력 시스템 EQ-LOG에 먼저 적는다.
2. 알람 이력 화면에서 필라멘트 누적 사용 시간을 확인한다. 180시간을 넘었으면 6번으로 간다.
3. 알람을 1회 리셋하고 15분간 빔 전류 추이를 관찰한다. 재시도는 2회까지만 허용하며 3회째 리셋은 금지한다.
4. 소스 가스 압력과 빔라인 진공도를 읽어 3절의 기준과 비교한다. 기준을 벗어난 항목은 해당 배관과 펌프부터 점검한다.
5. 추출 전극 오염이 의심되면 고전압을 차단하고 방전 대기를 마친 뒤 전극을 육안으로 점검한다. 오염이 보이면 이온주입 파트장 승인을 받아 전극을 세정한다.
6. 필라멘트 교체는 IM-PRT-302 문서를 따른다. 교체 부품(자재 코드 SRC-FIL-22)은 자재 시스템 MAT-ON에서 출고를 요청하고 자재 창고(내선 7720)에서 수령한다.
7. 교체나 세정 뒤에는 소스 안정화 운전을 40분간 하고 5절의 확인으로 넘어간다.

## 5. 복구 확인 기준

아래 조건을 모두 충족해야 복구로 인정한다.

- 테스트 웨이퍼 3매를 주입하는 동안 빔 전류 편차가 ±1.5% 이내로 30분간 연속 유지된다.
- 아크 전류 변동이 1분 이동 평균 대비 ±5% 이내다.
- 빔라인 진공도가 3.0×10⁻⁶ Pa 이하다.
- 알람이 24시간 동안 재발하지 않는다.

위 조건을 확인한 뒤 품질팀이 테스트 웨이퍼 결과를 검토하고 승인해야 보류 로트를 해제할 수 있다.

## 6. 안전 주의

이 장비의 추출부와 소스부에는 고전압이 걸린다. 덮개를 열기 전에 고전압을 차단하고 10분 이상 방전 대기한 뒤, 접지봉으로 잔류 전하가 없는지 확인한다. 작업 중에는 전원을 잠그고 표지를 거는 잠금·표지 부착(Lockout-Tagout, LOTO)을 반드시 적용하며, 작업은 2인 1조로 한다. 소스 챔버에는 독성 도펀트 가스가 남아 있을 수 있으므로 개방 전에 퍼지를 마친다. 가스 냄새나 경보를 감지하면 즉시 대피하고 안전환경팀 비상(내선 7119)에 알린다. 소스 주변 부품은 표면 온도가 60℃ 이하일 때만 만진다.

## 7. 보고와 에스컬레이션

1. 알람이 발생하면 즉시 설비 상황실(내선 7701)에 알린다.
2. 20분 안에 이온주입 파트장에게 현재 상태와 조치 계획을 보고한다.
3. 재시도 2회 안에 복구되지 않거나 복구에 2시간 넘게 걸리면 1시간 안에 설비지원센터장에게 보고한다.
4. 보류된 로트가 5개 이상이거나 웨이퍼 손상이 의심되면 품질팀(내선 7600)에 즉시 연락한다.
5. 필라멘트 교체 등 설정값이 바뀌는 작업은 변경 관리 시스템 CMS에 변경 요청을 올린다. 승인은 파트장, 설비지원센터장 순서의 2단계로 받는다.

야간이나 휴일에는 설비지원센터 당직(내선 7700)이 위 보고를 대신 접수한다.

모든 조치는 작업 종료 후 24시간 안에 EQ-LOG에 기록한다. 기록에는 아래 항목을 빠짐없이 포함한다.

| 점검값 | 필라멘트 누적 사용 시간, 소스 가스 압력, 빔라인 진공도 |
| 조치 내용 | 리셋 횟수, 교체한 부품의 자재 코드와 수량, 안정화 운전 시간 |
| 확인 결과 | 테스트 웨이퍼 결과, 품질팀 승인 여부, 로트 해제 시각 |
| 변경 관리 | CMS 변경 요청 번호와 승인 일시 |

같은 원인으로 30일 안에 이 알람이 다시 발생하면 기록에 재발 표시를 하고, 이온주입 파트장이 원인 분석 결과를 덧붙인다.
