# FC-CHG-406 설비 장비 임시 운전 승인 절차
- 문서번호: FC-CHG-406
- 판: v1
- 시행일: 2025-06-08
- 종류: 변경 승인 절차

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적과 적용 대상
이 문서(FC-CHG-406)는 한결반도체 2팹의 장비가 승인된 사양이나 운전 조건을 벗어난 상태에서 한시적으로 운전해야 할 때, 그 운전을 허가하는 절차와 책임을 정한다. 목적은 생산 연속성을 지키면서 품질과 안전 위험이 승인 없이 커지지 않게 하는 것이다. 적용 대상은 설비지원센터가 관리하는 식각, 증착, 화학적 기계적 연마(Chemical Mechanical Polishing, CMP), 세정, 이온주입 파트의 모든 장비이며, 식각 장비 EC-4와 세정 장비 WS-5도 포함한다. 부품 교체나 영구 개조처럼 변경 내용이 계속 남는 경우는 이 절차가 아니라 일반 변경 관리 절차로 처리한다.

## 2. 신청 조건
임시 운전은 다음 조건을 모두 만족할 때만 신청할 수 있다.

1. 이 장비의 일부 기능, 인터락(interlock, 안전 연동 장치) 설정 또는 공정 변수가 승인 범위를 벗어났고, 그 원인과 남은 위험을 설명할 수 있어야 한다.
2. 신청 기간은 최초 14일 이내로 한다. 연장은 1회, 7일까지만 허용한다.
3. 사람이나 설비의 안전과 직접 관련된 인터락을 해제하거나 우회하는 신청은 받지 않으며, 이 경우 장비를 정지한다.
4. 정상 복구 계획과 복구 예정일이 신청서에 있어야 한다.

신청은 장비 담당 파트의 담당자가 변경 관리 시스템(Change Management System, CMS)에서 임시 운전 신청서를 열어 한다. 신청서에는 「TOR-연도-일련번호」 꼴의 관리 번호가 자동으로 붙는다. 신청서에는 벗어난 항목과 정도, 영향받는 제품군, 위험 평가 결과, 운전 중지 기준을 적는다.

## 3. 승인 단계와 승인권자
임시 운전은 위험 등급에 따라 승인 단계가 달라진다. 등급은 신청 담당자가 제안하고 파트장이 확정한다.

| 등급 | 기준 | 승인 단계 |
|---|---|---|
| A | 제품 영향이 없고 설정 편차가 ±5% 이내 | 파트장 |
| B | 편차가 ±5% 초과 ±15% 이내이거나 품질 영향 가능성이 있음 | 파트장 → 품질팀 → 설비지원센터장 |
| C | 편차가 ±15% 초과이거나 화학물질, 고전압 등 안전 영향이 있음 | 파트장 → 품질팀 → 안전환경팀 → 설비지원센터장 |

각 승인권자는 CMS에서 승인 또는 반려를 기록한다. 반려할 때는 사유를 반드시 적는다. 앞 단계의 승인이 없으면 다음 단계로 넘어가지 않는다.

## 4. 처리 기한
승인 기한은 신청서가 접수된 시각부터 센다. A등급은 4시간, B등급은 1영업일, C등급은 3영업일 이내에 최종 결정을 내린다. 승인권자가 보완을 요청하면 기한 계산을 멈추고, 담당자가 보완해 다시 제출한 시각부터 다시 센다. 기한 안에 결정이 나지 않으면 자동 승인으로 보지 않고 운전하지 않은 상태를 유지한다. 이때 신청 담당자는 설비 상황실(내선 7701)에 지연 사실을 알리고, 상황실은 해당 승인권자의 상위 책임자에게 알린다. 승인된 임시 운전의 시작 시각과 종료 예정 시각은 신청서에 확정해서 적는다.

## 5. 검증 요건
임시 운전을 시작하기 전에 시험 웨이퍼 3매를 연속으로 처리해 주요 측정값이 모두 합격 범위 안에 드는지 확인한다. 한 매라도 벗어나면 승인 효력이 생기지 않으며 원인을 확인한 뒤 처음부터 다시 검증한다. 운전하는 동안에는 2시간마다 핵심 변수를 점검해 설비 이력 시스템(EQ-LOG)에 기록한다. 같은 알람이 임시 운전 중 3회 발생하거나 측정값이 신청서의 중지 기준을 넘으면 즉시 운전을 멈추고 파트장에게 보고한다. 품질 판정이 필요하면 품질팀(내선 7600)에 요청한다. 복구를 마친 뒤 정상 운전으로 복귀할 때의 확인 항목과 판정은 FC-OPS-603 문서를 따른다.

## 6. 긴급 변경
장비 정지로 생산 손실이 급격히 커지는데 정해진 승인권자와 연락이 닿지 않을 때만 긴급 변경을 쓸 수 있다. 긴급 변경은 A등급과 B등급에만 허용하며, C등급은 쓸 수 없다.

1. 담당자는 설비지원센터 당직(내선 7700)에 구두 승인을 요청한다.
2. 당직 책임자는 위험을 확인한 뒤 구두 승인하고 승인 시각을 기록한다.
3. 구두 승인의 효력은 최대 48시간이다.
4. 담당자는 구두 승인 후 24시간 이내에 CMS에 사후 신청서를 올려 정식 승인을 받는다.

안전이나 환경에 영향이 있을 수 있다고 판단되면 안전환경팀 비상 내선 7119로 즉시 알리고, 승인 전이라도 운전을 멈춘다. 정식 승인이 24시간 안에 나지 않으면 운전을 중지한다.

## 7. 기록과 사후 검토
신청서, 승인 이력, 검증 결과, 점검 기록은 EQ-LOG와 CMS에 함께 남기며 3년간 보존한다. 임시 운전에 필요한 대체 부품은 자재 시스템(MAT-ON)에서 요청하고, 재고 확인은 자재 창고(내선 7720)에 문의한다. 임시 운전이 끝나면 담당자는 5영업일 이내에 종료 보고서를 올려 실제 운전 기간, 중지 여부, 복구 결과를 적는다. 파트장은 종료 후 10영업일 이내에 사후 검토를 열어 승인 등급이 적절했는지, 재발 방지 조치가 필요한지를 정리한다. 같은 사유로 임시 운전을 연속해서 2회 신청한 경우에는 설비지원센터장이 원인 개선 과제를 별도로 지정한다.
