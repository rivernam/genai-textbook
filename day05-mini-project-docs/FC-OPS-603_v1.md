# FC-OPS-603 설비지원센터 설비 이력 시스템 입력 규정
- 문서번호: FC-OPS-603
- 판: v1
- 시행일: 2024-08-15
- 종류: 운영 규정

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적

이 규정(FC-OPS-603)은 한결반도체 2팹 설비지원센터가 설비에 수행한 예방점검, 고장수리, 교정, 부품 교체, 조건 변경의 내용을 설비 이력 시스템(Equipment Log, 이하 EQ-LOG)에 빠짐없이 같은 방식으로 남기도록 입력 기준과 책임을 정한다. 이력이 정확해야 고장 재발 원인 분석, 부품 수명 관리, 품질 이상 추적을 근거 있게 할 수 있다. 이 규정은 센터가 관리하는 모든 장비의 이력 입력에 공통으로 적용한다.

## 2. 적용 범위

이 규정은 설비지원센터 소속 장비 담당 파트의 엔지니어와 기술원, 그리고 센터 승인을 받아 작업하는 협력사 인력에게 적용한다. 적용 대상 작업은 예방점검, 고장수리, 교정, 부품 교체, 조건 변경이다. 일상 순회 점검은 별도 체크시트로 관리하므로 이 규정의 입력 대상이 아니다. 생산 부서의 로트 처리 기록도 대상이 아니다. 변경 관리 시스템(Change Management System, 이하 CMS)에서 승인된 변경 건은 CMS 승인 번호를 EQ-LOG 이력에 연결해서 입력한다.

## 3. 기준

이력 입력은 다음 기준을 따른다.

1. 이력 유형 코드는 H10(예방점검), H20(고장수리), H30(교정), H40(부품 교체), H50(조건 변경) 다섯 가지만 쓴다. 한 건에는 하나의 코드만 붙이며, 작업이 두 종류에 걸치면 건을 나누어 입력한다.
2. 필수 입력 항목은 일곱 가지다. 장비 식별 번호, 유형 코드, 작업 시작·종료 시각, 증상 또는 작업 목적, 조치 내용, 작업자, 최종 확인 결과이다.
3. 조치 내용은 40자 이상으로 쓴다. "정상 조치", "이상 없음"처럼 내용이 없는 표현만 쓰는 것은 허용하지 않는다.
4. 작업 시각은 실제 작업 시각과 ±10분 이내로 입력한다.
5. 부품을 교체한 건에는 자재 시스템(MAT-ON)의 출고 번호 12자리를 입력한다.
6. H20과 H40 건에는 작업 전후 사진을 2장 이상 첨부하며, 장당 5MB 이하로 한다.
7. 고장 원인을 바로 확정하지 못하면 임시 원인 코드 U99를 입력하고, 5영업일 안에 실제 원인 코드로 바꾼다.

## 4. 절차

1. 작업자는 작업을 시작할 때 EQ-LOG에서 이력 건을 생성하고 착수 시각을 등록한다.
2. 작업자는 작업이 끝나면 2시간 이내에, 늦어도 해당 교대가 끝나기 전에 3절의 필수 항목을 모두 입력한다.
3. 긴급 정지 대응처럼 현장 조치가 급한 건은 30분 이내에 유형 코드와 증상만 간이 입력한다. 나머지 항목은 24시간 이내에 보완한다.
4. 작업자는 입력을 마치면 제출 버튼으로 파트장에게 검토를 요청한다.
5. 파트장은 제출 후 1영업일 이내에 승인하거나 반려한다. 반려할 때는 사유를 한 줄 이상 적는다.
6. 반려된 건은 작업자가 1영업일 이내에 고쳐 다시 제출한다.
7. 승인된 건은 시스템이 자동으로 잠그며, 이후 수정은 5절의 정정 절차로만 한다.
8. 가동 정지가 8시간을 넘긴 H20 건은 승인 후 당일 안에 품질팀에 통보한다.

## 5. 예외와 승인

승인 후 72시간 이내에 발견한 오기는 파트장 승인으로 정정할 수 있다. 정정할 때는 사유를 20자 이상 적는다. 72시간이 지났거나 같은 건의 정정이 3회째가 되면 설비지원센터장이 승인한다. 승인 단계는 작업자 요청, 파트장 검토, 센터장 승인 순서다.

EQ-LOG 장애가 30분 넘게 이어지면 별지 1의 종이 양식으로 임시 기록하고, 복구 후 4시간 이내에 시스템에 다시 입력한다. 종이 양식 원본은 파트장이 서명해 보관한다.

협력사 인력은 시스템 계정이 없으므로 담당 파트 엔지니어가 대리 입력하며, 입력 전에 협력사 작업자의 서명을 확인한다. 촬영이 제한된 구역의 작업은 파트장과 안전환경팀의 2단계 승인을 받아 사진 첨부를 면제할 수 있다. 면제 사유는 이력에 적는다.

## 6. 연락처와 기한

| 구분 | 기한 | 담당 |
|---|---|---|
| 일반 이력 입력 | 작업 종료 후 2시간 | 작업자 |
| 긴급 건 간이 입력 | 30분 | 작업자 |
| 파트장 검토 | 제출 후 1영업일 | 파트장 |
| 임시 원인 코드 확정 | 5영업일 | 작업자 |
| 승인 후 정정 | 72시간 | 파트장, 센터장 |
| 장애 후 재입력 | 복구 후 4시간 | 작업자 |

문의와 장애 신고는 다음 번호로 한다.

- 설비지원센터 당직: 내선 7700
- 설비 상황실: 내선 7701
- 자재 출고 번호 확인(자재 창고): 내선 7720
- 장기 정지 건 통보(품질팀): 내선 7600
- 촬영 제한 구역 승인(안전환경팀): 내선 7119

## 7. 기록과 개정

승인된 이력과 정정 내역, 종이 양식 원본은 5년간 보존한다. 설비지원센터는 매월 1회 승인된 이력의 5%를 무작위로 뽑아 입력 내용을 실제 작업과 대조한다. 대조 결과 정확도가 98% 미만인 파트는 점검 후 2주 이내에 입력 교육을 다시 받는다.

이 규정은 연 1회 검토한다. 개정은 파트장 의견을 모아 설비지원센터장이 승인하며, 개정할 때마다 판 번호를 올려 공지한다. 이 판은 v1이며 시행일은 2024-08-15이다.
