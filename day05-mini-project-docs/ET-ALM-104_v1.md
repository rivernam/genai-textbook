# ET-ALM-104 EC-4 식각 장비 엔드포인트 미검출 알람(코드 E476) 조치 가이드
- 문서번호: ET-ALM-104
- 판: v1
- 시행일: 2025-10-10
- 종류: 알람 조치 가이드

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위와 알람 조건

이 문서(ET-ALM-104)는 식각 장비 EC-4에서 엔드포인트 미검출 알람(코드 E476)이 발생했을 때 식각 파트 엔지니어가 따를 조치 기준을 정한다. 엔드포인트는 광학 발광 분석(OES, Optical Emission Spectroscopy)으로 플라스마 빛의 변화를 읽어 식각이 끝나는 시점을 판정하는 기능이다. 시간 기반으로만 식각하는 레시피와 다른 장비의 알람에는 적용하지 않는다.

이 알람은 다음 두 조건 중 하나가 충족되면 발생한다.

1. 식각을 시작하고 22초가 지나도록 종점 판정 신호의 변화율이 설정 기준에 도달하지 못한다.
2. 감시 파장의 발광 강도가 2,400 카운트 미만인 상태가 5초 이상 이어진다.

## 2. 증상

이 알람이 발생하면 조작 화면에 경고가 표시되고, 해당 웨이퍼는 레시피의 최대 식각 시간 90초까지 진행된 뒤 자동으로 정지한다. 이때 종점을 놓쳐 과식각이 생길 수 있으므로 증상을 빠르게 구분해야 한다. 발광 강도 그래프에서 주로 다음 모습이 나타난다.

- 그래프가 거의 평평하고 강도가 처음부터 낮다. 광 경로의 문제를 의심한다.
- 강도는 충분하지만 잡음 진폭이 ±300 카운트를 넘는다. 커넥터나 검출기의 문제를 의심한다.
- 신호는 정상인데 변화율 판정만 실패한다. 레시피 설정의 문제를 의심한다.
- 같은 로트의 웨이퍼에서 알람이 반복되거나 특정 슬롯에서만 발생한다.

## 3. 추정 원인

원인은 발생 빈도가 높은 순서로 아래 표에 정리한다.

| 순번 | 추정 원인 | 확인 방법 |
|---|---|---|
| 1 | 관찰 창 내벽에 부산물이 쌓여 빛이 줄어듦 | 투과율 측정 결과가 70% 미만인지 확인 |
| 2 | 광섬유 커넥터가 풀렸거나 끝면이 손상됨 | 재체결 전후 발광 강도 비교 |
| 3 | 분광기 광원이나 검출기가 열화됨 | 누적 사용 시간이 1,200시간을 넘었는지 확인 |
| 4 | 감시 파장이나 판정 임계값이 잘못 바뀜 | 변경 관리 시스템(CMS)의 14일 이내 변경 이력 확인 |
| 5 | 공정 가스 유량이 흔들려 플라스마가 약해짐 | 질량 유량 제어기(MFC, Mass Flow Controller) 유량 편차가 ±5%를 넘는지 확인 |

## 4. 조치 절차

1. 알람을 확인하면 해당 로트를 홀드하고 추가 웨이퍼 투입을 중지한다. 설비 상황실(내선 7701)에 즉시 알린다.
2. 설비 이력 시스템(EQ-LOG)에서 최근 24시간의 알람 이력을 확인한다. CMS에서 14일 이내 레시피 변경이 있었는지도 확인한다. 변경이 있었다면 변경 전 값과 비교한다.
3. 발광 강도 그래프를 보고 2절의 증상 유형을 정한다. 강도가 낮으면 4~7단계로, 강도가 정상이면 8단계로 진행한다.
4. 가스 유량 편차가 ±5% 이내인지 확인한다. 벗어나 있으면 가스 공급 점검을 먼저 진행하고, 이 문서의 절차는 중단한다.
5. 챔버를 열지 않고 광섬유 커넥터를 분리해 끝면을 점검한다. 오염이 있으면 전용 천으로 닦고 0.6 N·m 토크로 다시 체결한다. 이어서 시험 식각으로 신호를 비교한다.
6. 관찰 창 투과율을 측정한다. 70% 미만이면 챔버를 열고 창을 세정하며, 반드시 6절의 안전 주의를 지킨다. 세정 후에도 75% 미만이면 창을 교체한다. 교체 부품은 자재 시스템(MAT-ON)으로 청구하고, 수령은 자재 창고(내선 7720)에 문의한다.
7. 광원이나 검출기의 누적 사용 시간이 1,200시간을 넘었으면 교체를 요청한다. 교체 후에는 기준 신호 보정을 다시 실행한다.
8. 임계값이나 감시 파장이 잘못 바뀐 경우, 변경 전 값으로 되돌리려면 CMS 변경 요청이 필요하다. 임의로 고치지 않는다.
9. 복구되기 전에 부득이하게 시간 기반 식각으로 전환해야 하면, 파트장 승인과 품질팀 확인의 2단계를 거친다. 전환은 1회에 최대 4시간까지만 허용한다.

## 5. 복구 확인 기준

조치를 마친 뒤 더미 웨이퍼로 확인하며, 아래 기준을 모두 만족해야 복구로 인정한다.

- 더미 웨이퍼 3매에서 연속으로 종점이 검출된다.
- 감시 파장의 발광 강도가 3,000 카운트 이상이다.
- 잡음 진폭이 ±300 카운트 이내이다.
- 종점 검출 시각이 기준 레시피 대비 ±1.5초 이내이다.
- 이어서 처리하는 첫 로트 25매에서 이 알람이 다시 발생하지 않는다.

품질팀(내선 7600)이 결과를 확인한 뒤에 홀드한 로트를 해제한다.

## 6. 안전 주의

챔버를 열기 전에 퍼지를 10분 이상 실시하고, 챔버 표면 온도가 40℃ 이하임을 확인한다. 작업 전 잠금·표지(LOTO, Lock Out Tag Out)를 적용하고, 작업자 본인이 자물쇠를 직접 채우고 해제한다. 챔버 내부와 관찰 창에는 부식성 부산물이 남아 있을 수 있으므로 내화학 장갑, 보안경, 방진 마스크를 착용한다. 광원은 전원을 끄고 식은 뒤에 분리하며, 광섬유 끝면을 눈으로 직접 들여다보지 않는다. 부산물이 피부나 눈에 닿으면 즉시 15분 이상 흐르는 물로 씻고, 안전환경팀 비상(내선 7119)에 연락한다.

| 연속 2개 로트에서 발생하거나 24시간 내 3회 이상 발생 | 설비지원센터장 | 1시간 이내 |

보고할 때는 발생 시각, 로트 번호, 알람 유형, 지금까지의 조치 내용을 함께 전달한다.

## 8. 조치 기록

조치를 마치면 24시간 이내에 EQ-LOG에 기록한다. 기록 항목은 다음과 같다.

1. 발생 및 복구 시각, 해당 로트 번호와 웨이퍼 수
2. 2절의 증상 유형과 확정한 원인
3. 실시한 조치와 측정값(투과율, 발광 강도, 유량 편차)
4. 교체한 부품과 MAT-ON 청구 번호
5. 시간 기반 식각으로 전환했다면 승인자와 전환 시간

식각 파트장은 다음 영업일에 기록을 검토하고 서명한다. 기록은 3년간 보존한다. 같은 원인이 한 달 안에 반복되면 파트장이 재발 방지 대책을 CMS에 등록한다.
