# CL-PRT-301 WS-5 세정 장비 소모품 교체 기준표
- 문서번호: CL-PRT-301
- 판: v1
- 시행일: 2024-08-03
- 종류: 부품 교체 기준표

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위

이 문서(CL-PRT-301)는 한결반도체 2팹 설비지원센터가 운영하는 세정 장비 WS-5(모델 CL-80)의 소모품 교체 주기와 교체 판단 기준을 정한다. 적용 대상은 세정 파트 엔지니어, 설비지원센터 당직 인원, 자재팀 담당자다. 대상 품목은 약액 필터, 순환 펌프 다이어프램, 공급 배관 원형 밀봉링(O-링), 노즐 팁, 웨이퍼 지지핀, 배기 필터의 여섯 가지다. 챔버 본체, 구동 모터, 제어 보드 같은 비소모성 부품은 이 문서에서 다루지 않고 별도 정비 절차를 따른다. 이 문서의 기준은 2024-08-03부터 적용하며 이전 기준은 같은 날 폐기한다.

## 2. 부품별 교체 주기

이 장비의 소모품은 아래 표의 정기 교체 주기를 따른다. 주기가 두 가지로 적힌 품목은 먼저 도래하는 쪽을 기준으로 한다.

| 부품 | 정기 교체 주기 |
|---|---|
| 약액 필터(공극 0.05 µm) | 누적 처리 4,500매 또는 60일 |
| 순환 펌프 다이어프램 | 누적 가동 2,200시간 |
| 공급 배관 O-링 | 180일 |
| 노즐 팁 | 누적 분사 9,000회 또는 120일 |
| 웨이퍼 지지핀 | 누적 처리 12,000매 |
| 배기 필터 | 90일 |

주기의 기산일은 설비 이력 시스템 EQ-LOG에 남은 마지막 교체 기록의 일시다. 기록이 없는 부품은 설치일을 기산일로 보고 세정 파트장이 EQ-LOG에서 확인한다. 주기가 도래하기 14일 전에 시스템이 세정 파트장에게 알림을 보내며, 파트장은 알림을 받은 날부터 3영업일 안에 교체 일정을 정한다. 정기 교체 기한은 주기 도래일로부터 최대 5일까지 미룰 수 있고, 이를 넘기려면 설비지원센터장의 승인이 필요하다.

## 3. 조기 교체 조건

아래 조건 중 하나라도 확인되면 정기 주기와 관계없이 해당 부품을 조기에 교체한다.

1. 약액 필터: 필터 전후 차압이 0.18 MPa 이상인 상태가 10분 넘게 이어질 때
2. 순환 펌프 다이어프램: 토출 압력의 변동폭이 설정값의 ±8%를 넘는 일이 하루 안에 3회 연속 측정될 때
3. 공급 배관 O-링: 표면 균열이 보이거나 누액 감지 센서가 한 번이라도 동작할 때
4. 노즐 팁: 입자 검사에서 0.1 µm 이상 입자가 웨이퍼 한 장당 30개를 넘는 일이 2매 연속 나올 때
5. 웨이퍼 지지핀: 마모 높이가 0.4 mm를 넘을 때

누액 감지 센서가 동작하면 즉시 이 장비를 정지하고 안전환경팀 비상 내선 7119로 알린다. 그 밖의 조기 교체는 결정한 당일 안에 품질팀(내선 7600)에 통보한다. 조기 교체한 부품은 정기 주기의 기산일을 새로 시작한다.

## 4. 교체 절차 요약

이 절차는 모든 소모품에 공통으로 적용하며, 약액 필터와 다이어프램은 반드시 2인 1조로 작업한다.

1. 설비 상황실(내선 7701)에 정지 시간과 작업 내용을 알리고 장비를 유지보수 모드로 전환한다.
2. 약액 배관을 비운 뒤 탈이온수(DI, deionized water)로 5분간 플러싱하고, 보호구를 착용한다.
3. 부품을 교체하기 전에 새 부품의 로트 번호와 포장 상태를 확인한다.
4. 교체 후 누설 시험을 실시한다. 배관에 0.3 MPa을 가하고 15분 동안 압력 저하가 없어야 한다.
5. 시험 웨이퍼 3매를 처리해 입자 수를 확인하고, 품질팀 확인을 받은 뒤 재가동한다.

작업 시작은 세정 파트장이 승인하고, 재가동은 품질팀 확인이 끝나야 한다. 이 표의 교체 주기를 바꿀 때는 변경 관리 시스템 CMS에 변경 요청을 등록하고 세정 파트장 검토, 품질팀 검토, 설비지원센터장 승인의 3단계를 거친다.

## 5. 재고와 발주 기준

자재팀은 아래 안전재고를 항상 유지한다. 약액 필터 4개, 다이어프램 2개, O-링 6세트, 노즐 팁 10개, 지지핀 24개, 배기 필터 3개다. 재고가 안전재고 이하로 내려가면 자재 시스템 MAT-ON이 발주 요청을 자동으로 만들고, 자재팀 담당자는 그날 안에 발주를 확정한다. 일반 발주의 납기는 10영업일이며, 재고가 0개가 될 우려가 있으면 자재 창고(내선 7720)에 긴급 출고를 요청한다. 부품은 입고 순서대로 쓴다. O-링은 제조일로부터 24개월이 지나면 사용하지 않고 폐기한다. 약액 필터는 포장을 열지 않은 상태로 보관하며, 포장을 연 필터는 당일 안에 설치하지 못하면 사용하지 않는다.

## 6. 교체 기록

교체를 마친 작업자는 24시간 안에 EQ-LOG에 교체 기록을 입력한다. 기록에는 교체 일시, 부품명, 새 부품의 로트 번호, 작업자 직무, 누설 시험 결과, 입자 확인 결과를 반드시 포함한다. 조기 교체는 3절의 조건 번호도 함께 적는다. 24시간을 넘겨 입력한 기록은 세정 파트장이 지연 사유를 덧붙인다. 세정 파트장은 매월 1회 누락과 지연 기록을 점검하고, 품질팀은 분기마다 1회 기록을 표본 감사한다. 교체 기록은 3년간 보존하며, 보존 기간 안에는 삭제하거나 수정할 수 없다. 잘못 입력한 내용은 정정 기록을 추가하는 방식으로 바로잡는다.
