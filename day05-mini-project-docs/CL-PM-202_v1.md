# CL-PM-202 WS-5 세정 장비 월간 예방 점검(PM) 절차서
- 문서번호: CL-PM-202
- 판: v1
- 시행일: 2024-05-25
- 종류: 정기 점검 절차서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적과 주기

이 문서(CL-PM-202)는 한결반도체 2팹 설비지원센터가 세정 장비 WS-5(모델 CL-80)에 대해 매월 시행하는 예방 점검(PM, Preventive Maintenance) 절차를 정한다. 점검의 목적은 약액 공급, 순환, 배기, 웨이퍼 이송 계통의 열화를 고장 나기 전에 찾아내어 공정 중단과 웨이퍼 오염을 막는 것이다.

점검은 월 1회, 매월 둘째 주 화요일 22시에 시작하며 소요 시간은 4시간 이내로 한다. 생산 일정 때문에 계획일을 옮겨야 하면 최대 5일까지만 연기할 수 있고, 연기는 세정 파트장이 승인한다.

## 2. 준비물과 사전 조건

점검자는 2인 1조로 편성하고, 아래 준비물을 점검 시작 전에 갖춘다.

- 디지털 온도계, 차압계, 배기 압력계, 비저항계, 유량 측정 용기(교정 유효기간 내의 것)
- 입자 시험용 웨이퍼 3매
- 순환 필터 예비품 2개
- 내화학 장갑, 보안경, 방독 마스크 등 보호구

사전 조건은 다음과 같다.

1. 점검 24시간 전까지 자재 시스템 MAT-ON에서 예비품 재고를 확인하고, 부족하면 자재 창고(내선 7720)에 요청한다.
2. 점검 시작 시점에 이 장비 안의 로트(lot)를 모두 반출하고 대기 상태로 둔다.
3. 약액 교체나 배액이 필요한 작업은 약액 온도가 40 ℃ 이하로 내려간 뒤에 시작한다.
4. 화학물질 취급, 에너지 차단, 잠금·표지 조치는 FC-SAF-501 문서를 따른다.
5. 작업 시작 전에 설비 상황실(내선 7701)에 점검 시작을 알린다.

## 3. 점검 항목과 기준값

이 장비의 월간 점검 항목과 기준값은 다음 표와 같다. 측정은 모두 대기 상태에서 하며, 온도와 유량은 안정화 후 10분이 지난 값을 쓴다.

| 항목 | 기준값 | 측정 방법 |
|---|---|---|
| 약액조 온도 | 65.0 ℃ ±1.5 ℃ | 3지점 측정 후 평균 |
| 약액 순환 유량 | 12.0 L/min ±0.8 L/min | 유량 측정 용기로 1분간 채취 |
| 순환 필터 차압 | 0.18 bar 이하 | 차압계 판독 |
| 초순수 비저항 | 17.5 MΩ·cm 이상 | 공급 배관 측정 지점 |
| 배기 압력 | -120 ~ -180 Pa | 배기 덕트 측정구 |
| 스핀 척 회전수 편차 | 설정값 ±8 rpm 이내 | 3개 속도 구간에서 확인 |
| 이송 로봇 위치 편차 | 0.3 mm 이하 | 티칭 기준점 대비 |
| 누액 센서 동작 | 3회 연속 정상 | 모의 누액 시험 |
| 입자 시험 | 웨이퍼 1매당 0.12 µm 이상 입자 20개 이하 | 시험 웨이퍼 3매 평균 |

## 4. 작업 절차

1. 설비 이력 시스템 EQ-LOG에서 지난 점검의 잔여 조치 사항을 확인한다.
2. 보호구를 착용하고 에너지 차단과 잠금·표지 조치를 마친 뒤 외관, 배관 이음부, 바닥의 누액 흔적을 눈으로 살핀다.
3. 약액조 온도, 순환 유량, 필터 차압을 표의 순서대로 측정하고 값을 점검표에 적는다.
4. 초순수 비저항과 배기 압력을 측정한다.
5. 스핀 척 회전수와 이송 로봇 위치 편차를 측정한다. 편차가 기준에 근접하면 티칭을 다시 확인한다.
6. 누액 센서에 모의 누액을 가해 경보와 급액 차단이 3회 연속 정상 동작하는지 확인한다.
7. 필터 차압이 기준을 넘었거나 마모된 부품이 보이면 교체하며, 소모 부품 교체 방법은 CL-PRT-301 문서를 따른다.
8. 잠금·표지를 해제하고 공정 조건으로 가동한 뒤, 시험 웨이퍼 3매로 입자 시험을 한다.
9. 점검표의 모든 칸이 채워졌는지 두 점검자가 서로 확인하고 서명한다.

## 5. 판정 기준

판정은 합격, 조건부 합격, 불합격의 세 단계로 한다.

- **합격**: 모든 항목이 기준값 안에 있다.
- **조건부 합격**: 한 항목 이상이 기준을 벗어났으나 벗어난 폭이 기준 허용 범위의 10 % 이내이고, 재측정에서도 같은 결과가 나온 경우다. 7일 이내에 조치하고 재확인한다.
- **불합격**: 입자 시험이나 누액 센서 시험에 실패했거나, 필터 차압이 0.25 bar를 넘은 경우다. 이 밖에 재측정에서 기준을 크게 벗어난 항목이 있어도 불합격으로 본다.

합격과 조건부 합격은 세정 파트장이 승인하고 생산에 복귀시킨다. 불합격은 세정 파트장의 검토 후 설비지원센터장이 승인해야 생산에 복귀시킬 수 있으며, 품질팀 확인이 끝나기 전에는 로트를 투입하지 않는다.

## 6. 이상 발견 시 조치

이상을 발견하면 즉시 작업을 멈추고 이 장비를 가동 금지 상태로 둔다. 누액이나 약액 냄새가 있으면 안전환경팀 비상(내선 7119)에 먼저 연락하고 현장을 벗어난다. 이어서 설비지원센터 당직(내선 7700)과 설비 상황실(내선 7701)에 알린다.

입자 시험에 실패하면 품질팀(내선 7600)에 알리고, 직전 점검 이후 처리된 로트의 영향 평가를 요청한다. 부품 교체가 필요하면 자재 창고(내선 7720)에 긴급 출고를 요청한다.

설정값이나 레시피(공정 조건표)를 바꿔야 하면 변경 관리 시스템 CMS에 변경 요청을 올려 승인받은 뒤에만 바꾼다. 불합격 건은 원인을 조치한 뒤 48시간 이내에 해당 항목을 다시 점검한다. 같은 항목이 2개월 연속 기준을 벗어나면 세정 파트장이 원인 분석 보고서를 작성한다.

## 7. 기록과 보고

점검자는 점검 종료 후 24시간 이내에 EQ-LOG에 작업 유형 코드 PMM-31로 결과를 입력한다. 측정값 원본이 담긴 점검표는 스캔하여 첨부한다. 불합격 항목에는 사유 코드 NG-C2(기준 초과)와 조치 내용을 함께 적는다.

세정 파트장은 점검 후 3영업일 이내에 결과 요약을 설비지원센터장에게 보고한다. 조건부 합격이나 불합격 건은 조치 기한과 담당자를 보고서에 적는다. 점검 기록은 3년간 보존하며, 보존 기간 중에는 임의로 수정하거나 삭제하지 않는다. 기록을 정정해야 하면 정정 사유와 정정자를 남긴다.
