# IM-CASE-706 IM-1 이온주입 소스 필라멘트 수명 경고 장애 사례 보고서
- 문서번호: IM-CASE-706
- 판: v1
- 시행일: 2025-09-15
- 종류: 장애 사례 보고서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 개요

이 문서는 2025년 9월 3일 이온주입 장비 IM-1(모델 IX-200)에서 발생한 소스 필라멘트 수명 경고 장애의 경과, 영향, 원인, 조치, 재발 방지 대책을 정리한 사례 보고서(IM-CASE-706)이다. 소스 필라멘트는 이온을 만드는 열전자 방출 부품이다. 알람 SRC-FIL-214는 필라멘트 누적 통전 시간이 설정 수명 380시간의 90%인 342시간에 이르면 발생한다. 이번 건은 경고가 나온 뒤에도 교체가 이루어지지 않아 필라멘트가 371시간에 끊어지고 가동이 멈춘 사례이다. 교육 실습용 가상 문서이므로 담당자는 직무와 부서로만 적는다.

## 2. 발생 경과

1. 9월 1일 22:40 : 이 장비의 누적 통전 시간이 342시간에 이르러 경고 알람이 발생했다. 경고는 설비 상황실 화면에만 표시되었고, 야간 운전원은 "다음 정비 때 교체"라고 메모만 남겼다.
2. 9월 2일 : 교체 작업은 설비 이력 시스템 EQ-LOG에 등록되지 않았고, 교대 인수인계에서도 이 경고는 언급되지 않았다.
3. 9월 3일 03:15 : 누적 371시간에서 필라멘트가 단선되었다. 빔 전류가 42 mA에서 8 mA 미만으로 떨어졌고 인터락(보호 정지 장치)이 작동해 장비가 멈췄다.
4. 03:22 : 설비 상황실(내선 7701)이 설비지원센터 당직(내선 7700)을 호출했고, 당직 엔지니어가 03:50에 현장에 도착했다.
5. 04:10 : 자재 창고(내선 7720) 확인 결과 예비 필라멘트 재고가 0개였다. 긴급 발주분은 14:10에 입고되었다.
6. 17:30 교체를 마쳤고 20:05에 가동을 재개했다.

## 3. 영향 범위

| 항목 | 내용 |
|---|---|
| 정지 시간 | 16시간 50분 (03:15~20:05) |
| 영향 로트 | 진행 중 1로트 25매, 대기 보류 2로트 50매, 합계 3로트 75매 |
| 품질 영향 | 중단 로트 마지막 6매 중 1매가 선량 편차 허용치(±2.0%)를 넘어 폐기, 나머지 74매는 재검사 후 합격 |
| 납기 영향 | 후속 공정 투입이 최대 1일 지연 |
| 안전 영향 | 인명 피해와 가스 · 방사선 관련 이상 없음 |

품질팀(내선 7600)에는 정지 후 40분 안에 통보했다. 다른 장비로의 파급은 없었다.

## 4. 원인 분석

직접 원인은 필라멘트가 설정 수명에 가까워진 상태에서 계속 가동된 것이다. 최근 교체한 필라멘트 3개의 평균 수명은 372시간이었다. 경고 시점(342시간)부터 설정 수명(380시간)까지는 38시간뿐이어서, 연속 가동하면 약 1.6일 만에 소진되는 여유였다. 근본 원인은 세 가지이다.

1. 경고가 화면 표시에 그쳐 교체 작업이 자동으로 등록되지 않았고, 당직으로도 연계되지 않았다.
2. 예비 필라멘트의 안전재고는 2개로 정해져 있었으나 8월 말 사용 뒤 보충 발주가 빠졌다. 자재 시스템 MAT-ON에서 재고가 0이 되어도 경보가 나오지 않았다.
3. 교대 인수인계 점검표에 미해결 경고 항목이 없어 야간 운전원의 메모가 주간 근무자에게 전달되지 않았다.

## 5. 조치 내용

1. 필라멘트와 인출 전극을 교체하고 소스 챔버 내부 증착물을 제거했다.
2. 빔 조정 후 시험 웨이퍼 3매로 시트 저항 균일도가 ±1.5% 이내인지 확인했다.
3. 보류 2로트는 품질팀 승인 후 재개했고, 중단 로트는 전수 재검사했다.
4. 단선 이후 장비 상태 확인과 알람 해제 순서는 IM-ALM-106 문서를 따른다.
5. 자재팀이 예비 필라멘트 3개를 추가 발주해 9월 5일까지 입고를 마쳤다.
6. 이번 건의 처리 내용을 EQ-LOG에 기록 번호 EL-250903-017로 남겼다.

## 6. 재발 방지 대책

1. **경고 2단계화** : 1차 경고는 현행대로 342시간(90%)에 내고, 2차 경고를 361시간(95%)에 추가한다. 2차 경고에서는 변경 관리 시스템 CMS에 교체 작업이 자동 등록되고 이온주입 파트장과 당직(내선 7700)에 문자가 발송된다.
2. **교체 기한** : 1차 경고 후 24시간 안에 교체 일정을 확정하고, 2차 경고 후 12시간 안에 교체를 마친다.
3. **재고 기준** : 예비 필라멘트의 안전재고를 3개, 발주점을 2개로 올린다. MAT-ON 재고가 발주점 아래로 내려가면 자재팀에 자동 알림이 가도록 한다. 재고 확인과 출고 운영은 FC-OPS-611 문서를 따른다.
4. **정기 점검** : 이온주입 파트가 매주 월요일 예비품 수량과 경고 이력을 점검한다.
5. **인수인계** : 교대 점검표에 "미해결 경고 및 교체 예정" 항목을 추가해 2025년 9월 22일부터 적용한다.
6. **승인 절차** : 수명 설정값을 바꿀 때는 이온주입 파트장, 설비지원센터장, 품질팀 순의 3단계 승인을 거친다.
7. **교육** : 분기마다 1회 모의 경고 대응 훈련을 하고, 첫 훈련은 2025년 10월 31일까지 마친다.
