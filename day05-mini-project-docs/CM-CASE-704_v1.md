# CM-CASE-704 CP-3 CMP 슬러리 유량 저하 장애 사례 보고서
- 문서번호: CM-CASE-704
- 판: v1
- 시행일: 2025-05-02
- 종류: 장애 사례 보고서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 개요

이 문서는 CMP(Chemical Mechanical Planarization, 화학적 기계적 평탄화) 장비 CP-3(모델 PL-300)에서 2025-04-24에 발생한 슬러리 유량 저하 장애를 정리한 사례 보고서(CM-CASE-704)이다. 이 장비는 연마 중 슬러리 공급 유량이 기준 아래로 떨어져 알람 SLR-F-214를 내고 자동 정지하였다. 장애는 약 3시간 35분 지속되었고, 원인은 슬러리 공급 라인 필터의 막힘으로 확인되었다. 이 보고서는 경과, 영향, 원인, 조치, 재발 방지 대책을 기록하며 교육 실습 자료로 쓴다.

## 2. 발생 경과

장애는 야간 근무 시간대에 시작되어 아침 교대 전에 복구되었다. 시간대별 경과는 다음과 같다.

| 시각 | 내용 |
|---|---|
| 02:10 | 연마 중 슬러리 유량이 정상 하한 180 mL/min 아래로 내려가 경고 표시 |
| 02:25 | 유량 150 mL/min 미만이 30초 이상 지속되어 알람 발생, 장비 자동 정지 |
| 02:32 | 설비지원센터 당직(내선 7700)이 접수하고 설비 상황실(내선 7701)에 보고 |
| 03:05 | CMP 파트 엔지니어가 현장에 도착하여 슬러리 탱크 잔량과 공급 펌프 상태를 확인, 이상 없음 |
| 04:20 | 라인 필터 전후 차압이 0.08 MPa로 측정되어 막힘으로 판단 |
| 05:10 | 라인 필터 교체 완료 |
| 05:50 | 더미 웨이퍼 3매로 시운전하여 유량 회복 확인 |
| 06:00 | 정상 재가동, EQ-LOG(설비 이력 시스템)에 기록 |

## 3. 영향 범위

정지 시점에 이 장비에는 2개 로트, 총 48매가 있었다. 한 로트는 연마 도중 멈추어 웨이퍼 12매의 연마가 끝나지 않았다. 품질팀(내선 7600)이 이 12매를 격리하고 잔막 두께를 측정하였다. 편차가 규격 안에 있는 것으로 확인되어 재연마 후 공정에 복귀시켰고, 폐기 웨이퍼는 없었다. 나머지 로트 36매는 영향이 없었다. 다만 대기 로트 5개의 투입이 최대 4시간 지연되어 후속 공정의 일정 조정이 필요했다. 인명 피해와 슬러리 누출은 없었다.

## 4. 원인 분석

직접 원인은 슬러리 공급 라인 필터에 응집 입자가 쌓여 유로가 좁아진 것이다. 이로 인해 펌프 토출 압력은 유지되었지만 실제 공급 유량이 줄었다. 근본 원인은 다음 세 가지이다.

1. 필터 교체 주기는 누적 400시간인데, 사고 시점의 사용 시간은 412시간이었다. 교체용 필터의 재고가 부족해 MAT-ON(자재 시스템)의 입고가 늦어졌고, 교체가 한 차례 연기되었다.
2. 필터 차압이 일일 점검표에 없어 막힘이 진행되는 것을 알아채지 못했다.
3. 유량 경고값(180 mL/min)과 알람 정지값(150 mL/min)의 간격이 좁아, 경고 후 조치할 시간이 거의 없었다.

## 5. 조치 내용

당직과 담당 파트는 즉시 다음과 같이 조치하였다.

1. 이 알람이 발생하면 정지 확인, 웨이퍼 보호, 보고의 순서로 대응한다. 알람 대응 절차는 CM-ALM-101 문서를 따른다.
2. 슬러리 탱크와 펌프를 점검하여 공급원 이상이 아님을 확인하였다.
3. 차압 측정으로 필터 막힘을 확인하고, 자재 창고(내선 7720)에서 교체용 필터를 출고받아 교체하였다.
4. 라인을 순수로 10분간 플러싱한 뒤 더미 웨이퍼 3매로 유량과 연마량을 확인하였다.
5. 격리한 웨이퍼 12매는 품질팀의 판정을 받은 뒤 재연마하였다.
6. 조치 내용과 측정값은 당일 EQ-LOG에 입력하였다.

## 6. 재발 방지 대책

재발 방지 대책은 아래와 같이 정하였다. 필터 교체 주기와 경고값은 설정을 바꾸는 일이므로 CMS(변경 관리 시스템)에 등록하고, 파트장과 설비지원센터장의 2단계 승인을 받아 시행한다. 변경 관리 절차는 FC-CHG-403 문서를 따른다.

| 항목 | 내용 | 담당 | 기한 |
|---|---|---|---|
| 필터 교체 주기 단축 | 누적 400시간에서 300시간으로 변경 | CMP 파트 | 2025-05-09 |
| 차압 일일 점검 | 점검표에 추가, 0.03 MPa 초과 시 당일 파트장에게 보고 | CMP 파트 | 2025-05-09 |
| 사전 경고값 상향 | 경고값을 180 mL/min에서 170 mL/min 추가 단계로 세분화하여 조치 여유 확보 | CMP 파트 | 2025-05-16 |
| 필터 안전 재고 | 최소 4개를 유지하고 3개 이하이면 자동 발주 | 자재팀 | 2025-05-16 |
| 효과 확인 | 3개월간 월 1회 차압과 교체 이력을 검토 | 설비지원센터 | 2025-08-15 |

## 7. 관련 문서

- 5절의 알람 대응 문서와 6절의 변경 관리 문서
- EQ-LOG의 2025-04-24 장애 조치 이력
- CMS에 등록된 필터 교체 주기 및 경고값 변경 요청
- 품질팀의 격리 웨이퍼 측정 결과

문의는 설비지원센터 당직(내선 7700)으로 한다.
