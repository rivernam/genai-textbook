# IM-PM-203 IM-1 이온주입 장비 분기 오버홀 점검 절차서
- 문서번호: IM-PM-203
- 판: v1
- 시행일: 2025-05-23
- 종류: 정기 점검 절차서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적과 주기

이 문서(IM-PM-203)는 IM-1 이온주입 장비의 분기 오버홀 점검 절차를 정한 것이다. 이온 소스, 빔라인, 진공계, 냉각계의 상태를 일정 수준으로 유지하고 예기치 않은 정지를 줄이는 것이 목적이다. 적용 대상은 이온주입 파트가 운영하는 이 장비 1대다. 점검은 13주마다 한 번 실시하며 허용 편차는 ±5일이다. 1회 점검에는 8시간을 계획한다. 빔 전류 불안정 알람 AL-IM-417이 24시간 안에 3회 이상 발생하면 정기 일정과 관계없이 이 절차를 앞당겨 적용한다.

## 2. 준비물과 사전 조건

준비물은 다음과 같다.

- 헬륨 누설 검출기와 교정 유효기간이 남은 진공 게이지
- 소스 필라멘트와 아크 챔버 교체 키트. 자재 시스템 MAT-ON에서 작업 3영업일 전까지 예약한다.
- 내화학 장갑, 방진복, 개인용 가스 검지기
- 도즈(주입량) 확인용 시험 웨이퍼 3매

사전 조건은 다음과 같다.

1. 작업 전날까지 진행 중인 로트를 모두 반출하고 장비를 점검 모드로 전환한다.
2. 고전압 전원과 도펀트 가스 라인의 잠금·표지 및 독성 가스 취급은 FC-SAF-501 문서를 따른다.
3. 고전압 전원을 차단한 뒤 30분이 지나고 잔류 전압이 50 V 이하임을 확인한 다음에 챔버를 연다.
4. 작업 허가는 이온주입 파트장이 승인한다. 소스 교체를 포함하면 설비지원센터장이 추가로 승인하며, 이때는 2단계 승인이다.
5. 작업은 2인 1조 이상으로 한다.

## 3. 점검 항목과 기준값

| 점검 항목 | 기준값 | 측정 조건 |
|---|---|---|
| 빔라인 기본 압력 | 2.0×10⁻⁶ Torr 이하 | 펌프 가동 4시간 후 |
| 헬륨 누설률 | 5×10⁻⁹ mbar·L/s 이하 | 챔버 체결부 전체 |
| 소스 필라멘트 누적 사용 | 450시간 도달 시 교체 | 아크 시간 기준 |
| 냉각수 유량 | 12 L/min 이상 | 소스 및 전극 냉각 라인 |
| 냉각수 온도 | 22±2 ℃ | 공급 측 |
| 빔 전류 드리프트 | 30분간 ±2.5% 이내 | 시험 주입 중 |
| 도즈 균일도 | 1σ(표준편차) 0.8% 이하 | 시험 웨이퍼 3매 평균 |
| 도펀트 가스 누설 경보 | 0.5 ppm 미만 | 가스 캐비닛 주변 |

모든 측정값은 작업 중 현장 기록지에 먼저 적고, 작업이 끝난 뒤 시스템에 옮긴다. 측정 장비는 교정 유효기간 안의 것만 쓴다.

## 4. 작업 절차

1. 장비를 정지하고 고전압 전원을 차단한 뒤 잠금·표지를 건다. 잔류 전압을 확인한다.
2. 소스 챔버를 질소로 대기압까지 복귀시키고 10분 이상 퍼지한 뒤 개방한다.
3. 필라멘트와 아크 챔버의 마모 상태를 확인한다. 누적 사용이 기준에 도달했거나 마모가 뚜렷하면 교체한다.
4. 인출 전극과 빔라인 어퍼처(빔 통과 구멍)를 세정하고 오염 정도를 기록한다. 교체한 부품의 재기동 시험은 IM-PRT-301 문서를 따른다.
5. 챔버를 닫고 펌프다운한 뒤 압력과 헬륨 누설률을 측정한다.
6. 냉각수 유량과 온도를 측정한다.
7. 시험 웨이퍼 3매에 주입하여 빔 전류 드리프트와 도즈 균일도를 측정한다.
8. 모든 항목이 끝나면 잠금·표지를 해제하고 점검 모드를 풀어 장비를 생산에 복귀시킨다.

## 5. 판정 기준

3절의 모든 항목이 기준값을 만족하면 합격이다. 한 항목이 기준값을 10% 이내로 벗어나면 조건부 합격으로 하고, 72시간 안에 재측정하여 최종 판정한다. 두 항목 이상이 벗어나거나 한 항목이 10%를 넘게 벗어나면 불합격이며 생산 복귀를 보류한다. 가스 누설 경보 항목은 조건부 판정을 적용하지 않는다. 최종 판정은 이온주입 파트장이 하고, 시험 웨이퍼 결과는 품질팀이 확인한다.

## 6. 이상 발견 시 조치

- 도펀트 가스 농도가 0.5 ppm 이상이면 즉시 작업을 중단하고 가스 밸브를 잠근 뒤 인원을 대피시킨다. 안전환경팀 비상 7119로 알린다.
- 압력이나 누설률이 기준을 넘으면 체결부를 다시 조이고 재측정한다. 재측정은 2회까지 하며, 그래도 불량이면 설비지원센터 당직 7700으로 연락한다.
- 교체 부품이 부족하거나 불량이면 자재 창고 7720에 긴급 출고를 요청한다.
- 도즈 균일도가 불합격이면 품질팀 7600에 알리고, 이 장비의 생산 투입을 보류한다.
- 부품 규격이나 작업 방법을 바꿔야 하면 변경 관리 시스템 CMS에 등록하고 승인을 받은 뒤 진행한다.
- 작업이 예정 시간을 2시간 넘기게 되면 설비 상황실 7701에 알린다.

## 7. 기록과 보고

작업자는 작업이 끝난 뒤 24시간 안에 설비 이력 시스템 EQ-LOG에 다음 내용을 입력한다.

- 3절의 측정값과 판정 결과
- 교체한 부품의 이름과 Lot 번호
- 시험 웨이퍼 결과
- 이상 발견 및 조치 내용

이온주입 파트장은 2영업일 안에 점검 결과를 설비지원센터장에게 보고한다. 점검 기록은 3년간 보존한다.
