# FC-OPS-611 설비지원센터 장비 다운타임 집계 규정
- 문서번호: FC-OPS-611
- 판: v1
- 시행일: 2024-08-19
- 종류: 운영 규정

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적
이 규정은 한결반도체 2팹 설비지원센터가 관리하는 장비의 다운타임(가동 중단 시간)을 같은 기준으로 구분하고 집계하는 방법을 정한다. 대상은 식각 장비 EC-4, 증착 장비 DP-2, CMP 장비 CP-3, 세정 장비 WS-5, 이온주입 장비 IM-1을 포함한 센터 관리 장비이다. 파트마다 가동률과 고장 통계가 다르게 산출되는 일이 없도록 이 문서(FC-OPS-611)에서 코드, 기한, 승인 단계를 정한다. 개선 활동의 우선순위는 이 기준으로 집계한 결과에 따라 판단한다.

## 2. 적용 범위
이 규정은 설비지원센터가 관리하는 모든 양산 장비와 이를 담당하는 식각, 증착, CMP, 세정, 이온주입 파트에 적용한다. 파트장은 소속 장비의 입력과 확인을 책임지고, 설비지원센터장은 월간 집계의 최종 승인을 맡는다. 품질팀, 안전환경팀, 자재팀은 정지 사유를 확인할 때 협조한다.

다음의 경우에는 이 규정을 적용하지 않는다.
- 설치 후 인수 시험을 마치기 전의 장비
- 공정 개발 목적의 평가 전용 운전 중 정지

## 3. 기준
다운타임은 장비가 생산 가능 상태를 벗어난 시각부터 복귀 확인을 마친 시각까지의 경과 시간이다. 분 단위로 올림하여 기록한다. 10분 이상 정지는 건별로 집계한다. 10분 미만 정지는 교대조별로 합산하여 소정지 1건으로 기록한다.

모든 다운타임은 아래 다섯 가지 코드 중 하나로 분류한다.

| 코드 | 구분 | 판단 기준 |
|---|---|---|
| DT-P | 계획 정비 | 정지 48시간 전까지 등록한 예방 정비 |
| DT-U | 비계획 고장 | 알람 정지나 부품 고장으로 인한 정지 |
| DT-W | 대기 | 자재나 인력을 기다린 시간 중 최초 30분을 넘는 부분 |
| DT-Q | 품질 홀드 | 품질팀의 홀드 요청으로 인한 정지 |
| DT-X | 외부 요인 | 유틸리티 공급 이상, 안전환경팀의 정지 지시 |

월 가동률(%)은 (달력 시간 − 전체 다운타임) ÷ 달력 시간 × 100으로 계산한다. 관리 목표는 94.0% 이상이다. 가동률이 91.0% 미만이면 해당 파트장이 개선 계획서를 제출한다. 비계획 고장(DT-U)이 달력 시간의 2.5%를 넘는 장비도 같은 조치를 한다.

단일 건이 8시간을 넘으면 장기 다운타임으로 구분한다. 같은 원인의 정지가 30일 안에 3회 이상 발생하면 반복 고장으로 구분하고, 재발 방지 검토 대상에 올린다.

## 4. 절차
1. 정지가 발생하면 담당 파트 엔지니어는 인지한 때부터 15분 이내에 설비 이력 시스템 EQ-LOG(Equipment Log)에 정지 건을 열고 정지 시각을 기록한다.
2. 원인을 확인한 뒤 위 다섯 가지 코드 중 하나를 선택한다. 정지가 끝난 후 4시간 이내에 원인, 조치 내용, 복귀 시각을 입력한다.
3. 복귀 시각은 파트장 또는 지정 대리인이 시험 웨이퍼 결과를 확인한 뒤 정한다. 품질 판정이 필요한 정지는 품질팀의 복귀 동의를 받은 시각을 기준으로 한다.
4. 대기(DT-W)로 분류하는 건에는 자재 시스템 MAT-ON의 요청 번호를 함께 적는다. 자재팀은 자재 창고(내선 7720)를 통해 출고 시각을 확인해 준다.
5. 파트장은 입력된 건을 24시간 이내에 확인하고 코드의 적정성을 승인한다.
6. 센터 집계 담당자는 매월 3영업일 18:00까지 전월 실적을 확정하고, 5영업일 이내에 센터장에게 월간 보고서를 제출한다.
7. 장기 다운타임은 인지한 때부터 30분 이내에 설비 상황실(내선 7701)에 구두로 보고하고, 이후 매 8시간마다 진행 상황을 갱신한다.

## 5. 예외와 승인
월 마감 전의 코드 변경은 파트장의 승인 1단계로 처리한다. 마감 후 정정은 변경 관리 시스템 CMS(Change Management System)로 요청하며, 마감 후 5영업일 이내에 접수한다. 승인은 파트장, 센터장의 2단계로 한다. 품질 홀드(DT-Q) 건을 변경할 때는 품질팀 확인이 추가되어 3단계가 된다.

4시간 이내 입력 기한을 지키지 못한 경우에는 사유서를 첨부하고 파트장 승인을 받는다. 입력 지연이 한 달에 3건을 넘는 파트는 센터장 점검 대상이 된다.

안전환경팀의 지시로 정지한 시간은 외부 요인(DT-X)으로 분류하고, 안전환경팀이 발급한 확인서를 첨부한다. 이 시간을 가동률 산정에서 제외하려면 센터장의 승인이 필요하다. 단일 건이 72시간을 넘으면 센터장이 주관하는 점검 회의에서 복구 계획과 코드 분류를 다시 확인한다. 제외 승인은 건별로 하며, 포괄 승인은 하지 않는다.

## 6. 연락처와 기한
| 상황 | 연락처 | 기한 |
|---|---|---|
| 정지 발생 시 근무 시간 외 지원 | 설비지원센터 당직 7700 | 즉시 |
| 장기 다운타임 보고 | 설비 상황실 7701 | 인지 후 30분 이내 |
| 품질 홀드 해제와 복귀 동의 | 품질팀 7600 | 해제 요청 후 당일 |
| 안전 사유 정지 확인서 | 안전환경팀 비상 7119 | 정지 후 24시간 이내 |
| 자재 출고 시각 확인 | 자재 창고 7720 | 입력 기한 내 |

정리하면 EQ-LOG 입력은 정지 종료 후 4시간, 파트장 확인은 24시간, 월 집계 확정은 매월 3영업일 18:00, 월간 보고는 5영업일 이내, 마감 후 정정 접수는 5영업일 이내이다. 기한의 기준 시각은 EQ-LOG에 남은 입력 시각이다.

## 7. 기록과 개정
다운타임 기록, 승인 내역, 첨부 확인서는 EQ-LOG에 3년간 보존한다. 월간 보고서는 센터 공유 폴더에 저장하고, 정정이 있으면 정정 전후의 값과 사유를 함께 남긴다. 반복 고장과 장기 다운타임 건은 재발 방지 검토 결과를 해당 정지 건에 연결하여 보관한다.

이 규정은 매년 8월에 정기 검토한다. 코드나 기준값을 바꿀 때는 센터장의 승인을 받고, 판 번호를 올려 시행일을 명시한다. 개정 내용은 시행 5영업일 전까지 각 파트장이 소속 엔지니어에게 전달한다. 이 문서는 2024-08-19에 v1으로 제정하여 시행한다.
