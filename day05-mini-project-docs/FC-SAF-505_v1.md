# FC-SAF-505 설비 밀폐 공간(챔버 내부) 작업 기준
- 문서번호: FC-SAF-505
- 판: v1
- 시행일: 2025-11-14
- 종류: 안전 작업 기준

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위

이 기준은 한결반도체 2팹 설비지원센터가 관리하는 장비의 챔버(공정 반응 공간) 내부에 작업자의 머리나 몸통이 들어가는 모든 작업에 적용한다. 식각 장비 EC-4(모델 VX-ETCH9)와 증착 장비 DP-2(모델 CV-700)를 비롯해 CMP, 세정, 이온주입 파트의 장비가 모두 대상이다. 팔만 넣는 단순 닦기 작업은 제외한다. 다만 머리가 개구부 안쪽으로 들어가면 이 기준을 따른다. 이 기준(FC-SAF-505)은 시행일인 2025-11-14 이후 시작하는 작업부터 적용하며, 협력업체 인원에게도 똑같이 적용한다.

## 2. 위험 요인

챔버 내부 작업의 위험은 다음 다섯 가지로 구분한다.

1. 산소 결핍: 질소 퍼지(불활성 가스로 내부를 씻어 내는 작업) 뒤에는 내부 산소 농도가 낮게 남을 수 있다. 19.5% 미만이면 출입을 금지한다.
2. 잔류 유해 가스: 공정 부산물이 벽면에 남아 있다가 챔버를 열면 방출된다. 부식성 가스가 1.5 ppm을 넘으면 출입할 수 없다.
3. 고온 표면: 내벽과 전극 표면이 45℃를 넘으면 화상 위험이 있다.
4. 에너지 재투입: 고주파 전원, 진공 펌프, 게이트 밸브가 작업 중 동작하면 협착이나 감전 사고가 난다.
5. 갇힘: 개구부가 좁아 쓰러진 작업자를 꺼내는 데 시간이 걸린다. 구조가 늦어지면 곧바로 치명적인 결과로 이어진다.

## 3. 작업 전 확인

작업 책임자는 작업 시작 전에 아래 항목을 모두 확인하고 밀폐 공간 작업 허가서(서식 CS-12)에 기록한다. 허가서는 장비 담당 파트장, 안전환경팀, 설비지원센터장 순으로 3단계 승인을 받아야 한다. 허가서의 유효 시간은 발급 후 8시간이며, 시간이 지나면 새로 발급받는다.

| 확인 항목 | 기준 |
|---|---|
| 사전 환기 | 퍼지 종료 후 공기 치환 25분 이상 |
| 산소 농도 | 19.5~23.5% |
| 잔류 부식성 가스 | 1.5 ppm 이하 |
| 내벽 온도 | 45℃ 이하 |
| 가스 측정기 교정 | 최근 90일 이내 |

측정은 챔버 안쪽 상·중·하 3개 지점에서 각각 하며, 가장 불리한 값을 기준으로 판정한다. 작업자와 감시자는 밀폐 공간 교육을 이수해야 하고, 교육 유효 기간은 12개월이다.

## 4. 작업 절차

1. 이 장비를 정지하고 잠금·표지 장치(LOTO, Lockout-Tagout)로 전원, 진공 펌프, 게이트 밸브, 가스 공급을 차단한다. 잠금 장치마다 작업자 개인 자물쇠를 건다.
2. 설비 이력 시스템 EQ-LOG에 작업 개시를 기록하고 설비 상황실(내선 7701)에 알린다.
3. 개구부 앞에 감시자 1명을 상시 배치하고 출입 명부와 반입 공구 목록을 작성한다. 감시자는 작업을 겸할 수 없다.
4. 입장 직전에 3절의 항목을 다시 측정한다. 작업자는 연속 측정기를 몸에 지니고 들어가며, 산소가 19.5% 미만으로 떨어져 경보가 울리면 즉시 나온다.
5. 동시 입장은 최대 2명이다. 연속 작업은 40분 이내로 하고, 나온 뒤 15분 이상 쉬며 환기 상태를 다시 측정한다.
6. 감시자는 5분 간격으로 작업자를 호출한다. 30초 안에 응답이 없으면 비상 대응으로 전환한다.
7. 작업을 마치면 반입 목록과 공구 수량을 대조하고 내부 잔류물을 확인한다. 이어서 파트장 입회 아래 잠금을 역순으로 해제하고, 재가동 전 파티클 점검을 품질팀(내선 7600)에 요청한다.

## 5. 보호구

| 항목 | 기준 |
|---|---|
| 전신 보호복 | 내화학·정전기 방지 소재, 작업마다 새것 착용 |
| 방독 마스크 | 입장 시 상시 착용, 정화통은 개봉 후 30일 이내 교체 |
| 장갑 | 내화학 장갑 위에 보호 장갑을 겹쳐 2중 착용 |
| 안전모·안전화 | 머리 보호와 미끄럼 방지 기능 확인 |
| 구조용 안전 벨트 | 길이 3 m 몸줄을 입구 인양 장치에 연결 |

보호구는 착용 전에 작업자와 감시자가 서로 파손 여부를 확인한다. 불량이 있으면 교체하며, 교체품은 자재 창고(내선 7720)에서 받는다.

## 6. 비상 대응

1. 경보가 울리거나 작업자가 응답하지 않으면 감시자는 입구를 떠나지 않고 안전환경팀 비상(내선 7119)과 설비지원센터 당직(내선 7700)에 동시에 연락한다.
2. 감시자는 어떤 경우에도 혼자 들어가지 않는다. 몸줄을 인양 장치로 당겨 꺼내거나, 공기호흡기를 착용한 구조 인력의 도착을 기다린다.
3. 안전환경팀 구조 인력은 신고 후 3분 이내 현장 도착을 목표로 한다.
4. 꺼낸 작업자의 의식이 없으면 즉시 산소를 공급하고 응급처치를 하며 구급 이송을 요청한다.
5. 사고 현장은 보존한다. 작업 책임자는 24시간 이내에 사고 보고서를 제출하고, 설비지원센터장과 안전환경팀이 공동으로 원인을 조사한다.
6. 안전환경팀은 분기 1회 구조 훈련을 실시하며, 장비 담당 파트는 감시자 전원을 참석시킨다.

## 7. 위반 시 조치

허가서 없이 입장하거나 감시자를 두지 않은 경우에는 즉시 작업을 중지한다. 해당 작업자는 3일간 작업이 정지되고 4시간의 재교육을 받아야 한다. 측정값 조작이나 허위 기록은 중대 위반으로 보아 설비지원센터장에게 보고하며, 밀폐 공간 작업 자격을 6개월 정지한다. 같은 파트에서 1년 안에 위반이 2회 이상 나오면 파트장에게도 책임을 묻는다. 모든 위반 내용은 EQ-LOG에 기록하고 3년간 보존한다.
