# DP-ALM-104 DP-2 증착 장비 리프트 핀 위치 오류 알람(코드 D286) 조치 가이드
- 문서번호: DP-ALM-104
- 판: v1
- 시행일: 2025-07-18
- 종류: 알람 조치 가이드

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위와 알람 조건

이 문서는 증착 장비 DP-2(모델 CV-700)에서 리프트 핀 위치 오류 알람(코드 D286)이 발생했을 때의 조치 방법을 정한다. 리프트 핀은 웨이퍼를 서셉터(웨이퍼 받침대) 위로 들어 올리거나 내려놓는 세 개의 핀이다. 제어부는 핀 위치 센서값과 명령 위치를 비교한다. 편차가 ±0.15 mm를 3초 넘게 벗어나거나, 이동 명령 후 8초 안에 목표 위치에 닿지 못하면 이 알람이 발생한다. 적용 대상은 증착 파트 설비 엔지니어와 설비지원센터 당직자이다.

## 2. 증상

이 알람이 발생하면 이 장비는 웨이퍼 이송을 멈추고 상태를 '이송 보류'로 바꾼다. 챔버 안에 웨이퍼가 있으면 공정 단계를 마친 뒤 정지한다. 화면에는 아래 세부 구분이 함께 표시된다.

| 세부 구분 | 의미 | 주로 나타나는 현상 |
|---|---|---|
| A | 상승 미도달 | 웨이퍼가 이송 로봇 높이까지 올라오지 않는다 |
| B | 하강 미도달 | 웨이퍼가 서셉터에 완전히 안착하지 않는다 |
| C | 핀 간 높이 편차 | 웨이퍼가 기울고 이송 중 미세한 마찰음이 난다 |

같은 알람이 24시간 안에 3회 이상 반복되면 일시적 오류가 아닌 부품 불량으로 보고 4절의 2단계 점검으로 바로 넘어간다.

## 3. 추정 원인

원인은 발생 빈도 순으로 다음과 같이 본다.

1. 핀 구동부 벨로우즈(주름관)에 증착 부산물이 쌓여 움직임이 둔해진 경우
2. 핀 위치 센서의 오프셋이 틀어졌거나 센서 커넥터가 접촉 불량인 경우
3. 핀 끝단이 마모되어 높이가 달라진 경우
4. 구동 모터의 토크 저하 또는 공압 공급 부족

세부 구분 C는 3번의 비중이 높고, 구분 A와 B는 1번과 4번의 비중이 높다.

## 4. 조치 절차

1. **1단계(원격 재시도)**: 당직 엔지니어는 알람 화면과 세부 구분을 설비 이력 시스템 EQ-LOG에 먼저 기록한다. 이어서 핀 홈 복귀(원점 복귀)를 실행한다. 복귀는 최대 2회까지만 시도하고, 2회 모두 실패하면 2단계로 넘어간다.
2. **2단계(현장 점검)**: 챔버 내부 온도가 80℃ 이하인지 확인한 뒤 장비를 정지 상태로 전환한다. 6절의 잠금·표지 부착(Lockout-Tagout, LOTO) 절차를 완료한 뒤 센서 커넥터 체결, 공압 라인 압력(기준 0.45 MPa 이상), 벨로우즈 외관을 점검한다.
3. **3단계(청소 및 교정)**: 벨로우즈에 부산물이 보이면 승인된 세정 천으로 닦아낸다. 센서 오프셋은 교정 지그로 다시 맞춘다. 교정 목표는 세 핀 모두 높이 편차 ±0.05 mm 이내이다.
4. **4단계(부품 교체)**: 핀 끝단 마모가 0.30 mm를 넘거나 교정 후에도 편차가 해소되지 않으면 핀 세트나 센서를 교체한다. 부품은 자재 시스템 MAT-ON에서 출고를 요청하고, 급할 때는 자재 창고(내선 7720)에 문의한다. 부품을 교체하면 파트장 승인 후 변경 관리 시스템 CMS에 교체 내용을 등록한다.

## 5. 복구 확인 기준

복구는 다음 조건을 모두 만족해야 인정한다.

- 핀 상승과 하강을 연속 10회 반복하는 동안 알람이 없고, 매 회 이동 시간이 8초 미만일 것
- 세 핀의 위치 편차가 ±0.05 mm 이내일 것
- 챔버 누설률이 5 mTorr/min 이하일 것(챔버를 열었을 경우)
- 모니터링용 웨이퍼 3매를 처리한 결과, 웨이퍼 위치 이탈이나 긁힘이 없을 것

부품을 교체한 경우에는 위 조건을 통과한 뒤에도 첫 생산 로트 25매를 지켜보며 재발 여부를 확인한다.

## 6. 안전 주의

챔버를 열기 전에는 반드시 LOTO를 실시하고, 전원, 공압, 공정 가스 라인의 차단을 각각 확인한다. 내부 온도가 80℃ 이하로 내려가기 전에는 챔버를 열지 않는다. 증착 부산물은 인체에 유해할 수 있으므로 방진 마스크, 내열 장갑, 보안경을 착용한다. 핀 구동부는 공압이 남아 있으면 갑자기 움직일 수 있으므로 압력을 완전히 배기한 뒤 손을 넣는다. 작업은 2인 1조로 하며, 가스 냄새나 경보가 나면 즉시 작업을 중단하고 안전환경팀 비상 내선 7119로 알린다.

## 7. 보고와 에스컬레이션

알람을 처음 확인한 당직자는 30분 안에 설비 상황실(내선 7701)과 증착 파트장에게 보고한다. 1단계 재시도로 복구되지 않으면 설비지원센터 당직(내선 7700)에 지원을 요청한다. 복구에 2시간이 넘게 걸리거나 웨이퍼 손상이 의심되면 증착 파트장이 설비지원센터장에게 보고하고, 이와 함께 품질팀(내선 7600)에 영향 로트 확인을 요청한다. 부품 교체 후 장비 재가동은 파트장 승인과 설비지원센터장 승인, 두 단계를 모두 거쳐야 한다.

## 8. 조치 기록

조치를 마치면 당직자는 당일 근무 종료 전까지 EQ-LOG에 다음 항목을 기록한다.

- 알람 발생 시각, 세부 구분, 반복 횟수
- 수행한 단계와 측정값(편차, 공압, 누설률)
- 교체한 부품의 이름과 MAT-ON 출고 번호
- 복구 확인 결과와 승인자

기록은 3년간 보관한다. 같은 원인이 한 달 안에 2회 이상 확인되면 증착 파트장은 다음 정기 점검 회의에서 예방 정비 주기의 조정 여부를 안건으로 올린다.
