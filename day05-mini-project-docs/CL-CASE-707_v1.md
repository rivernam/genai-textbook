# CL-CASE-707 WS-5 세정 로봇 웨이퍼 미검출 장애 사례 보고서
- 문서번호: CL-CASE-707

- 시행일: 2025-03-11
- 종류: 장애 사례 보고서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 개요

이 문서는 2025-03-04 한결반도체 2팹 세정 공정의 WS-5(모델 CL-80) 세정 로봇에서 발생한 웨이퍼 미검출 장애(알람 코드 E-3107)를 정리한 장애 사례 보고서(CL-CASE-707)이다. 이 장애는 로봇 손끝 부품인 엔드이펙터의 웨이퍼 감지 센서가 놓여 있는 웨이퍼를 읽지 못해 반송이 멈춘 사건이다. 설비지원센터 세정 파트가 조치를 맡았다. 이 보고서는 경과, 영향, 원인, 조치와 재발 방지 대책을 기록하며, 교육 실습에서 사례 분석 자료로 쓴다.

## 2. 발생 경과

2025-03-04 새벽 야간 근무 중에 알람이 발생했다. 주요 경과는 다음과 같다.

| 시각 | 내용 |
|---|---|
| 02:10 | 알람 발생, 로봇 정지. 운전원이 설비 상황실(내선 7701)에 보고 |
| 02:25 | 설비지원센터 당직(내선 7700) 도착. 알람이 3회 반복되는 것을 확인 |
| 03:05 | 세정 파트 엔지니어가 센서 수광량을 측정. 58%로 기준 80% 이상에 못 미침 |
| 04:30 | 센서 렌즈의 약액 결정 잔류물과 엔드이펙터 패드 마모를 확인하고 렌즈를 세척 |
| 05:20 | 위치 재교정 후 시험 반송 10회 연속 정상 |
| 06:50 | 승인 절차를 마치고 생산 재개 |

이 장비는 02:10부터 06:50까지 4시간 40분 동안 멈췄다. 이 사이 운전원은 알람을 두 차례 임의로 초기화하고 재시도했으며, 이것이 정지 시간을 늘렸다.

## 3. 영향 범위

정지 시점에 반송 중이던 로트는 2개이고 웨이퍼는 모두 48매였다. 이 중 3매는 로봇 암 위에서 가장자리가 패드에 닿았을 가능성이 있어 품질팀(내선 7600)이 우선 검사했다. 검사 결과 접촉 흔적이나 파티클 증가는 없었고, 48매 전량을 재세정한 뒤 합격 처리했다. 폐기 웨이퍼는 0매이다. 후속 로트의 투입이 약 5시간 늦어져 해당 공정 구간의 일일 계획 대비 달성률이 하루 동안 낮아졌다. 다른 세정 장비와 인접 공정에는 영향이 없었다.

## 4. 원인 분석

직접 원인은 다음 두 가지가 겹친 것이다.

1. 센서 렌즈에 약액 결정 잔류물이 쌓여 수광량이 58%까지 떨어졌다. 기준은 80% 이상이다.
2. 엔드이펙터 패드가 누적 6,200회 사용되어 교체 기준 5,000회를 넘겼다. 이 때문에 웨이퍼 안착 높이 편차가 0.6 mm로 커져 기준 ±0.3 mm를 벗어났고, 센서 광축에서도 벗어났다.

근본 원인은 관리 체계에 있다. 첫째, 센서 점검이 8주 주기여서 렌즈 오염이 쌓이는 속도에 비해 길었다. 둘째, 패드 사용 횟수가 EQ-LOG(설비 이력 시스템)와 연동되지 않아 교체 시점을 사람이 가늠해야 했다. 셋째, 운전원이 알람을 반복 초기화하는 것을 막는 기준이 없었다.

## 5. 조치 내용

현장에서 다음 순서로 조치했다.

1. 센서 렌즈를 전용 용제로 세척하고 수광량을 다시 측정했다. 결과는 91%였다.
2. 엔드이펙터 패드를 새것으로 교체했다. 패드는 자재 창고(내선 7720)에서 MAT-ON(자재 시스템)으로 출고했다.
3. 반송 위치를 재교정해 편차가 ±0.3 mm 이내임을 확인했다.
4. 시험 반송 10회를 연속 정상으로 마쳤다.
5. 세정 파트장이 확인하고 설비지원센터장이 승인하는 2단계 절차를 거쳐 생산을 재개했다.

이 알람의 해제와 초기화 절차는 CL-ALM-106 문서를 따른다. 조치 내용과 측정값은 당일 EQ-LOG에 기록했다.
