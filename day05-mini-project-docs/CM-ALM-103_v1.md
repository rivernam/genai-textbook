# CM-ALM-103 CP-3 CMP 장비 헤드 진공 저하 알람(코드 C855) 조치 가이드
- 문서번호: CM-ALM-103
- 판: v1
- 시행일: 2024-02-12
- 종류: 알람 조치 가이드

## 1. 적용 범위와 알람 조건
이 문서는 「한결반도체 2팹」 설비지원센터가 운영하는 화학적 기계적 평탄화(CMP, Chemical Mechanical Planarization) 장비 CP-3에서 헤드 진공 저하 알람(코드 C855)이 발생했을 때 CMP 파트 담당자가 따를 조치 절차를 정한다. 이 알람은 연마 헤드의 웨이퍼 흡착 압력이 -68 kPa보다 대기압 쪽에 가까운 상태로 3초 이상 이어질 때 발생한다. 정상 흡착 압력은 -78~-85 kPa이다. 연마 패드나 슬러리 공급 알람에는 이 문서를 적용하지 않는다.

## 2. 증상
이 알람이 발생하면 장비는 진행 중인 연마를 즉시 멈추고 헤드를 반송 위치로 올리며, 경광등이 황색으로 점멸한다. 조작 화면의 진공 압력 그래프에는 붉은 경고 표시가 나타난다. 다음 현상 중 하나 이상이 있는지 확인한다.

- 흡착 압력이 -68 kPa 부근에서 오르내리거나 0 kPa 쪽으로 서서히 오른다.
- 웨이퍼를 적재한 직후 흡착 확인 단계에서 같은 알람이 반복된다.
- 연마한 웨이퍼 가장자리에 긁힘이나 슬러리 얼룩이 보인다.
- 진공 펌프 소음이 커지거나 배관에서 바람 새는 소리가 난다.

## 3. 추정 원인
발생 빈도가 높은 순서로 정리하면 다음과 같다. 슬러리가 굳어 흡착 구멍이 막힌 경우도 있으므로 헤드 하면을 함께 본다.

| 순위 | 추정 원인 | 확인 방법 |
|---|---|---|
| 1 | 헤드 멤브레인(고무막) 마모 또는 미세 찢어짐 | 사용 시간 450시간 초과 여부, 육안 점검 |
| 2 | 진공 라인 필터(부품 코드 HV-214) 막힘 | 필터 전후 압력차 측정 |
| 3 | 배관 체결부나 회전 연결부 누설 | 누설 시험 |
| 4 | 진공 펌프 성능 저하 | 펌프 단독 도달 압력 확인 |
| 5 | 진공 센서 오차 | 기준 게이지와 비교 |

## 4. 조치 절차
1. 발생 시각, 로트 번호, 헤드 번호를 기록한다. 헤드에 웨이퍼가 남아 있으면 수동 탈착 모드로 먼저 회수한다.
2. 흡착 압력 추이를 10분간 관찰한다. 기준 게이지와 ±2 kPa 이상 차이 나면 센서 오차로 보고 센서를 교정한다.
3. 장비를 정지하고 잠금·표지 절차를 적용한 뒤 헤드 하면과 멤브레인을 점검한다. 찢어짐이 있거나 사용 시간이 450시간을 넘었으면 멤브레인을 교체한다. 부품은 자재 시스템 MAT-ON으로 요청하고 자재 창고(7720)에서 받는다.
4. 진공 라인 필터를 분리해 막힘을 확인한다. 전후 압력차가 15 kPa를 넘으면 필터를 교체한다.
5. 배관 체결부를 점검하고 풀린 곳은 4 N·m 토크로 다시 조인다. 이어서 진공을 차단하고 60초 동안 압력 상승이 5 kPa 이하인지 누설 시험을 한다.
6. 누설이 없는데도 도달 압력이 -78 kPa에 못 미치면 진공 펌프 점검을 설비지원센터 당직(7700)에 요청한다.
7. 조치를 마치면 점검 모드에서 흡착 시험을 3회 반복한 뒤 잠금·표지를 해제한다.

## 5. 복구 확인 기준
다음 조건을 모두 만족해야 복구로 판단한다.

- 흡착 압력이 -78~-85 kPa 범위에서 안정적으로 유지된다.
- 누설 시험 60초 동안 압력 상승이 5 kPa 이하이다.
- 더미 웨이퍼 3매를 연속 연마하는 동안 이 알람이 다시 발생하지 않는다.
- 모니터 웨이퍼 1매를 연마해 품질팀(7600)이 긁힘이 없음을 확인한다.

재가동은 CMP 파트장 승인과 품질팀 확인의 2단계를 거친다. 재가동 후 4시간 동안은 재발 여부를 별도로 관찰한다.

## 6. 안전 주의
헤드 하면 작업 전에 반드시 잠금·표지 절차를 적용하고, 진공 배관을 분리하기 전에 잔압이 0 kPa인지 확인한다. 헤드 어셈블리는 약 18 kg이므로 2인 1조로 분리하고 장착한다. 슬러리를 만질 때는 보안경과 내화학 장갑을 착용한다. 슬러리가 눈이나 피부에 닿으면 즉시 15분 이상 흐르는 물로 씻고 안전환경팀 비상 연락처(7119)에 알린다. 깨진 웨이퍼 조각은 맨손으로 만지지 말고 전용 집게로 수거한다.

## 7. 보고와 에스컬레이션
1. 알람 발생 후 15분 안에 CMP 파트장에게 보고한다.
2. 1시간 안에 복구하지 못하면 설비 상황실(7701)에 생산 영향을 알린다.
3. 2시간을 넘기면 설비지원센터장에게 보고하고 진행 중인 로트의 이동을 협의한다.
4. 웨이퍼 파손이 있거나 24시간 안에 이 알람이 3회 재발하면 즉시 설비지원센터장과 품질팀에 알리고, 변경 관리 시스템 CMS에 원인 분석 요청을 등록한다.
5. 슬러리 누출이나 인명 피해가 있으면 다른 보고에 앞서 7119로 먼저 연락한다.

## 8. 조치 기록
담당자는 조치를 마친 뒤 24시간 안에 설비 이력 시스템 EQ-LOG에 다음 항목을 기록한다. 발생 시각, 로트 번호, 헤드 번호, 알람 시점과 복구 후의 흡착 압력, 교체한 부품 코드와 수량, 누설 시험 결과, 승인자이다. 멤브레인을 교체했으면 사용 시간 카운터를 0으로 초기화했는지도 적는다. 이 기록은 3년간 보존하며, 재발 분석 때 이전 기록을 대조한다.
