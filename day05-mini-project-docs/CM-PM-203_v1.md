# CM-PM-203 CP-3 CMP 장비 분기 오버홀 점검 절차서
- 문서번호: CM-PM-203
- 판: v1
- 시행일: 2025-09-18
- 종류: 정기 점검 절차서

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적과 주기

이 절차서(CM-PM-203)는 한결반도체 2팹에서 쓰는 화학 기계적 평탄화(CMP, Chemical Mechanical Planarization) 장비 CP-3의 분기 오버홀 점검 방법을 정한다. 연마 패드, 연마 헤드, 슬러리 공급 계통의 마모와 편차를 정기적으로 확인해 연마 균일도 불량과 슬러리 유량 편차 알람(SL-318)을 미리 막는 것이 목적이다.

점검은 13주마다 1회 한다. 정해진 날짜의 앞뒤 5일 이내에 끝내야 한다. 담당은 CMP 파트이며, 1회 작업 시간은 최대 14시간이다.

## 2. 준비물과 사전 조건

작업 전에 다음 준비물을 갖춘다.

- 패드 두께 측정기: 교정 유효기간이 6개월 이내인 것
- 토크 렌치와 진공 게이지
- 유량 확인용 메스실린더(1 L)
- 교체 부품: 연마 패드 1장, 컨디셔너 디스크 1개, 리테이너 링 1세트, 슬러리 필터 2개
- 시험 웨이퍼 5매

교체 부품은 작업 7일 전까지 자재 시스템 MAT-ON에서 출고를 요청하고, 수량은 자재 창고(내선 7720)에서 확인한다.

사전 조건은 다음과 같다.

1. 작업 7일 전까지 변경 관리 시스템 CMS에 작업을 신청한다. 승인은 CMP 파트장, 설비지원센터장 순서의 2단계로 받는다.
2. 작업 시작 4시간 전에 이 장비에 걸린 생산 Lot의 투입을 멈추고 다른 장비로 옮긴다.
3. 슬러리 라인은 탈이온수(DI, deionized water)로 20분 동안 씻어 낸 뒤 작업한다.
4. 작업은 2인 1조로 하며, 화학물질 취급 보호구와 에너지 차단 및 잠금 조치는 FC-SAF-501 문서를 따른다.

## 3. 점검 항목과 기준값

이 장비에서 점검하는 항목과 기준값은 아래 표와 같다. 측정은 항목마다 3회 하고 평균값을 기록한다.

| 항목 | 기준값 | 조치 한계 |
|---|---|---|
| 연마 패드 잔여 두께 | 신품 1.25 mm | 0.90 mm 이하이면 교체 |
| 컨디셔너 디스크 누적 사용 | 120시간 미만 | 120시간 이상이면 교체 |
| 리테이너 링 마모량 | 0.40 mm 미만 | 0.40 mm 이상이면 교체 |
| 헤드 압력 편차 | 설정값 ±0.3 kPa | 초과 시 조정 |
| 플래튼 회전 속도 편차 | 설정값 ±1.5 rpm(분당 회전수) | 초과 시 조정 |
| 슬러리 유량 편차 | 설정값 ±4 % | 초과 시 필터 교체 후 재측정 |
| 헤드 진공 | -80 kPa 이하 | 미달 시 배관 점검 |
| DI 공급 압력 | 250~300 kPa | 벗어나면 레귤레이터 조정 |

## 4. 작업 절차

1. 잠금 조치를 마치고 장비 내부 압력이 대기압과 같아졌는지 확인한다.
2. 연마 패드의 잔여 두께를 반경 방향 5개 지점에서 잰다. 한 지점이라도 0.90 mm 이하이면 패드를 교체한다.
3. 컨디셔너 디스크의 누적 사용 시간을 EQ-LOG에서 확인하고, 표면의 다이아몬드 입자 탈락 여부를 눈으로 살핀다.
4. 리테이너 링의 마모량을 재고, 토크 렌치로 헤드 체결 볼트를 규정 토크로 다시 조인다.
5. 헤드의 압력과 진공, 플래튼 회전 속도를 설정값과 비교한다.
6. 슬러리를 1분 동안 흘려 보내 메스실린더로 받아 유량 편차를 계산한다. 필터는 이 시점에 2개 모두 교체한다.
7. 조립을 끝내고 잠금을 푼 뒤 시험 웨이퍼 5매를 연마한다.
8. 교체한 소모 부품의 반납과 폐기는 CM-PRT-301 문서를 따른다.

## 5. 판정 기준

점검 결과는 세 가지로 판정한다.

- **합격**: 모든 항목이 기준값 안에 있고, 시험 웨이퍼 5매의 제거율 편차가 ±3 % 이내이며 웨이퍼 내 균일도가 4 % 이하이다. 이때 생산에 복귀시킨다.
- **조건부 합격**: 한 항목만 한계를 벗어났으나 조정 뒤 재측정에서 기준값 안으로 들어온 경우이다. 복귀 후 처음 3개 Lot은 품질팀이 전수 확인한다.
- **불합격**: 시험 웨이퍼 결과가 기준을 넘거나 두 항목 이상이 재측정 후에도 한계를 벗어난 경우이다. 생산 복귀를 허용하지 않는다.

## 6. 이상 발견 시 조치

기준값을 벗어난 항목은 그 자리에서 교체하거나 조정하고 다시 측정한다. 재작업은 최대 2회까지 한다.

슬러리나 약액이 새면 작업을 즉시 멈추고 안전환경팀 비상 연락처(내선 7119)에 알린다. 누설 구역은 출입을 막고, 처리가 끝나기 전에는 작업을 재개하지 않는다.

재작업을 2회 했는데도 불합격이면 설비 상황실(내선 7701)에 알리고 설비지원센터장에게 즉시 보고한다. 품질팀(내선 7600)에는 해당 기간에 생산된 Lot의 목록을 보낸다.

복귀 후 72시간 안에 이 알람이 다시 발생하면 이번 점검 내용을 처음부터 검토한다. 이때는 CMP 파트장이 원인 분석서를 5영업일 이내에 작성한다. 알람이 계속되면 당직(내선 7700)으로 연락한다.

## 7. 기록과 보고

작업자는 작업이 끝난 뒤 24시간 이내에 EQ-LOG에 다음 내용을 입력한다.

- 항목별 측정값(3회 평균)
- 교체한 부품과 수량
- 시험 웨이퍼 결과
- 판정 결과와 재작업 횟수

측정 원본 기록지는 3년 동안 보관한다. 시험 웨이퍼 결과는 2영업일 이내에 품질팀에 전달한다. CMP 파트장은 작업 종료 다음 영업일 12시까지 설비지원센터장에게 결과를 보고하고, CMS의 작업 건을 종료 처리한다. 불합격이나 재작업 2회 건은 월간 설비 회의에서 별도로 다룬다.
