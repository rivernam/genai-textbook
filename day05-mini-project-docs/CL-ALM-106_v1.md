# CL-ALM-106 WS-5 세정 장비 로봇 웨이퍼 미검출 알람(코드 W116) 조치 가이드
- 문서번호: CL-ALM-106
- 판: v1
- 시행일: 2024-11-07
- 종류: 알람 조치 가이드

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위와 알람 조건

이 문서(CL-ALM-106)는 세정 장비 WS-5(모델 CL-80)에서 로봇이 웨이퍼를 집으러 간 위치에서 웨이퍼를 감지하지 못할 때 발생하는 알람 W116의 조치 방법을 정한다. 세정 파트 엔지니어와 설비지원센터 당직 담당자에게 적용한다. 로봇 암이 카세트 슬롯이나 처리 챔버 앞에서 흡착 동작을 한 뒤 3초 안에 진공 압력이 -62 kPa(킬로파스칼)보다 깊어지지 않거나, 암 끝 광센서가 2회 연속 '웨이퍼 없음'으로 읽으면 알람이 발생한다. 알람이 발생하면 장비는 해당 로트의 이송을 멈추고 대기 상태가 된다.

## 2. 증상

이 알람이 발생하면 다음 증상이 나타난다.

- 조작 화면에 적색 알람 배너가 뜨고 경광등이 점멸한다.
- 로봇 암이 슬롯 앞에서 멈추고, 같은 위치에서 흡착을 2회 자동 재시도한 뒤 정지한다.
- 웨이퍼 맵(카세트 안 웨이퍼 위치 정보)의 장수와 실제 장수가 다르게 표시된다.
- 후속 로트가 로드 포트에서 대기하며 처리 시간이 늘어난다.

1시간 안에 3회 이상 발생하면 반복 알람으로 분류하고, 7절의 보고 기준을 함께 적용한다.

## 3. 추정 원인

추정 원인은 발생 빈도가 높은 순으로 아래와 같다.

| 순위 | 추정 원인 | 확인 방법 |
|---|---|---|
| 1 | 흡착 패드 마모 또는 오염 | 사용 90일 또는 흡착 40만 회 초과 여부, 패드 표면 육안 확인 |
| 2 | 진공 라인 누설 또는 필터 막힘 | 진공 게이지가 -75 kPa 이하인지 확인 |
| 3 | 암 끝 광센서 렌즈 오염 | 신호 레벨이 기준의 70% 미만인지 확인 |
| 4 | 슬롯 위치 티칭(로봇 위치 학습) 편차 | 기준 위치 대비 ±0.4 mm 초과 여부 |
| 5 | 전면 개방형 웨이퍼 운반함(FOUP) 안 웨이퍼 밀림 또는 빈 슬롯 | 육안 확인과 웨이퍼 맵 대조 |

## 4. 조치 절차

1. 알람 발생 시각과 로트 번호를 기록하고 장비를 수동 모드로 전환한다.
2. 카세트 문을 열기 전에 로봇 암 정지와 인터록 상태를 확인한다. 이어서 실제 웨이퍼 장수를 웨이퍼 맵과 대조한다. 암 위나 챔버 입구에 웨이퍼가 걸려 있으면 임의로 빼지 말고 7절에 따라 보고한다.
3. 이상이 없으면 알람을 해제하고 흡착 재시도를 1회만 한다. 같은 알람이 다시 발생하면 4단계로 간다.
4. 광센서 렌즈를 이소프로필 알코올을 묻힌 무진 부직포로 닦고 신호 레벨을 확인한다.
5. 진공 게이지를 확인한다. -75 kPa 이하에 이르지 못하면 진공 호스 체결과 필터를 점검한다. 필터 압력 강하가 15 kPa 이상이면 필터를 교체한다.
6. 패드 마모가 확인되면 자재 창고(내선 7720)에서 자재 시스템 MAT-ON으로 패드를 불출받아 교체한다.
7. 티칭 편차가 ±0.4 mm를 넘으면 자동 티칭을 실행한다. 티칭 값 변경은 파트장 승인을 받아 변경 관리 시스템 CMS에 등록한 뒤 적용한다.
8. 더미 웨이퍼로 시험 이송을 하고 5절 기준으로 복구를 확인한다.

## 5. 복구 확인 기준

복구는 아래 기준을 모두 만족할 때 인정한다.

- 더미 웨이퍼 시험 이송을 연속 10회 하는 동안 이 알람이 0회 발생한다.
- 흡착 후 진공이 2초 이내에 -75 kPa 이하에 도달한다.
- 웨이퍼 맵 장수와 실제 장수가 일치한다.
- 복구 후 첫 로트는 품질팀(내선 7600)이 입자 측정 결과(0.12 µm 이상 입자 30개 이하)를 확인한다.

첫 2개 로트는 세정 파트 엔지니어가 이송 상태를 지켜본다. 이 동안 알람이 재발하면 복구로 보지 않고 4절을 처음부터 다시 수행한다.

## 6. 안전 주의

- 암이나 챔버 내부에 손을 넣는 작업 전에는 장비 전원에 잠금·표지(LOTO, Lockout Tagout)를 적용한다. 로봇 동작 범위 안에는 인터록이 확인되기 전까지 들어가지 않는다.
- 챔버 입구에 세정 약액이 남아 있을 수 있으므로 내화학 장갑, 보안경, 방액 앞치마를 착용한다.
- 이소프로필 알코올은 인화성이므로 점화원을 멀리하고, 작업 현장에는 한 번에 100 mL 이하만 가져간다.
- 깨진 웨이퍼 파편은 맨손으로 만지지 않고 전용 파편 용기에 담는다.
- 약액 노출이나 누출이 있으면 즉시 작업을 멈추고 안전환경팀 비상 내선 7119로 연락한다.

## 7. 보고와 에스컬레이션

알람 발생 후 10분 안에 해결되지 않으면 설비지원센터 당직(내선 7700)에 알린다. 30분이 지나도 복구되지 않으면 세정 파트장에게 보고한다. 60분이 지나도 복구되지 않으면 설비지원센터장에게 보고하고, 설비 상황실(내선 7701)에 가동 중단을 통보한다. 웨이퍼 장수 불일치, 파손, 위치 불명이 확인되면 시간과 관계없이 즉시 품질팀(내선 7600)에 알리고 해당 로트를 홀드한다. 반복 알람으로 분류되면 파트장이 당일 보고하고, 원인 분석 결과는 영업일 3일 이내에 제출한다.

## 8. 조치 기록

조치가 끝나면 설비 이력 시스템 EQ-LOG에 작업 종료 후 24시간 이내에 기록한다. 기록 항목은 아래와 같다.

- 발생 시각과 로트 번호
- 원인 분류(3절의 순위 번호 사용)
- 진공 측정값과 티칭 편차
- 교체 부품과 MAT-ON 불출 번호
- 시험 이송 결과

세정 파트장은 영업일 2일 이내에 기록을 확인하고 승인한다. 기록은 3년간 보존한다.
