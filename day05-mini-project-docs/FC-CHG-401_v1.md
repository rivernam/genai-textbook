# FC-CHG-401 설비 레시피 변경 승인 절차
- 문서번호: FC-CHG-401
- 판: v1
- 시행일: 2024-11-28
- 종류: 변경 승인 절차

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 목적과 적용 대상

이 문서는 한결반도체 2팹 설비지원센터가 관리하는 장비의 설비 레시피(공정 조건 값과 단계 순서를 담은 설정 파일)를 바꿀 때 거치는 신청, 승인, 검증, 기록의 절차를 정한다. 승인받지 않은 변경으로 생기는 수율 저하와 설비 손상을 막고, 모든 변경의 근거를 나중에 추적할 수 있게 하는 것이 목적이다.

적용 대상은 식각 장비 EC-4, 증착 장비 DP-2, CMP(화학 기계 연마, Chemical Mechanical Polishing) 장비 CP-3, 세정 장비 WS-5, 이온주입 장비 IM-1의 설비 레시피 변경이다. 이 절차(FC-CHG-401)는 레시피의 숫자 값, 단계 순서, 사용 가스와 약품의 종류를 바꾸는 모든 경우에 적용한다. 장비 부품 교체와 제어 소프트웨어 갱신은 적용 대상이 아니다.

## 2. 신청 조건

변경 신청은 장비 담당 파트의 엔지니어가 변경 관리 시스템(Change Management System, CMS)에서 한다. 신청서에는 다음 네 가지를 모두 적는다.

1. 변경 전후 값과 변경 사유
2. 변경 대상 레시피의 현재 버전 번호
3. 영향받는 제품 로트의 범위
4. 검증 계획

신청은 시행 희망일 2영업일 전 오후 3시까지 접수해야 한다. 같은 레시피에 처리 중인 신청이 있으면 새로 신청할 수 없다. 신청자는 접수 전에 변경 전 레시피 사본을 설비 이력 시스템(Equipment Log, EQ-LOG)에 올려 둔다.

변경 등급은 공정 파라미터 기준값 대비 변경폭과 변경 내용으로 정한다. 등급이 둘 사이에서 모호하면 높은 쪽을 적용한다.

| 등급 | 변경 내용 |
|---|---|
| C | 기준값 대비 ±3% 이내이고 단계 순서가 같다 |
| B | 기준값 대비 ±3% 초과 ±10% 이내이고 단계 순서가 같다 |
| A | ±10% 초과, 단계 추가·삭제, 가스·약품 종류 변경 중 하나 이상에 해당한다 |

## 3. 승인 단계와 승인권자

승인 단계는 변경 등급에 따라 다르다. 신청자 본인은 승인권자가 될 수 없다.

| 등급 | 승인 단계 | 승인권자 순서 |
|---|---|---|
| C | 1단계 | 해당 파트장 |
| B | 2단계 | 해당 파트장, 품질팀 공정 품질 담당 |
| A | 3단계 | 해당 파트장, 품질팀장, 설비지원센터장 |

가스나 약품의 종류를 바꾸는 신청은 품질팀장 승인 전에 안전환경팀의 위험성 검토를 한 번 더 받는다. 어느 단계에서든 반려되면 신청은 종료된다. 반려된 신청은 반려일부터 5영업일 이내에 기존 신청번호를 인용해 재신청할 수 있다. 최종 승인 후 10영업일 안에 시행하지 않으면 승인은 자동으로 만료된다.

## 4. 처리 기한

각 승인권자는 신청을 받은 날부터 1영업일 이내에 승인 또는 반려를 결정한다. 신청 접수부터 최종 결정까지의 전체 기한은 등급 C가 1영업일, 등급 B가 3영업일, 등급 A가 5영업일이다.

기한이 지나도 결정이 없으면 CMS가 해당 승인권자에게 알림을 보낸다. 초과한 지 1영업일이 지나면 설비지원센터장에게도 같은 알림이 간다. 진행 상황을 묻거나 기한 연장이 필요하면 설비지원센터 당직(내선 7700)에 연락한다. 기한 연장은 한 신청에 1회, 최대 2영업일까지만 인정한다.

## 5. 검증 요건

변경을 시행한 뒤에는 등급별로 정한 수의 시험 웨이퍼로 변경 결과를 확인한다. 검증 결과는 CMS의 해당 신청서에 첨부한다.

| 등급 | 시험 웨이퍼 | 검증 방식 |
|---|---|---|
| C | 3매 | 1회 처리 후 측정 |
| B | 5매 | 연속 2로트 처리 후 측정 |
| A | 25매 | 1로트 처리, 품질팀 입회 |

합격 기준은 모든 측정값이 관리 한계 안에 들고, 공정 능력 지수(Process Capability Index, Cpk)가 1.33 이상인 것이다. 하나라도 기준을 넘으면 불합격이다. 불합격이 나오면 2시간 이내에 이전 버전 레시피로 되돌리고 설비 상황실(내선 7701)에 알린다. 복귀 후 장비를 다시 가동하는 절차는 FC-OPS-603 문서를 따른다. 검증이 끝나기 전에는 이 변경을 양산 로트에 적용하지 않는다.

## 6. 긴급 변경

설비 정지나 수율 이상이 진행 중이어서 정식 승인을 기다릴 수 없을 때만 긴급 변경을 할 수 있다. 신청자는 설비지원센터 당직(내선 7700)에 구두 승인을 요청하고, 당직 설비지원센터장 또는 그 대행자가 승인한다.

긴급 변경 뒤의 후속 조치는 다음과 같다.

1. 시행 후 4시간 이내에 CMS에 사후 등록한다.
2. 24시간 이내에 해당 파트장과 품질팀(내선 7600)의 사후 승인을 받는다.
3. 긴급 변경 값은 72시간만 유효하며, 이후에는 정식 절차로 다시 신청한다.

가스나 약품의 종류를 바꾸는 변경은 긴급 변경으로 할 수 없다. 같은 레시피에 긴급 변경을 연속 2회 넘게 적용해서도 안 된다.

## 7. 기록과 사후 검토

모든 변경은 EQ-LOG에 신청번호, 변경 전후 값, 승인자, 시행 시각, 검증 결과를 남긴다. 이 기록은 3년간 보존한다. 기록이 빠진 변경은 승인되지 않은 변경으로 보고, 해당 파트의 신규 신청 접수를 보완이 끝날 때까지 보류한다.

파트장은 시행 후 14일째에 변경 결과를 사후 검토하고, 이상이 없으면 신청을 종결한다. 설비지원센터장은 매월 1회 변경 심의 회의를 열어 그 달의 긴급 변경, 반려, 복귀 사례를 점검한다. 회의에서 나온 개선 사항은 다음 달 회의 전까지 담당 파트가 처리하고 결과를 보고한다.
