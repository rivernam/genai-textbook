# DP-ALM-106 DP-2 증착 장비 배기 라인 막힘 경고 알람(코드 D634) 조치 가이드
- 문서번호: DP-ALM-106
- 판: v1
- 시행일: 2025-05-01
- 종류: 알람 조치 가이드

> 교육용 가공 문서입니다. 실제 설비 · 인물 · 수치가 아닙니다.

## 1. 적용 범위와 알람 조건

이 문서(DP-ALM-106)는 증착 장비 DP-2(모델 CV-700)에서 배기 라인 막힘 경고 알람(코드 D634)이 발생했을 때 현장 엔지니어가 따를 조치를 정한다. 적용 대상은 증착 파트 엔지니어와 설비지원센터 당직자이다. 이 알람은 공정 챔버와 배기 처리 설비 입구 사이의 배기 차압이 8.5 kPa 이상인 상태로 3분 이상 이어지면 발생한다. 차압이 12.0 kPa에 이르면 장비가 새 공정 시작을 막는 인터락(안전 정지 장치)이 작동하며, 이때는 별도의 정지 알람이 함께 표시된다.

## 2. 증상

이 알람이 발생하기 전후에 다음 증상이 보인다.

- 조작 화면에 노란색 경고가 표시되고 배기 차압 값이 8.5 kPa 이상으로 나타난다.
- 공정 중 챔버 압력이 설정값보다 0.3 Torr 이상 높게 흔들린다.
- 공정이 끝난 뒤 챔버를 비우는 시간이 기준 90초를 넘는다.
- 배기 배관 이음부 주변에 흰색 분말이 보이거나 배관 표면 온도가 구간별로 달라진다.

## 3. 추정 원인

이 알람의 원인은 대부분 공정 부산물이 배기 경로에 쌓이는 것이다. 발생 빈도가 높은 순서로 정리하면 다음과 같다.

| 순서 | 추정 원인 | 확인 방법 |
|---|---|---|
| 1 | 부산물 포집 트랩의 필터 카트리지 포화 | 트랩 전후 차압 비교, 누적 사용 시간 확인 |
| 2 | 배관 히터 온도 저하로 인한 분말 응축 | 히터 컨트롤러 설정값과 실측값 비교 |
| 3 | 배기 밸브 개도 불량 | 밸브 개도 표시값과 지령값 비교 |
| 4 | 차압 센서 오차 | 예비 센서 값과 교차 확인 |

필터 카트리지는 누적 사용 시간이 320시간에 이르면 교체 시기로 보며, 이 시간을 넘긴 경우 1순위 원인으로 먼저 의심한다.

## 4. 조치 절차

1. 진행 중인 로트의 현재 공정 스텝이 끝나면 신규 로트 투입을 중지하고 장비를 대기 상태로 둔다. 스텝 종료까지 10분을 넘게 기다려야 하면 설비지원센터 당직(내선 7700)에 알린다.
2. 설비 이력 시스템 EQ-LOG에서 최근 24시간의 차압 추이와 필터 누적 사용 시간을 확인한다.
3. 배기 경로에 질소를 15분 동안 흘려 보낸다. 유량은 40 slm(standard liter per minute, 분당 표준 리터)으로 한다. 퍼지 후 차압이 8.5 kPa 미만으로 내려가면 4단계로 가고, 그렇지 않으면 5단계로 간다.
4. 배관 히터 설정이 140 ℃인지 확인한다. 설정이 다르면 원래 값으로 되돌리고 20분 안정화한 뒤 차압을 다시 읽는다.
5. 차압이 내려가지 않으면 장비를 정지 상태로 전환하고 트랩 점검에 들어간다. 배관 표면 온도가 60 ℃ 이하로 내려간 것을 확인한 뒤 2인 1조로 작업한다. 트랩 분해와 부산물 취급은 DP-PRT-302 문서를 따른다.
6. 필터 카트리지(자재코드 FLT-6420)가 필요하면 자재 시스템 MAT-ON에서 재고를 확인하고, 없으면 자재 창고(내선 7720)에 긴급 불출을 요청한다. 카트리지 교체는 증착 파트장의 승인을 받은 뒤 진행한다.
7. 조립 후 이음부 누설 점검을 하고 질소 퍼지를 한 번 더 실시한 다음 장비를 대기 상태로 복귀시킨다.

## 5. 복구 확인 기준

다음 조건을 모두 충족해야 복구로 인정한다.

- 배기 차압이 5.0 kPa 이하로 30분 연속 유지된다.
- 시험 웨이퍼 2매를 공정한 뒤 챔버 압력 편차가 0.1 Torr 이내이다.
- 공정 후 챔버 배기 시간이 90초 이내이다.
- 이 알람이 대기 상태에서 재발하지 않는다.

위 조건을 확인한 뒤 품질팀(내선 7600)이 시험 웨이퍼의 결과를 확인하면 첫 제품 로트를 투입한다. 첫 로트는 공정 완료 후 입자 검사를 거친다.

## 6. 안전 주의

배기 경로에 쌓인 분말은 피부와 호흡기를 자극할 수 있다. 트랩을 열 때는 내화학 장갑, 보안경, 방진 마스크를 착용한다. 작업 전에는 장비 전원을 차단하고 잠금·표지(LOTO, lock-out tag-out)를 건 뒤 작업자 2명이 서로 확인한다. 배관 표면이 60 ℃를 넘으면 접촉하지 않는다. 분말이 눈이나 피부에 닿거나 흡입 증상이 있으면 즉시 작업을 멈추고 안전환경팀 비상 내선 7119로 연락한다.

## 7. 보고와 에스컬레이션

| 시점 | 보고 대상 | 방법 |
|---|---|---|
| 알람 확인 즉시 | 설비지원센터 당직 | 내선 7700 |
| 조치 시작 후 30분 내 복구되지 않을 때 | 증착 파트장 | 구두 보고와 EQ-LOG 입력 |
| 조치 시작 후 2시간 내 복구되지 않을 때 | 설비지원센터장 | 설비 상황실(내선 7701)을 통해 보고 |
| 인터락이 작동했거나 분말 노출 사고가 있을 때 | 안전환경팀 | 내선 7119 |

2시간을 넘겨도 복구되지 않으면 설비지원센터장이 해당 장비의 로트 재배정 여부를 품질팀과 협의해 결정한다.

## 8. 조치 기록

조치를 마친 담당자는 24시간 이내에 EQ-LOG에 다음 항목을 입력한다. 입력 항목은 알람 발생 시각, 최대 차압 값, 실시한 조치, 교체한 부품과 자재코드, 복구 확인 결과이다. 기록은 3년간 보관한다. 같은 알람이 7일 안에 2회 이상 발생하면 근본 원인 개선을 위해 변경 관리 시스템 CMS에 변경 요청을 등록한다. 요청에는 증착 파트장의 검토 의견을 붙이고, 설비지원센터장이 최종 승인한다.
