# 챔버 월간 상태 보고서 초안

## 범위
- 챔버 하나, 한 달치 보고서 초안 한 부를 씁니다. 여러 챔버 비교나 원인 분석은 이 Skill의 범위가 아닙니다.

## 입력
- 챔버 이름(예: ETCH-04)과 연월(예: 2026-07). 둘 중 하나라도 없으면 쓰기 전에 되묻습니다.

## 절차
1. 런 수와 NG 건수는 `runs` 테이블에서 셉니다. `mart_chamber_daily`는 완료 로트(lots.status='DONE')만 집계한 요약표라 전체 건수보다 적게 나옵니다.
   - 예: `python tools/query_db.py "SELECT COUNT(*), SUM(result='NG') FROM runs WHERE chamber='ETCH-04' AND start_ts LIKE '2026-07%'"`
2. 전월도 같은 방식으로 셉니다.
3. 비율과 증감은 `python tools/calc.py`로 계산합니다. 암산한 숫자를 쓰지 않습니다.
4. 관련 사내 규정은 `python tools/search_docs.py`로 찾아 문서 ID를 적습니다. 찾지 못하면 「찾지 못함」으로 적습니다.

## 출력 양식 (이 순서와 제목을 그대로 씁니다)
```
# {챔버} {연월} 월간 상태 보고 (초안)
대상 기간: {연월} · 비교 기준: {전월}
## 1. 요약
(세 줄 이내)
## 2. 수치
| 항목 | 값 | 출처 |
| 런 수 | … | runs |
| NG 건수 | … | runs |
| NG 비율 | …% | calc |
## 3. 전월 대비
## 4. 관련 사내 규정
## 5. 확인 필요 사항
```

## 검증 기준
- 수치표의 모든 행에 출처 칸이 채워져 있습니다.
- NG 건수가 runs 테이블에서 센 값과 같습니다.
- 다섯 개 절 제목이 모두 있습니다.
- 개인 이름을 쓰지 않습니다. 사람은 역할(파트장·설비 엔지니어)로 적습니다.
