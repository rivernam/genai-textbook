# SL-FAB 사내 보고 규정 (보고서·판정 근거 공통)

- R1 수치 출처: 보고서에 쓰는 수치마다 출처(DB 테이블 이름, 문서 ID, calc 중 하나)를 붙입니다.
- R2 개인정보: 개인 이름·사번·연락처를 적지 않습니다. 사람은 역할(파트장·설비 엔지니어·품질 담당)로 적습니다.
- R3 추정 표시: 조회하거나 계산하지 않은 값은 「추정」이라고 표시합니다.
- R4 판정 확정 금지: 폐기·출하 중지·설비 정지처럼 되돌리기 어려운 판정은 보고서가 확정하지 않고 「승인 필요」로 남깁니다.
- R5 대상 명시: 첫 부분에 대상(챔버·제품·로트 등)과 기간을 적습니다.
